# Databricks

You can connect to a Databricks database to query data in tables from Databricks Workspace clusters and SQL Analytics SQL endpoints.

[*Create a Databricks connection*](Create-Databricks-connection.htm)

Information noteIndustry-accepted best practices must be followed when using or allowing access through the ODBC Connector. Administrators must follow The Principle of Least Privilege when setting up source database privileges and permissions.

## Supported Databricks versions

The followings database versions are supported:

- Databricks 11.3, 12 LTS, 13 LTS, 14

## Supported Databricks data types

The following Databricks data types are supported:

- BigInt
- Binary
- Boolean
- Date
- Decimal
- Double
- Float
- Integer
- SmallInt
- String
- Timestamp
- TinyInt
- Varchar
