# Navigating in the application interface

Build and explore data analytics applications with Qlik Cloud.

## Application overview

When you open an application from your [activity center](#glossary-1 "Glossary term"), you arrive at the application overview.

See all the content that the application contains, such as [sheets](#glossary-2 "Glossary term"), [stories](#glossary-3 "Glossary term"), and [bookmarks](#glossary-4 "Glossary term") and navigate between the different views.

For more information, see:

- [*Application overview*](../Apps/app-overview-cloud-hub.htm)
- [*Navigation bar*](tabbed-navigation.htm)
- [*Sheet view*](../Sheets/sheet-view.htm)
- [*Storytelling view*](../StoryTelling/storytelling-view.htm)

## Insight Advisor

[Insight Advisor](#glossary-5 "Glossary term") helps you explore data and create analyses.

Insight Advisor uses the Qlik cognitive engine and a [logical model](#glossary-6 "Glossary term") of application data to create [visualizations](#glossary-7 "Glossary term") and analyses in an application. As an application creator, Insight Advisor helps you create application content. As a business user using apps for analysis, Insight Advisor helps you create analyses outside of what is available in the application.

For more information, see [*Creating visualizations with Insight Advisor*](../Insights/insight-advisor-create-visualizations.htm).

![Insight Advisor](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_gen-insight-advisor_saas-rev.png)

## Manage data

Load and manage data using the [Data manager](#glossary-8 "Glossary term"), the [data catalog](#glossary-9 "Glossary term"), [Data load editor](#glossary-10 "Glossary term"), and the [Data model viewer](#glossary-11 "Glossary term").

### Data manager

Add data sources and load data without using scripts in the Data manager.

Associate the data manually or based on recommendations in the Associations view. View and manipulate tables in the Tables view.

For more information, see [*Data manager*](../LoadData/data-management.htm).

![Data manager of Qlik Cloud analytics application](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_gen-data-manager_saas-rev.png)

### Data catalog

Use the data catalog to load data from the files that you have access to.

View and select data to load from all the data files to which you have access. Associate and manipulate the data in Data manager or Data load editor.

For more information, see [*Loading data from the data catalog*](../LoadData/adding-data-catalog.htm).

![](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_InApp_DataCatalog_Summary.png)

### Data load editor

Load data using scripts in the Data load editor.

You can edit a script manually, or it can be generated by the Data manager. If you need to use complex script statements, you need to edit them manually.

For more information, see [*Data load editor*](../LoadData/data-load-editor-overview.htm).

![Data load editor in a Qlik Cloud analytics application.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_gen-dle-cloud-rev2.png)

### Data model viewer

See the data structure of the data that you have added to your application in the Data model viewer.

Preview data and view metadata for a table or a [field](#glossary-12 "Glossary term") and create [dimensions](#glossary-13 "Glossary term") and [measures](#glossary-14 "Glossary term") from fields.

For more information, see [*Data model viewer*](../DataModeling/data-model-viewer-overview.htm).

![Data model viewer of Qlik Sense cloud UI](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_gen-data-model-viewer_saas-rev.png)

## Reporting

You can configure enterprise report output to be generated from the application.

Define [templates](#glossary-15 "Glossary term") and a [distribution list](#glossary-16 "Glossary term"), and create [filters](#glossary-17 "Glossary term") and [report tasks](#glossary-18 "Glossary term"). These elements control what is included in the report output, who receives the reports, and how the reports are delivered. Additionally, you can activate on-demand reporting so that users can generate reports as they analyze sheets in the application.

For more information, see [*In-application reporting with Qlik Cloud Analytics*](../Reporting/InAppGeneral/cloud-in-app-reports-intro.htm).
