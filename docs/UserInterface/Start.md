# Logging in to Qlik Cloud

To access your Qlik Cloud tenant, use the appropriate URL for your tenant. If you have multiple tenants, you will be prompted to select the one you wish to access.

## Accessing your tenant

Do the following:

1. In a web browser, enter the following URL:

   https://<your tenant address>

   (Your system administrator can provide the exact address.)

   Alternatively, you can visit [www.qlikcloud.com](http://www.qlikcloud.com/) to access your tenant.
2. If prompted, enter your username and password in the login window.
3. If you have multiple tenants, you will be directed My Qlik. From here, you can select the tenant you want to access. This page also displays any Talend tenants associated with your account.
4. Upon successful login, you will be directed to your default [activity center](#glossary-0 "Glossary term")'s Home.

   Tip note

   You can change which activity center you start in from your Settings.

## Getting status information on Qlik Cloud

Qlik makes data on uptime and incidents publicly available on [status.qlikcloud.com](http://status.qlikcloud.com/). Log in to take advantage of all available status information.

There, you are able to:

- See the current operational status, from fully operational, to degraded, to full outages.
- Review a history of past incidents beyond what is currently happening.

  Information noteLogin required.
- Subscribe to status updates.

  Information noteLogin required.
