# Exploring apps on a small screen

When you are using Qlik Sense on a small screen (480 pixels wide or smaller), you can make [selections](#glossary-0 "Glossary term") and navigate between apps, [sheets](#glossary-1 "Glossary term"), [visualizations](#glossary-2 "Glossary term"), and [stories](#glossary-3 "Glossary term"). You cannot create or edit sheets, stories, or visualizations. Performing [options menu](/en-US/cloud-services/Subsystems/Hub/Content/Sense_Hub/Sheets/sheet-view.htm#Options2) actions on a visualization is also unavailable.

This page discusses the process of using Qlik Sense on a small screen through a web browser. It is to be distinguished from using the Qlik Sense mobile app. For more information about using the mobile app, see [Qlik Sense Mobile SaaS](/en-US/cloud-services/Subsystems/Hub/Content/Sense_Hub/Mobile/qsmsaas-intro.htm).

### Navigating

The navigation panel at the top is used to reach your [activity centers](#glossary-4 "Glossary term"), application overview, and the help.
The navigation panel at the bottom is used to browse between sheets, stories and visualizations. You can hide the navigation panels to make more room for exploring your application. Going from portrait to landscape mode will provide more details in some situations.

### Discovering and analyzing

You can explore the sheets, and also go into detail and view each of the visualizations in full screen. You can navigate between the visualizations one at time and make selections in them. In full screen you also have access to the visual exploration menu at the top.

### Using Insight Advisor

Click ![Arrow down](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_arrow_down.svg) to switch between Sheet view and Insights. For more information on [Insight Advisor](#glossary-5 "Glossary term"), see [*Creating visualizations with Insight Advisor*](../Insights/insight-advisor-create-visualizations.htm).

### Using data storytelling

You can play the stories in an application, not edit them. When you are playing a story, you must go to sheet view to view the sheet and make selections.

### Using bookmarks

You can use existing [bookmarks](#glossary-6 "Glossary term") and create your own bookmarks.
