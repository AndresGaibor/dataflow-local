# Accessibility

Qlik Sense provides the following accessibility features:

- High-contrast color schemes available
- Keyboard navigation
- Keyboard shortcuts
- Screen reader support

## Using Qlik Sense with a screen reader

You can use a screen reader to interact with apps. You can use the screen reader in your [activity centers](#glossary-0 "Glossary term"), and in a [sheet](#glossary-1 "Glossary term") in analysis view.

The supported configuration is:

- [NVDA screen reader](https://www.nvaccess.org/download/) for Microsoft Windows and Google Chrome. The NVDA screen reader is a third party product and users are responsible to obtain their own license for the screen reader.
