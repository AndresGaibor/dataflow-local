# Navigation bar

Navigate quickly and use the tools your need in the application navigation bar. Your options depend on:

- Your permissions
- Whether you are developing an application or consuming an application
- The view that you are in, for example in a sheet or in a story

Navigation bar

![](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Navigation/ui_app-navigation-bar.png "Click to view full size")

In the navigation bar, you can:

- Click ![Qlik Sense SaaS navigation menu.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_grid_menu.svg) to navigate between [activity centers](#glossary-0 "Glossary term").
- Navigate between area of the application using the application navigation menu.

  The application navigation menu replaces the Analyze, Narrate, and Prepare tabs in the previous navigation bar.

  Application navigation menu

  ![Image of the menu on the app navigation](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Navigation/ui_app-navigation-app-nav-menu-rev.png "Click to view full size")
- Click ![App](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Navigation/app.svg) to open and close the application overview.
- Click ![](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) to perform actions based on the view you are in.

  In all sections of apps, the following are available:

  - Show details/Hide details

    Information note

    Details is not available for anonymous users.
  - Touch screen mode
  - Settings

  In Overview, Reporting, Data manager, and Data model viewer, the following are available:

  - Data catalog
  - Files and other source

  In Sheets, the following are available:

  - Make sheet public/Make sheet private
  - Subscribe to sheet
  - Create link to this sheet
  - Download sheet as PDF
  - Duplicate sheet
  - Delete sheet
  - Embed sheet

  In Storytelling, the following are available:

  - Make story public
  - Download story as PDF
  - Duplicate story
  - Delete story
- Click ![Question mark](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_help_outline.svg) to open the resource center.
- Click ![Bell](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_bell_outline.svg) to view notifications.
- Click your profile icon to open the profile menu and perform other tasks. For example, manage alerts, subscriptions, API keys, spaces, and [notifications](#glossary-1 "Glossary term").

  [*Managing your personal settings*](../Introduction/profile-settings.htm)

You can hide some options in the application navigation bar. For more information, see [*Hiding toolbar, sheet header, and application navigation bar options*](../Apps/style-app.htm#Hiding).
