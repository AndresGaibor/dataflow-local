# Interacting with the application interface

Whether you are using a desktop computer or a mobile device, you need to know how you can interact with the Qlik Sense user interface to get the most of your experience with it and find things easily.

Learn about the following:

- [Exploring apps on a small screen](explore-apps-on-small-screen.htm)

  Learn how you explore on small screens
- [Accessibility in Qlik Sense](accessibility.htm)

  Accessibility includes default color schemes with high contrast, keyboard navigation and shortcuts, and screen reader support.
- [Keyboard navigation and shortcuts in Qlik Sense](keyboard-navigation-and-shortcuts.htm)

  You can use a keyboard to navigate in the [activity centers](#glossary-0 "Glossary term"), the application overview, the toolbar, sheets, data, and visualizations.
- [Touch gestures](touch-gesture-keyboard-shortcut.htm)

  Qlik Sense supports touch gestures on mobile and hybrid devices .
- [Long-touch menu on touch devices](../Visualizations/long-touch-menu.htm)

  When you work on a touch device or a computer with a touch screen, you can long-touch a visualization to open an options menu..
- [Undoing and redoing actions](undo-redo.htm)

  When editing in sheet view or storytelling view you can undo or redo actions using the user interface or keyboard shortcuts.
