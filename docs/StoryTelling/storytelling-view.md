# Storytelling view

Tell [stories](#glossary-0 "Glossary term") to share your data insights with an audience.

Click Storytelling in the application navigation menu to create or open a story.

Storytelling view

![Storytelling view.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_gen_storytelling_slide-qcs.png "Click to view full size")

## Taking snapshots

Right-click on a [visualization](#glossary-1 "Glossary term") in a [sheet](#glossary-2 "Glossary term") to take a [snapshot](#glossary-3 "Glossary term"). The snapshot is saved to your snapshot library, which you can access from the sheet view or the storytelling view. You have to be in view mode to take a snapshot.

Take snapshot dialog

![Take snapshot dialog.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_gen_storytelling_take_snapshot.png "Click to view full size")

For information on adding a snapshot to a slide, see [*Adding a snapshot to a slide*](Slide/creating-a-slide.htm#Adding2).

## Using storytelling tools

Click a tool in the storytelling toolbar to add snapshot and effects to the slides in your story.

Storytelling toolbar

![Storytelling toolbar.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_gen_storytelling_toolbar-rev.png "Click to view full size")

Story tools

| UI item | Description |
| --- | --- |
| Snapshot | Snapshot library with all your taken snapshots. |
| Text | Text objects with different text styles. |
| Shapes | Shapes library with a variety of shapes. |
| Effects | Effects library with a set of visual effects to apply to your snapshots. |
| Image | Media objects with different types of media (such as images). |
| Sheets | Sheet library with sheets in the application which can be inserted as live data sheets in your story. |

Snapshot tools

| UI item | Description |
| --- | --- |
| Unlocked | Lock the snapshot. |
| Edit | Edit the snapshot.  For more information, see [*Editing slides*](Slide/editing-slides.htm) and [*Changing a snapshot's appearance*](Snapshots/change-snapshot-appearance.htm). |
| Snapshot | Replace the snapshot.  For more information, see [*Replacing a snapshot on a slide*](Slide/editing-slides.htm#Replacin). |

## Touch gestures in storytelling view

The table describes the touch gestures that are used for navigating in storytelling view.

Touch gestures for navigating in storytelling view

| Touch gesture | Description |
| --- | --- |
| Tap | Highlight a data point in a snapshot by applying an effect. |
| Double-tap | Edit a text object or an image. |
| Long-touch and release | Open the shortcut menu. |
| Long-touch and drag | Move a slide to a new location in the timeline.  Move an item on a slide. |
| Swipe | Scroll the list in the snapshot library.  Go to the next or previous slide when playing a story. |
