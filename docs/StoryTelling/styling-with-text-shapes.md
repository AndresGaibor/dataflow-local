# Styling with text and shapes

To make your [stories](#glossary-0 "Glossary term") compelling you can add stylistic elements. Text, hyper links and shapes are good examples.

In this section you fill find topics that help you style your insights. You can add and format elements by size, color, font style and more.

## Adding text to slides

You can add different styles of text to a story slide.

Do the following:

1. In storytelling view, click ![Text](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_text_object.svg).

   The Text objects dialog is opened.
2. Locate the text style you want to add and drag it onto the slide.

   The text object is placed on the slide and snaps to the grid. You can use the keyboard arrows to move it freely.
3. Double-click on the text object or click ![Edit](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_edit_outline.svg).
4. Type your text.
5. Click outside the text object or click ![Edit](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_edit_outline.svg).

The text is saved.

## Formatting text on slides

On a story slide you can change the format of your texts with the text formatting toolbar. You can change color, size, font style, and text alignment. Additionally, you have options for adding links and [bookmarks](#glossary-1 "Glossary term").

Text formatting toolbar for paragraph text object.

![Text formatting toolbar.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_gen_StorytellingToolbar_PS506.png)

Information noteTo enable a text object for formatting, you double-click on it.

### Changing font styles

Do the following:

1. Double-click on the text object you want to format, while in storytelling view. Or, click on the text object and click ![Edit](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_edit_outline.svg).

   The text formatting toolbar appears.
2. Select the text you want to style.
3. Click one or more of ![Text-Bold](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_bold.svg), ![Text-italic](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_italic.svg) and ![Text-Underlined](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_underline.svg).
4. Click outside the text object or click ![Edit](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_edit_outline.svg).

The font style of the text is changed.

### Changing font size of paragraphs

Do the following:

1. Double-click the Paragraph text object you want to format, while in storytelling view. Or, click on the text object and click ![Edit](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_edit_outline.svg).

   The text formatting toolbar appears.
2. Select the text you want to resize.
3. Click ![Arrow down](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_triangle_bottom.svg) next to the font size indicator and select a size: XS, S, M, L or XL.
4. Click outside the text object or click ![Edit](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_edit_outline.svg).

The font size of the text is changed.

### Changing font size of titles

Do the following:

1. Click the Title text object you want to format, while in storytelling view.
2. Drag one of the corners to change the font size.
3. Click outside the text object or click ![Edit](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_edit_outline.svg).

The font size of the text is changed.

### Changing text alignment of paragraphs

Do the following:

1. Double-click the Paragraph text object you want to format, while in storytelling view. Or, click on the text object and click ![Edit](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_edit_outline.svg).

   The text formatting toolbar appears.
2. Click in the text paragraph you want to align.
3. Click ![Align left](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_align_left.svg), ![Align right](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_align_right.svg) or ![Align center](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_align_center.svg).
4. Click outside the text object or click ![Edit](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_edit_outline.svg).

The text alignment is changed.

Information noteBy default, the text is left-aligned.

### Changing text color

Do the following:

1. Double-click the text object you want to format, while in storytelling view. Or, click on the text object and click ![Edit](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_edit_outline.svg).

   The text formatting toolbar appears.
2. Select the text you want to change color on.
3. Click ![Arrow down](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_triangle_bottom.svg) next to the color indicator in the toolbar.

   A color palette appears.
4. Click on a color in the palette.
5. Click outside the text object or click ![Edit](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_edit_outline.svg).

The color is applied to the text.

## Adding a shape to a slide

You can add different types of shapes on a slide.

Do the following:

1. In storytelling view, click ![Shapes](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_shapes_outline.svg).

   The shapes library is opened.
2. Locate the shape you want to use and drag it onto the slide.

   The shape is placed on the slide and snaps to the grid. You can use the keyboard arrows to move it freely.

The shape is placed on the slide.

## Formatting shapes on a slide

Using the shapes formatting toolbar you have the following options to format your shapes:

- Color

### Changing the color of a shape

Do the following:

1. In storytelling view, click the shape you want to format.

   A toolbar with color options appears.
2. Click the color square in the toolbar.

   A color palette appears.
3. Click a color.
4. Click outside the shape.

The color is applied to the shape.
