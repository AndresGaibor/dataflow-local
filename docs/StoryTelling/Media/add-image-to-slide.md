# Adding images to a slide

You can add an image to a [story](#glossary-0 "Glossary term") slide. You can use one of the default images, or an image of your own.

Do the following:

1. In storytelling view, click ![Image](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_image_outline.svg).

   The Media library opens.

   The following formats are supported: .png, .jpg, .jpeg, and .gif.When using Qlik Sense in Qlik Cloud, you upload images to the In app folder in the media library.
2. Select the image that you want to add to the slide.

   A preview of the image is shown.
3. Click Insert.

   Information noteAlternatively, right-click the image file you want to add and select Insert.

The image is added and snaps to the grid. You can use the keyboard arrows to move it freely.

Information noteIf the image is larger than the width or height of a slide, it will be re-sized to fit on the slide.
