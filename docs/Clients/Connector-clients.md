# SAP Connector clients

Qlik Cloud access SAP system data using different connector clients. Once a connection has been established, queries are defined to create the load scripts that retrieve the data from the SAP system.

You must have a valid Enterprise license that supports Qlik connectors for use with SAP NetWeaver. To access data, you need to have access credentials.

## Qlik Cloud

The following can be used with Qlik Cloud:

- SAP BW Connector
- SAP SQL Connector
- SAP Report Connector
