# Creating categories

Categories allow you to group and classify your terms. Once you have added your categories, you can add your terms.

Do the following:

1. Select the Terms tab.
2. Select Create >Category.

   Information note

   Your Qlik Cloud environment will not list the same users as the example environment, therefore you can select individuals that make sense for your environment.
3. Create the category Customer:

   1. Click Create new category.
   2. After Name, enter Customer.
   3. After Description, enter An entity (company or individual) that has or has had a financial purchase transaction with the organization.
   4. After Category Stewards, select a user from your Qlik Cloud environment.
4. Create the category Partner:

   1. Click Create new category.
   2. After Name, enter Partner.
   3. After Description, enter Any business partner who may be subject to or part of a contract. Partners can be suppliers, third party equipment and software providers, service providers, integration specialists, resellers, etc. Contracted partners have an active contract in place.
   4. After Category Stewards, select a user from your Qlik Cloud environment.
5. Create the category OEM:

   1. Click Create new category.
   2. After Name, enter OEM.
   3. After Description, enter OEM (original equipment manufacturer) partners are entities whose offerings can be embedded within proprietary products or applications.
   4. After Category Stewards, select a user from your Qlik Cloud environment.
   5. After Parent category, enter Partner.
6. Create the category Customer Contracts:

   1. Click Create new category.
   2. After Name, enter Customer Contracts.
   3. After Description, enter Contracts are formal and legally binding agreements between the corporation and one or more parties that detail certain rights and obligations.
   4. After Category Stewards, select a user from your Qlik Cloud environment.
   5. After Parent category, enter Customer.
7. Create the category Partner Contracts:

   1. Click Create new category.
   2. After Name, enter Partner Contracts.
   3. After Description, enter Contracts are formal and legally binding agreements between the corporation and one or more parties that detail certain rights and obligations.
   4. After Category Stewards, select a user from your Qlik Cloud environment.
   5. After Parent category, enter Partner.

Now that your categories are complete, you can add your terms.
