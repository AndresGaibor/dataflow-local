# Data flow processors

The following processors are available to build your data flow and prepare your data.

![Filter](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_filter.png)

### [*Filter processor*](data-flow-processor-filter.htm)

Filters data based on conditions

![Select fields](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_select_fields.png)

### [*Select fields processor*](data-flow-processor-select-columns.htm)

Renames and reorganizes your fields

![Join](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_join.png)

### [*Join processor*](data-flow-processor-join.htm)

Combines two flows based on one or more keys

![Map fields](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_apply_map.png)

### [*Map fields processor*](data-flow-processor-map-fields.htm)

Looks up values in a mapping table and replaces or adds a field

![Union](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_union.png)

### [*Union processor*](data-flow-processor-union.htm)

Appends records from a second flow

![Fork](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_fork.png)

### [*Fork processor*](data-flow-processor-fork.htm)

Duplicates the data into two identical outputs

![Aggregate](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_aggregate.png)

### [*Aggregate processor*](data-flow-processor-aggregate.htm)

Performs operations on groups of the data

![Sort](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_sort.png)

### [*Sort processor*](data-flow-processor-sort.htm)

Sorts the data based on given fields

![Remove fields](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_remove_fields.png)

### [*Remove fields processor*](data-flow-processor-remove-columns.htm)

Removes the selected fields

![Strings](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_strings.png)

### [*Strings processor*](data-flow-processor-strings.htm)

Performs string related operations

![Dates](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_date.png)

### [*Dates processor*](data-flow-processor-dates.htm)

Performs date related operations

![Math](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_numbers.png)

### [*Numbers processor*](data-flow-processor-numbers.htm)

Performs number related operations

![Math](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_math.png)

### [*Math processor*](data-flow-processor-math.htm)

Performs calculations on numbers

![Concatenate](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_concatenate.png)

### [*Concatenate fields processor*](data-flow-processor-concatenate.htm)

Merges the content of two fields

![Split](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_split.png)

### [*Split fields processor*](data-flow-processor-split.htm)

Splits fields using a separator

![Aggregate](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_cleanse.png)

### [*Cleanse processor*](data-flow-processor-cleanse.htm)

Fills or replaces fields with a given value

![Hash](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_hash.png)

### [*Hash processor*](data-flow-processor-hash.htm)

Hides the original data through hashing

![Calculate fields](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_calculate_fields.png)

### [*Calculate fields processor*](data-flow-processor-calculate-fields.htm)

Adds new fields based on Qlik script expressions

![Unpivot](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_unpivot.png)

### [*Unpivot processor*](data-flow-processor-unpivot.htm)

Unpivots table columns to rows

![Pivot](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_pivot.png)

### [*Pivot processor*](data-flow-processor-pivot.htm)

Pivots rows to table columns

![Window](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_window.png)

### [*Window processor*](data-flow-processor-window.htm)

Performs calculations on specific data ranges

![Script](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_script.png)

### [*Qlik script processor*](data-flow-processor-script.htm)

Creates or transforms inputs using Qlik script

![Table recipe](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_table_recipe.png)

### [*Table recipe processor*](data-flow-processor-table-recipe.htm)

Embed a table recipe to the data flow

![Sample](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Dataflow/ic_data_flow_processor_sample.png)

### [*Sample processor*](data-flow-processor-sample.htm)

Keeps only the first rows or a random subset of rows
