# Sort processor

Sorts the data based on given fields.

The Sort processor allows you to sort numeric or textual data from your fields by ascending or descending order.

## Usage

The Sort processor requires one input flow and can generate only one output flow.

## Properties

Properties to configure to perform operations on your fields.

Configuration

| Property | Configuration |
| --- | --- |
| Field | Select the field you want to sort on. Click the + icon to sort on another field. |
| Order | - Ascending: Sorts numerical data from 0 to 9, and alphabetical data from A to Z. - Descending: Sorts numerical data from 9 to 0, and alphabetical data from Z to A. |

To rename the processor or edit its description, point your mouse over the name or description to change in the Properties panel and click the ![Edit](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_edit_outline.svg) Edit icon.
