# Remove fields processor

Removes the selected fields.

The Remove fields processor allows you remove unwanted fields from your input records in a data flow.

## Usage

The Remove fields processor requires one input flow and can generate only one output flow.

## Properties

Properties to configure to delete fields.

Configuration

| Property | Configuration |
| --- | --- |
| Fields to remove | Select the input field you want to remove. You can add several fields to remove.  Information noteUsing the Select all checkbox to remove all the fields results in bad script. |

To rename the processor or edit its description, point your mouse over the name or description to change in the Properties panel and click the ![Edit](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_edit_outline.svg) Edit icon.
