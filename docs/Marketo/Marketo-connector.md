# Marketo

Connections to a Marketo database are made by selecting Marketo from the list of connectors in the Add data or Data load editor dialogs.

## Supported Marketo data types

The following Marketo data types are supported by the Marketo connector:

- Big Int
- Bit
- Currency
- Datetime
- Email
- Float
- Integer
- LongVarChar
- Percent
- Phone
- Reference
- Score
- String
- Textarea
- Type\_Date
- Type\_Timestamp
- URL
- VarChar
- WVarChar
