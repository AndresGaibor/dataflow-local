# Qlik Sense Desktop

Qlik Sense Desktop is a Windows app that allows you to create visualizations, charts, interactive dashboards and analytics applications for local and offline usage. Use Qlik Sense Desktop to try out and explore Qlik Sense, or use it for developing and testing applications in a contained environment, that is your local computer.

Applications you create in Qlik Sense Desktop can be exported and used in Qlik Cloud Analytics, Qlik Sense Enterprise, or by other Qlik Sense Desktop installations.
