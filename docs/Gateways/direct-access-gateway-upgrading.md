# Upgrading and uninstalling Qlik Data Gateway - Direct Access

This section explains how to upgrade your Direct Access gateway installation and lists the new features and enhancements for each version.

## Performing an upgrade

### Backing up your Direct Access gateway installation

It's recommended to back up important Direct Access gateway files before upgrading your installation.

To do this:

1. Do one of the following, depending on installation workflow:

   - Windows server installation:

     Stop the Direct Access gateway service.
   - Containerized installation:

     Stop the direct-access-agent container.
2. Do one of the following, depending on installation workflow:

   - Windows server installation:

     Back up all files (not subfolders) in [install folder]\data. The default location is C:\Program Files\Qlik\ConnectorAgent\data.

     This will back up the tenant configuration and gateway registration files for the current version.

     Warning note

     Do not save backups to C:\Program Files\Qlik as the contents of this folder might be cleaned during the upgrade.
   - Containerized installation:

     Back up all files (not subfolders) in /usr/data.
3. During the upgrade, the installer should create a copy of the existing configuration.properties file as follows. However, as a precaution, you might want to back up the configuration.properties file anyway.

   - Windows server installation:

     - Create a copy of the C:\ProgramData\Qlik\Gateway\configuration.properties file as C:\ProgramData\Qlik\Gateway\configuration.properties\_BK.
     - Consider also backing up the C:\ProgramData\Qlik\Gateway\configuration.properties file itself.

     Warning note

     Do not save backups to C:\Program Files\Qlik as the contents of this folder might be cleaned during the upgrade.
   - Containerized installation:

     - Create a copy of the /usr/share/Qlik/Gateway/configuration.properties file as /usr/share/Qlik/Gateway/configuration.properties\_BK.
     - Consider also backing up the /usr/share/Qlik/Gateway/configuration.properties file itself.
4. Once the upgrade completes, if you encounter issues related to the tenant configuration, follow the procedure in [*Restoring your Direct Access gateway installation*](#Restorin) below.

Warning noteIf problems arise during the upgrade, never delete the Direct Access gateway from the Administration activity center. Doing so will break all of your existing data connections, since you are registering a "new" gateway at that point as opposed to re-registering an existing gateway.

#### The upgrade procedure

Information noteThis section applies mainly to upgrades of gateways installed on a Windows server. For containerized Direct Access gateway, a new deployment of a newer version will automatically perform this upgrade.

To upgrade Direct Access gateway, simply download the setup file as described in [*Stage one: Download Qlik Data Gateway - Direct Access*](direct-access-gateway-setup-win.htm#Stage5), and then run the setup on the Direct Access gateway machine.

You can determine the installed Qlik Data Gateway - Direct Access version using the following methods:

- Go to Data gateways in Administration and check the Version column.
- Go to the Apps & features page in Windows Settings on the computer where it is installed.

  ![Version number of Qlik Data Gateway - Direct Access](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_DataGatewayVersion.png "Click to view full size")

#### Restoring your Direct Access gateway installation

Once the upgrade completes, if you encounter issues related to the tenant configuration, gateway registration, or gateway configuration (configuration.properties), stop the Direct Access gateway service, restore the backed up files to their original locations, and then start the Direct Access gateway service.

See also: [*Backing up your Direct Access gateway installation*](#Backing).

## Uninstalling Qlik Data Gateway - Direct Access

You can uninstall a Direct Access gateway that is no longer in use.

### Uninstalling Qlik Data Gateway - Direct Access gateways installed on a Windows server

Locate the gateway in the Windows Apps > Installed apps list and select Uninstall from the ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_catmore.svg) menu at the end of the row.

![Direct Access gateway in the Add/Remove programs list](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/add-remove-DAG.png)

Information noteUninstalling Direct Access gateway does not remove the configuration settings. In other words, if you uninstall one version of Direct Access gateway and then install a different version, the newly installed version will use the same configuration as the uninstalled version.

### Uninstalling containerized Qlik Data Gateway - Direct Access gateways

Do all of the following:

- Delete dcaas-dg container
- Delete direct-access-agent container
- Delete qlik-data-gateway-direct-access\_agent-data volume
