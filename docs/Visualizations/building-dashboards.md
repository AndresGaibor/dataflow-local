# Dashboard objects

When building your sheets and dashboards, you can use dashboard objects to format your sheets to best present the analytic information in other charts.

The following dashboard objects are available:

- ![Treemap](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_play.svg) Animator: You can animate changes in your [visualizations](#glossary-0 "Glossary term") over a period of time.

  [*Animator*](DashboardBundle/animator.htm)
- ![Button](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_button_outline.svg) Button: You can use buttons to add quick links for easy selection and navigation in your application.

  [*Button*](Button/button.htm)
- ![Date picker](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_calendar.svg) Date picker: You can select a single date or a range of dates from a calendar.

  [*Date range picker*](DashboardBundle/date-range-picker.htm)
- ![Select image](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_image_outline.svg) Image: Insert images directly onto the sheet.

  [*Image object*](Image/image-object.htm)
- ![](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_layout_container_outline.svg) Layout container: Add and arrange visualizations in a container.

  [*Layout container*](DashboardBundle/layout-container.htm)
- ![Line](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_line_object.svg) Line: Add vertical and horizontal lines to a [sheet](#glossary-1 "Glossary term").

  [*Line*](DashboardBundle/line.htm)
- ![Navigation menu](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_menu.svg) Navigation menu: The navigation menu adds a sheet navigation options into your sheet.

  [*Navigation menu*](Navigation-menu/navigation-menu.htm)
- ![Natural language insights](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_natural_language_generation.svg) NL insights: The NL insights visualization displays natural language insights about data in the form of a chart.

  [*NL insights*](NLInsights/nl-insights.htm)
- ![Slider](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_slider_outline.svg) Slider: Allow users to change the value of fields and variables during analysis.

  [*Slider*](Slider/slider.htm)
- ![Container box](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_box_outline.svg) Tab container: You can add visualizations in a limited space and show or hide the visualizations inside the container based on conditions.

  [*Tab container*](Container/container-object.htm)
- ![Text](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_text_object.svg)Text: You can use the text visualization to add text and links to webpages.
- ![Trellis container](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_grid_outline.svg) Trellis container: Creates a trellis chart based on a master [visualization](#glossary-2 "Glossary term").

  [*Trellis container*](VisualizationBundle/trellis-container.htm)
- ![](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_control_outline.svg) Variable input: You can set the value of a variable

  [*Variable input control*](DashboardBundle/variable-input.htm)
- ![Video player](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_video_outline.svg) Video player: You can add a video to your sheet.

  [*Video player*](DashboardBundle/video-player.htm)
