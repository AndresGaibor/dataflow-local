# Image object

Use the Image object to enhance your applications with image-based content.

Image object on sheet

![Image dashboard object added to sheet in analytics application](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_gen_image-dashboard-object.png "Click to view full size")

## When to use it

You can use the Image object to:

- Add external content and graphics to enhance understanding of data.
- Enhance the styling of your analytics applications.
