# Navigation menu

The navigation menu adds sheet navigation options into your sheet.

Users can navigate between sheets from the assets panel. You can also add a sheet navigation menu to allow users to navigate directly in the sheets, without needing to open the assets panel.

By default, the navigation menu displays all public sheets and groups in an application.

Navigation menu

![Navigation menu in a sheet, showing two sheets and a group.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_navigation-menu.png "Click to view full size")

You can choose to have the navigation menu open a drawer menu over the application. When this is selected, the navigation menu become an icon (![Menu icon](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_menu.svg)).

Drawer navigation menu

![Navigation menu with drawer styling.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_navigation-menu-drawer.png "Click to view full size")

## When to use the navigation menu

The navigation menu is useful when you want to provide an alternative method of navigating sheets in an application.

## Limitations

The navigation menu has the following limitations:

- The Qlik Analytics mobile app does not support navigation menus. If you are creating an application intended for a mobile audience, it is not recommended to include navigation objects.
