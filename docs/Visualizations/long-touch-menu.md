# Long-touch menu on touch devices

When you work on a touch device or a computer with a touch screen, you can long-touch a [visualization](#glossary-0 "Glossary term") to open an options menu.

You can toggle touch support on and off by clicking or tapping the application navigation button (![Navigation](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg)) and using the toggle for ![Touch screen mode](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_touch_outline.svg) Touch screen mode.

Menu options will be different depending on:

- Whether you are editing or analyzing (viewing) charts in an application.
- The chart type.
- The privileges that have been assigned to you by your administrator.
- Custom settings for visualization menus that have been configured by the application developer (see [*Hiding items in visualization menus*](../Apps/style-app.htm#HidingContext)).

The options menu opens when you long-touch a visualization.

- ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) Shortcut menu: View data, Monitor in activity centers, Share, Subscribe, Alerts, Download, and more.
- ![Expand](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_expand_3_outline.svg) Full screen
- ![Controls](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_control_outline.svg) Exploration menu
- ![Snapshot ](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_camera2.svg) Snapshot
- ![Snapshot ](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_photo_library_outline.svg) Snapshot library
- ![Linked Object](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_info_outline.svg) Visualization details
- ![Linked Object](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_link_outline.svg) Save as a master item or unlink from a master item (not shown)
