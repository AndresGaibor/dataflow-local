# Selections in straight tables

You can make [selections](#glossary-0 "Glossary term") in a straight table by clicking or drawing in the [dimension](#glossary-1 "Glossary term") columns.

Measure values cannot be selected. When you make a selection, it is always the dimension values that you select. You can only make selections in one column at a time.

To deselect a row, click it. To confirm a selection, click ![Checkmark ](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_tick.svg) or click outside the visualization. You can also press Enter. To cancel, click ![Cancel selection](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_cross.svg) or press Esc. If you confirm, the selection is reflected in all visualizations associated with the table.

You cannot select dimension values that are null. Null values in a table are presented as dashes (-). Rows without valid dimension values will not be included in the selection.

To view the selections applied to column, click ![Search](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_search.svg) in the column header, or click the column header and select ![Search](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_search.svg) Search.

Do one of the following, depending on chart accessibility settings:

- Click ![Search](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_search.svg) in the column header.
- Click the column header and select ![Search](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_search.svg) Search.
