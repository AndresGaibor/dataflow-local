# Creating straight tables

You can create a straight table on the sheet you are editing.

Do the following:

1. In the assets panel, open Charts.
2. Under Visualizations, drag a Straight table to the sheet.
3. In the chart, click one of the following:

   - Add columns: Add dimension and measure columns based on existing fields and master items.
   - Custom expression: Add a dimension or measure column based on custom formulas, using the expression editor.
4. In the properties panel, under Data, add additional columns:

   - Click ![Open Add data asset menu](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_add.svg) to add more dimensions or measures from existing fields or master items.
   - Click ![Open Expression editor](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_expression.svg) to add more dimensions or measures based on custom formulas, using the expression editor.
5. As needed, further manage the table data in the Data tab of the properties panel. You can:

   - Click the checkbox next to any item. Click ![Tools](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) or right-click an item to perform the following actions:

     - Move to top
     - Move to bottom
     - Hide
     - Show
     - Cut
     - Copy
     - Duplicate
     - Paste
     - Delete

     You can apply changes to multiple items by selecting them and then right-clicking on one of the selected items.

     Information noteHide and show actions are not available when both visible and alternative columns are selected.
   - Click ![Hide](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_view_outline.svg) or ![Show](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_view_disabled_outline.svg) on items to hide or show them—that is, to add and remove them from alternative columns. Hidden columns can be added when using [chart exploration](/en-US/cloud-services/Subsystems/Hub/Content/Sense_Hub/Visualizations/StraightTable/sn-straight-table-chart-exploration.htm).
   - Click ![Draggable column](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_draggable.svg) next to columns and drag them to reorder the columns in the table.
