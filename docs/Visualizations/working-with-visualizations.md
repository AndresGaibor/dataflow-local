# Working with visualizations

Visualizations let you present data so that your application's users can interpret and explore it. For example, a bar chart that compares sales numbers for different regions, or a table with precise values for the same data.

You can create visualizations yourself manually, developing your own charts and analyses. You can also create visualizations with assistance, letting Insight Advisor help build your visualizations.

## Creating visualizations manually in Qlik Cloud Analytics

Good visualizations help you quickly and accurately interpret displayed data. Visualizations are easy to add and customize. They can take the form of charts, such as bar charts, pie charts, tables, gauges, or treemaps. Each chart type has unique functionality. To learn more about the visualizations available in Qlik Cloud Analytics, see [*Choosing the right visualization*](creating-visualization.htm).

You can create visualization manually, adjusting the range of properties to customize your data presentation. For more information on creating visualizations, see [*Creating and editing visualizations*](create-visualizations-overview.htm).

You can also create visualizations by selecting the type of analysis you would like to see and then letting Qlik Sense choose the chart type. For more information, see [*Creating and editing analyses*](../Analyses/creating-analyses.htm).

## Creating visualizations with assistance

Insight Advisor offers several methods for assisted visualization creation:

- You can use Insight Advisor Search to generate visualizations based on your searches or selections. You can then choose to add these visualizations to your sheets. For more information, see:
  - [*Creating analyses using search*](../Insights/insight-advisor-create-visualizations.htm#Explorin).
  - [*Creating analyses by asset selection*](../Insights/insight-advisor-create-visualizations.htm#Selectin).
- You can use Insight Advisor Analysis Types to generate visualizations by picking the type of analysis you want to see and then selecting the fields. You can then choose to add these visualizations to your sheets. For more information, see [*Creating analyses by selecting analysis types*](../Insights/insight-advisor-create-visualizations.htm#Creating).
- You can create visualizations using Insight Advisor chart suggestions by dragging a field onto the sheet from the assets panel and then dragging additional fields that you want in the visualization onto the first field.
  Qlik Sense then creates a suggested visualization based on the fields selected for the visualization. For more information, see [*Creating visualizations using Insight Advisor chart suggestions*](creating-visualization-assistance.htm).
