# Use cases for write tables

The [write table](#glossary-0 "Glossary term") speeds up the process of gathering, presenting, and reacting to fast-changing analytics data. With the write table, you can greatly reduce the typical turnaround time for updating analytics dashboards, particularly for information that is time-sensitive and requires immediate action. These benefits are achieved by allowing users to make updates directly as they analyze data.
