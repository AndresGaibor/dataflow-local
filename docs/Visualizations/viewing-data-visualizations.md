# Viewing data of visualizations

You can change between a [visualization](#glossary-0 "Glossary term") and a view of the data it represents.

Viewing data presents the data used in the chart in a plain, high-contrast table. This offers an accessible option for viewing information in a chart that may not be designed with accessibility in mind. Viewing data is also useful when you need to take a look at data behind a selection in analysis mode. For most visualizations, a table containing their data is available through the context menu.

## Visualizations where data viewing is available

In the following visualizations you can change between the visualization and a view of its data in table form:

- Bar chart
- Box plot (excluding outliers)
- Bullet chart
- Combo chart
- Distribution plot
- Gauge
- Histogram
- Line chart
- Mekko chart
- Pie chart
- Pivot table
- Scatter plot
- Treemap
- Waterfall chart

Information note

Data viewing is not available for analyses, even if they are displaying a supported chart.

### Custom objects that support data viewing

The following charts, available from the Visualization bundle and Dashboard bundle, also support data viewing:

- Grid chart
- Org chart
- Pivot table (Visualization bundle)
- Variance Waterfall

### Data viewing for containers

Compatible charts within any of the following containers can also open in data view:

- Tab container
- Layout container

## Changing between visualization and data view

Do the following:

1. Right-click on the visualization or click the hover menu ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg).
2. Select View data. If a selection has been made only the selected data will be shown.
3. Right-click on the view of data and select View chart to go back to the visualization.

Information noteWhen you enter edit mode, or if you navigate to another [sheet](#glossary-1 "Glossary term") any visualizations changed to data view will change back to the original visualizations.
