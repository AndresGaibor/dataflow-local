# Searching in tables

In a table, you can search the [dimension](#glossary-0 "Glossary term") columns, and make [selections](#glossary-1 "Glossary term") in the resulting list.

Information note

The Straight table has replaced the Table as the default table visualization. Consider upgrading existing tables to straight tables for improved functionality and performance. For information about the straight table, see [*Straight table*](../StraightTable/sn-straight-table.htm).

Do the following:

1. Click ![Search](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_search.svg) in the dimension column that you want to search in.

   A selection popup is displayed with a list of all values of the [field](#glossary-2 "Glossary term"). This includes values that are excluded by selections. Excluded values are dark gray.
2. Type your search string. You can use any of the available search types. See [*Searching within selections or visualizations*](../../Selections/SelectionsToolbar/search-selections.htm).

   While you type, the list is filtered to only display matching items.
3. Make a selection by clicking or drawing.
4. Confirm your selection.

   Tip noteYou can confirm the selection of all matching items by pressing Enter.

The new selection is active and reflected in all associated [visualizations](#glossary-3 "Glossary term").

Tip noteYou can remove the search string by clicking ![Cancel selection](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_cross.svg) or pressing Esc. The search string is always removed when you press Enter.
