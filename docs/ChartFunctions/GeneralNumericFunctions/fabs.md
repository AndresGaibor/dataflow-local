# Fabs Script and chart function

Fabs() returns the absolute value of x. The result is a positive number.

Syntax:

fabs(x)

Return data type:  numeric

Examples and results:

Examples and results

| Examples | Results |
| --- | --- |
| fabs( 2.4 ) | Returns 2.4 |
| fabs( -3.8 ) | Returns 3.8 |
