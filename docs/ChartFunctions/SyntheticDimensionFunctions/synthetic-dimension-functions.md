# Synthetic dimension functions

A synthetic [dimension](#glossary-0 "Glossary term") is created in the app from values generated from the synthetic dimension functions and not directly from fields in the data model. When values generated by a synthetic dimension function are used in a [chart](#glossary-2 "Glossary term") as a calculated [dimension](#glossary-3 "Glossary term"), this creates a synthetic dimension. Synthetic dimensions allow you to create, for example, charts with dimensions with values arising from your data, that is, dynamic dimensions.

Information noteSynthetic dimensions are not affected by selections.

The following synthetic dimension functions can be used in charts.

Use the drop-down on each function to see a brief description and the syntax of each function. Click the function name in the syntax description for further details.

ValueList

ValueList() returns a set
of listed values, which, when used in a calculated dimension, will form a synthetic dimension.

[**valuelist**](valuelist.htm) (v1 {, Expression})

ValueLoop
