# Qlik Cloud interface overview

When you log into Qlik Cloud for the first time, you start on the Home page of your default [activity center](#glossary-0 "Glossary term"). Your activity center's Home page is your base. Depending on your permissions, you can navigate to other activity centers from the Navigation menu ![Navigation menu](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_grid_menu.svg).

You can find introductory content for Qlik Cloud Analytics by clicking ![navigation menu](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_grid_menu.svg) > Analytics > Getting started. Here you will find helpful resources to start using Qlik Cloud Analytics. These resources include tutorials, demos, and demo applications. Introductory content for Qlik Talend Data Integration is available from the Home page in the Qlik Talend Data Integration activity center.

Navigate to different activity centers from the navigation menu.

![Select the navigation menu to navigate to different activity centers](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_GettingStarted_LauncherMenu-rev.png "Click to view full size")

You can customize your settings as well as download additional tools in Settings. For more information, see [*Managing your personal settings*](../Introduction/profile-settings.htm) and [*Changing language in Qlik Cloud*](../UserInterface/Languages.htm).

Information note

Qlik Cloud supports keyboard navigation. For more information, see [*Keyboard navigation and shortcuts in Qlik Cloud*](../../Global_Common/HelpSites/keyboard-navigation-hub.htm).

## Activity centers

Activity centers provide logical groupings of Qlik Cloud Analytics and Qlik Talend Data Integration content based on user roles and activities. This replaces the previous platform hub experience in Qlik Cloud. Each activity center has its own Home and sections, with overlap for shared activities.

You can navigate between your activity centers from the Navigation menu ![Navigation menu](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_grid_menu.svg). Qlik Cloud users are increasingly using both Qlik Cloud Analytics and Qlik Talend Data Integration to take advantage of Qlik's unified end-to-end platform for real-time data integration and analytics.

You can only access the activity centers relevant to your user entitlement, roles, and space permissions. For example, if you have an Analyzer entitlement, you will only see the Insights activity center in Qlik Cloud. If you were given the Steward role and added to a shared space, you would then see the Analytics activity center as you can now create and upload glossaries.

Information noteThe functionality you see in Qlik Cloud depends on your user entitlement and the space permissions assigned to you. Content in screenshots may vary from what you see depending on your user entitlement and space permissions.

### Qlik Cloud Analytics

For users who build and explore data analytics applications, there are two activity centers:

- Insights: View analytic applications and other content. Explore data and make analyses.

  [*Insights activity center*](Insights-activity-center.htm)
- Analytics: Create applications and other analytic content. Analytics is available to users who have permission to create content in spaces.

  [*Analytics activity center*](Analytics-activity-center.htm)

For more information on Qlik Cloud Analytics, see [*Analyzing data*](../Introduction/analyzing-data.htm).

### Qlik Talend Data Integration

For users who deliver data to the cloud using data movement, transformations, and automated data pipelines, there is the Qlik Talend Data Integration activity center. This activity center is available by selecting Data Integration from the navigation menu. For more information, see [*Qlik Talend Data Integration activity center*](../NewNavigation/new-navigation-talend-data-integration.htm).

For more information on Qlik Talend Data Integration, see [*Integrating data*](../DataIntegration/Introduction/Data-services.htm).

### Administration

The Administration activity center is available for tenant administrators to manage spaces, user assignments, application and security settings, and other tenant configurations. Previously, this was called the Management Console.

For more information, see [*Accessing the Administration activity center*](../Admin/management-console.htm).

### Talend Cloud

If configured by your administrator, you will find a direct link to Talend Cloud on your navigation menu. Talend is an ETL (Extract, Transform, Load) platform that specializes in data integration, data quality management, data preparation, big data processing, and application integration. For more information, see [*Adding a direct navigation link to Talend Cloud*](../Admin/mc-administer-talend-link.htm).

### Search

You can search to find applications and other content, including terms and categories from business glossaries. As you enter your search terms, Qlik Cloud returns matching results. When you search, you can get a wider range of results for your search term in your applications and datasets by clicking ![AI icon](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_sparkle.svg)Show more results or pressing Enter. This provides a semantic search experience for applications and datasets, understanding context and intent, and can provide more accurate and meaningful results. Semantic searches also look for equivalent terms in other languages.

Semantic searches are only applied to application and dataset names and descriptions. Other content types will still be searched textually. You can also search textually for sheets and bookmarks from applications.

Information noteMatches from sheets and bookmarks to which users have access in Section Access applications will be listed, but only the application will be listed in the results.

You can filter your search results by type.

### Insight Advisor Chat (Insights and Analytics activity centers only)

You can interact with Insight Advisor Chat while navigating analytics content. Click Ask Insight Advisor in the navigation bar to open Insight Advisor Chat.

The chat window now opens as an overlay so you can continue your content navigation experience while maintaining the conversation with Insight Advisor Chat.

Click ![Pin](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_pin_outline.svg) to pin the Insight Advisor Chat chat window. Pinning the window resizes the entire page so that your navigation experience is optimized. Clicking ![Unpin](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_pin.svg) unpins the window.

Information note

Insight Advisor Chat is not available when a tenant is use the Qlik Answers agentic experience. Users can use Qlik Answers to explore applications with natural language.

### Notifications

You can receive notifications in the hub for events that occur in Qlik Cloud. For example, when new applications are added to a space or when an alert is triggered.
You can view them by clicking the Notifications icon (![Notifications](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_bell_outline.svg)). You can manage your tenant-level notifications in Settings. You can configure your notifications for an individual space by opening the space in Catalog and clicking Space settings > Notifications in Catalog. To configure your notifications for an individual item (for example, an application or a note), click ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) on the item, and select Notifications.

Notifications can be sent by web in the hub or by email. If you have the Qlik Analytics mobile app, web notifications can be pushed to your mobile device.

Information noteGroups cannot receive notifications. If you have been added to a space as a part of a group, you cannot receive notifications from that space.

Information noteEmail notifications require an email server configured for your tenant. If email notifications cannot be selected in Notifications, your tenant administrator may not have configured an email server.

To learn more about notifications, see [*Managing space notifications*](../Spaces/notifications-space.htm).

### Profile menu

The profile menu contains options to manage your personal settings, view helpful links, and log out.

Profile menu

![User profile menu](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Navigation/ui_user-profile-menu.png "Click to view full size")

Settings opens your personal settings. In the settings, you can:

- View and edit your preferences:

  - View the roles that are assigned to you.
  - Set your preferred activity center when you log in.
  - Set preferred language and time zone.
  - Set the regional settings (such as date formats and decimal formatting) for the applications you create.
- View and set your default notification preferences.
- View all the [shared](#glossary-1 "Glossary term") and [managed spaces](#glossary-2 "Glossary term") to which you belong.
- Manage your devices for Qlik Sense Mobile.
- Download tools such as Qlik DataTransfer.
- View and generate API keys.
