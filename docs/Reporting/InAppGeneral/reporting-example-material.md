# Examples - In-application reporting

This page is where you can download the application and source data materials that are used for the examples shown throughout the help documentation.

## What you need to do

1. Download the materials

   Download this package and unzip it onto your computer:

   [ReportingExampleMaterials](/en-US/cloud-services/tutorials/ReportingExampleMaterials.zip)
2. Upload the materials to Qlik Cloud

   Upload the application file Demo application - Qlik Cloud Reporting.qvf. Then, upload the five data source files for the application into the same space where you uploaded the application.

   [*Uploading applications*](../../Apps/uploading-apps.htm)

   [*Adding a data file to a space*](../../Spaces/manage-data-files-spaces.htm#UploadFile)
3. Reload the application in the Data load editor

   Open the application. In the [Data load editor](#glossary-0 "Glossary term"), click Load data. The application needs to be reloaded before you can view the visualizations and create reports.
4. Complete examples throughout the help

   You are ready to start using the application to complete [these examples](#Examples).
