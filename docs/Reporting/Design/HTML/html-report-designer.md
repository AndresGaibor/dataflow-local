# Navigating the HTML designer

The HTML designer is where you construct HTML [report templates](#glossary-0 "Glossary term"). The designer is embedded within Qlik Sense applications.

The HTML designer allows you to work with HTML code and integrate application content into your template.

The HTML designer

![An image of the HTML designer, showing all elements that need to be mentioned, such as the design surface, toolbar, and the objects panel](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_gen_report-designer-html.png "Click to view full size")

## Opening the HTML designer

You open the HTML designer by creating a new HTML template, or editing an existing one.

Do the following:

1. In your application, use the drop down menu in the navigation bar and select Reporting.
2. Switch to the Templates tab.
3. In the top right, click Create new > HTML template.
4. Enter a Name for the template.

The HTML designer opens.

## Designer toolbar

The designer toolbar is located at the top of the HTML designer. In the toolbar, you can:

- Easily add common HTML elements to your template, such as headers, paragraphs, and lists.
- Add external images to your template. For example, you can add your company logo.
- Add recipient tags. For more information, see [*Adding recipient placeholder tags*](html-report-recipient-tags.htm).
- Undo and redo actions, and adjust the zoom level.

For more information, see [*Adding standard HTML code to your template*](html-report-toolbar-actions.htm).

## Design surface

The design surface is shown in the center of the designer. This is where your template content is shown. It is a canvas where you add template content in the form of HTML code and references to application objects you have added in the objects panel.

## Objects panel

The objects panel is located on the right side of the designer. You use the objects panel to create and manage objects from the analysis application, and add them as content to the template. Resize the panel as needed.

You can access the following menus from the top of the objects panel:

- ![Home](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_home_2.svg): The home menu. This is where you start when you create your template.
- ![Tables](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_table_outline.svg): The Tables menu. This is where you add tabular data to the template.

  [*Adding tabular data to your HTML template*](html-report-tabular-data.htm)
- ![Chart object](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_chart_object_outline.svg): The Charts menu. This is where you add chart images to the template.

  [*Adding charts as images in your HTML template*](html-report-chart-images.htm)
- ![Variables](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_variables_outline.svg): The Variables and expressions menu. This where you add variables and expressions to the template.

  [*Adding variables and expressions to HTML report templates*](html-report-variables-expressions.htm)
- ![Levels and pages](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_layer_outline.svg): The Levels menu. This is where you add levels to the template, for iterations of filtered content.

  [*Looping and cycling HTML report elements with levels*](html-report-levels.htm)
