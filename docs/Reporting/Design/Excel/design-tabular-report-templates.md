# Designing tabular report templates

With [tabular reporting](#glossary-0 "Glossary term"), you can design Excel-based reports containing large, detailed datasets. You design these templates in the Qlik add-in for Microsoft Excel. Generated reports can be in .xlsx or PDF format.

Tabular report generated from Qlik Cloud Analytics

![Tabular report (.xlsx file) generated from a Qlik Sense app in Qlik Cloud Analytics](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_gen_CloudTabularReport.png "Click to view full size")

## What is tabular reporting?

Tabular reporting is built for spreadsheet-style report authoring and consumption. Using the Qlik add-in for Microsoft Excel, develop report templates based on your Qlik Sense application. When templates are ready, upload them into the Qlik Sense application for use in scheduled and on-demand reporting.

Data can be added in a number of ways, including:

- Chart images
- Column-level tabular data from a chart
- Variables defined in the source Qlik Sense application
- Expressions using the native Qlik Sense calculations
- Native Excel calculations applied to tabular data

You can loop the report elements over field and chart values, creating new filtered sections and worksheets based on these discrete values.
