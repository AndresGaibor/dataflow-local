# Working with levels and pages in tabular report templates

With levels and pages, you can automatically generate new sections and worksheets in your [tabular reports](#glossary-0 "Glossary term"). With levels and pages, a new filtered section or worksheet is generated for each unique value in a field, or row in a chart source table.

Levels and pages provide an additional layer of data filtering to reports, on top of the report filters you can apply in your Qlik Sense[report tasks](#glossary-1 "Glossary term"). You can use a combination of levels, pages, and [report filters](#glossary-2 "Glossary term") to generate highly customized and individualized report output. For information on report filters, see [*Working with report filters*](../../Generate/cloud-in-app-reports-filters.htm).

Click the ![Levels and pages](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_layer_outline.svg) icon on the top toolbar of the add-in to open the Levels and pages tab. This is where you add, modify, and delete level and page objects.

## Applies to

This content applies to designing [tabular report](#glossary-3 "Glossary term") templates using the Qlik add-in for Microsoft Excel. See [*Qlik add-in for Microsoft Excel*](../OfficeCommon/reporting-add-ins.htm#Excel).

Similar functionality exists for PowerPoint and Word templates, with some notable differences. For more information, see:

- [*Defining pages in PowerPoint report templates*](../PowerPoint/powerpoint-report-pages.htm)
- [*Adding levels to Word report templates*](../Word/word-report-levels.htm)

## Levels

Levels cycle report elements through all the distinct values of a field, or per row in the chart source table. Use levels to create sections in your report. Within a level, you add the content for which you want to have filtered, repeated sections.

You can use the following items as levels:

- Field: If you use a field as a level, a filtered section is added for each distinct value in the field.
- Chart: You can also use a chart as a level.

The following are examples of how you can use levels in the template:

- Create a level for a Year, YearMonth, or YearQuarter dimension. Within the level, nest tabular data with dimensions and measures like Product Group, Store Number, and Sales.
- For a report detailing support ticket progress, create a level for an Incident Status dimension. Within the level, nest tabular data with dimensions and measures like Ticket ID, Assignee, Ticket Opening Date, Ticket Closing Date, and Time Spent to Close.

### Adding a level

Do the following:

1. Click the ![Levels and pages](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_layer_outline.svg) icon on the top toolbar of the add-in. A list of any existing levels appears.
2. Click Add level.

   Levels and pages tab in Qlik add-in for Microsoft Excel. This tab allows you to add a new level or page, or revisit one you have already added.

   !['Levels and pages' tab an add-in, from which you can add/modify existing levels and pages you have added, or add a new one](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_gen_ExcelAddIn_AddLevel.png "Click to view full size")
3. Expand an item in the list. Your list will contain Fields, as well as each sheet containing compatible charts. Click the ![Plus symbol](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_add.svg) icon to the right of the item you want to use as a level.
4. After you click ![Plus symbol](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_add.svg), a list of field tags appears under Select fields to add (optional). In the generated report, the field tags appear in every section generated by the level tag. For more information about field tags, see [*Field tags*](#Field).
5. Click Add. The level tags are added to the currently selected area. Any field tags are inserted between the level tags.

   Level and field tags inserted into the template

   ![Level and field tags inserted into the template](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_gen_ExcelAddIn_AddLevelTags.png "Click to view full size")
6. After the level and field tags are inserted, move them around as needed and begin adding content inside the level.

   Report template modified to include additional tabular data within the level tags

   ![Report template with level and field tags moved around to fit more tabular data within the level](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_gen_ExcelAddIn_AddLevelConfigTags.png "Click to view full size")

Revisit any level object you have added at any point for modifications to its configuration, to locate it in the workbook, or to add another instance of it to the workbook. Click the ![Levels and pages](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_layer_outline.svg) icon in the add-in to open the Levels and pages landing page, and click ![Right-directional arrow](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_direction_right.svg) to navigate to the cell where it is inserted. Adjust any settings as needed in the add-in.

### Nesting levels

You can also create complex hierarchies by nesting levels within levels.

For example, let's say you nest a level by Country within a level by Year. Within the Country level, let's say you insert one chart image. In this case, the number of images generated in the report would be the distinct number of years, multiplied by the distinct number of countries. This example illustrates that without filters, you could easily exceed the limits of the cloud when nesting report elements inside one another.

Refer to [*Limitations for in-application reporting*](../../Reporting-service-specifications-limitations.htm#Limitati2) for a list of the limits that apply to using levels and pages.

## Pages

You can create different filtered Excel worksheets using pages.

Adding a page tag to a worksheet name will generate a separate, filtered page for each unique entity value linked to it. Data in each worksheet are filtered by the related value of the field or the source table row. You can create a page using the following items:

- Field: If you use a field as a page, you will have a worksheet for each distinct value in the field.
- Chart: You can also use a chart as a page. The chart can only have one dimension.

### Adding a page

You can use fields and compatible charts as pages.

Do the following:

1. Click the ![Levels and pages](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_layer_outline.svg) icon on the top toolbar of the add-in. A list of available level and page objects appears.
2. Click Add page.

Expand Fields, and click the ![Plus symbol](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_add.svg) icon to the right of the field you want to use as a page. Alternatively, if your application has a compatible chart, expand the section for the sheet on which it appears.

## Field tags

A field tag is a unique tag that can be added inside a level tag, or in a cell on a worksheet defined with a page tag. Field tags are not objects. Instead, they are elements within level and page objects, and they are optional.

For each field you are adding as the level or page, a field tag can optionally be added. The field tag displays the field value for each discrete entity on which the level or page is looping the data generation. Within a level or page, a field tag often functions as a section header, but it still contains tabular data.

Access the fields and field tags for a level or page by selecting the cell containing the level or page, and looking under Fields in the object's settings.

Field tags can be removed by deleting or clearing the area in which they have been added. Add a field tag back by clicking Add field tag under Fields in the object's settings.

A field tag can be set to Keep source formats, or this setting can be turned off to apply custom formatting and styling to the cell using the native Excel features.

## Removing a level or page

Like with any other object, you can remove a level or page from the [report template](#glossary-4 "Glossary term"), and from the list of that object type in the add-in pane.

Do the following:

1. Select the area where the object is located.
2. Click Delete in the bottom of the add-in window.

This removes the tags and the object from the corresponding object list.

If you instead use Excel features to delete a level or page, it will not be inserted in the generated report. However, the object will still appear in the list of added objects. This means you can easily re-add the object later.
