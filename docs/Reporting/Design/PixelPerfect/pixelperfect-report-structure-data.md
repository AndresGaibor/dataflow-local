# Defining report structure and data

You define the report structure by creating bands as needed, and arranging them according to the order in which you want to present them. You do not need to determine the exact structure of your report output from the beginning, but it can help in keeping things organized and avoiding formatting issues.

Apply levels to your reports if you need to repeat band content for each of the unique values in a dimension. To apply a level, you need to add a level data binding and connect a band to it.

For more information, see:

- [*Banded report authoring*](pixelperfect-banded-authoring.htm)
- [*Using a level to loop over application data*](pixelperfect-create-level.htm)
