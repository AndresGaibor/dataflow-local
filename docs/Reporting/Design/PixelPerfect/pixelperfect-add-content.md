# Adding content to your PixelPerfect report template

Add content to your PixelPerfect report template by adding objects onto the design surface. Generally, content can be added to the template by dragging objects from the toolbox panel (left side of designer), dragging objects from the ![Database icon with plus symbol](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_database_add.svg) Field List menu (expanded from right side panel), or by copying and pasting objects. Content also includes the [bands](/en-US/cloud-services/Subsystems/Hub/Content/Sense_Hub/Reporting/pixelperfect-banded-authoring.htm) that define the report structure.

Content can include:

- Bands
- Non-data-bound objects, such as custom fixed text, shapes, and lines
- Objects connected to data bindings
- Objects added for structuring and formatting output

## Workflow

This is the recommended workflow for adding content to your PixelPerfect report template. Generally speaking, the steps can be completed in order or as needed.

1. Define report structure using banded design.

   [*Defining report structure and data*](pixelperfect-report-structure-data.htm)
2. Add data bindings for the application data sources you want to incorporate in your report.

   [*Data binding*](pixelperfect-data-binding.htm)
3. Add objects. You will likely need to use a combination of non-data-bound and data-bound objects.

   [*Adding objects to your PixelPerfect report template*](pixelperfect-add-objects.htm)

   [*Arranging content in your PixelPerfect report template*](pixelperfect-arrange-content.htm)
4. Prepare the report for output, by adding page breaks, page numbers, report cover, table of contents, and more.

   [*Preparing your report template for output*](pixelperfect-prep-for-output.htm)

   [*Adding a table of contents*](pixelperfect-toc-bookmarks.htm)
