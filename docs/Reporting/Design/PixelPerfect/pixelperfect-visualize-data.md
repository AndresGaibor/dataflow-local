# Visualizing application data in your report

At the most basic level, you can incorporate application data into your PixelPerfect report by dragging objects onto the design surface from the toolbox or ![Database icon with plus symbol](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_database_add.svg) Field List menu. Depending on how you add an object and the outcome you want to achieve, it is often recommended that you follow specific workflows to achieve best results.

As you add objects to visualize application data, placeholders are shown in the PixelPerfect designer. To check how the content will look in output, you can generate previews from the PixelPerfect designer.
