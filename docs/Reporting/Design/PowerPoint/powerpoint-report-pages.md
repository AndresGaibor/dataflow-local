# Defining pages in PowerPoint report templates

Add pages to your PowerPoint report template to create separate, filtered slides in the report based on unique dimension values—or charts—from your application.

Pages are created in the add-in window, in the Levels and pages tab.

## Applies to

This content applies to designing PowerPoint report templates using the Qlik add-in for Microsoft PowerPoint.  See [*Qlik add-in for Microsoft PowerPoint*](../OfficeCommon/reporting-add-ins.htm#PowerPoint).

Similar functionality exists for Word and Excel templates, with some notable differences. For more information, see:

- [*Adding levels to Word report templates*](../Word/word-report-levels.htm)
- [*Working with levels and pages in tabular report templates*](../Excel/add-in-excel-levels-pages.htm)

## Adding a page

Adding a page tag to a PowerPoint slide will generate a separate, filtered slide for each unique value or chart row linked to it. Data in each slide are filtered by the related value of the field, or row in the chart source table. You can create a page using the following items:

- Field: If you use a field as a page, you will have a worksheet for each distinct value in the field.
- Chart: You can also use a chart as a page.

Do the following:

1. Click the ![Levels and pages](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_layer_outline.svg) icon on the top toolbar of the add-in. A list of available page objects appears.
2. Click Add page.

   Levels and pages tab in Qlik add-in for Microsoft PowerPoint. This tab allows you to add a new page object, or revisit one you have already added.

   !['Levels and pages' tab, from which you can add/modify existing pages you have added, or add a new one](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_gen_PowerPointReport_AddPage.png "Click to view full size")
3. Expand an item in the list. Your list will contain Fields, as well as each sheet containing compatible charts. Click the ![Plus symbol](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_add.svg) icon to the right of the item you want to use as a page.

   In this example, the page tag will create a new section for each unique City value in the application.

   Select a field or chart to use as the page

   ![Expanding the 'Fields' section of the 'Add level' workflow, select a field to use for the level](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_gen_PowerPointReport_AddPageFields.png "Click to view full size")
4. After you click ![Plus symbol](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_add.svg), a list of field tags appears under Select fields to add (optional). If you choose to include the field tag, it will be inserted at your current position on the slide. In the generated report, the field tag will appear on every slide generated by the page tag. It will display the field value to which the page applies. For more information about field tags, see [*Field tags*](#Field).
5. Optionally, edit the Slides property if you want to use more than one slide per unique item in the page. For more information, see [*Customizing the Slides property*](#Slides).
6. Click Add. The following occurs:

   - The current slide becomes a page object. The slide is tagged as a page, but the tag itself is not visible.
   - Any field tags you selected are added to the slide, and are visible.

With some adjustments and the addition of a chart image, report output might look like the following. A new slide is generated for each city.

Revisit any page object you have added at any point for modifications to its configuration, to locate it in the presentation, or to add another instance of it. Click the ![Levels and pages](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_layer_outline.svg) icon in the add-in to open the Levels and pages landing page, and click ![Right-directional arrow](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_direction_right.svg) to navigate to the slide where it is inserted. Adjust any settings as needed in the add-in.

### Customizing the Slides property

With the Slides property, you can have more than one page field in a presentation, but on separate slides.

Example:

You have a Year field that covers 2023, 2024, and 2025. You can add the Year field on the first slide, but have each Year span over three slides.

To achieve this, you can type 1-3 for the Slides property.

In this example, the result will be:

- Slide 1 - 2 - 3: filtered for 2023
- Slide 4 - 5 - 6: filtered for 2024
- Slide 7 - 8 - 9: filtered for 2025

## Field tags

In the Qlik add-in for Microsoft PowerPoint, a field tag is a unique tag that can be added to a slide that is defined as a page tag. Field tags are not objects. Instead, they are elements within page objects, and they are optional.

For each field or chart you are adding as a page, a field tag can optionally be added. The field tag displays the field value (or chart row) for which the page is looping the data generation. Within a page, a field tag often functions as a section header, but it still contains tabular data.

To see the fields and field tags for a page, open the Levels and pages tab in the add-in, and click ![Right-directional arrow](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_direction_right.svg). Expand Fields in the page's settings.

Field tags can be removed by deleting or clearing the area in which they have been added. Add a field tag back by clicking Add field tag under Fields in the object's settings.

A field tag can be set to Keep source formats, or this setting can be turned off to apply custom formatting using native Microsoft PowerPoint features.

## Removing a page

Like with any other object, you can remove a page from the [report template](#glossary-0 "Glossary term"), and from the list of that object type in the add-in pane.

Do the following:

1. Click the ![Levels and pages](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_layer_outline.svg) icon on the top toolbar of the add-in.
2. Click ![Right-directional arrow](../../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_direction_right.svg) next to the page object.
3. Click Delete in the bottom of the add-in window.

This removes the tags and the object from the corresponding object list.

If you instead use PowerPoint features to delete a page object, it will not be inserted in the generated report. However, the object will still appear in the list of added objects. This means you can easily re-add the object later.
