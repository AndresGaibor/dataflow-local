# Designing report templates

You can create report templates in a variety of formats. After you create your template, use it in report tasks to generate and distribute output, or activate it for on-demand reporting so application consumers can generate reports as they analyze sheets.

## Tabular report templates

Create Excel templates to generate tabular reports in .xlsx or PDF format.

Report templates for tabular reporting are created with the Qlik add-in for Microsoft Excel.

For more information, see [*Designing tabular report templates*](Excel/design-tabular-report-templates.htm).

## PixelPerfect templates

Create PixelPerfect templates directly within your Qlik Sense application using the PixelPerfect designer. Reports generated from a PixelPerfect template are in PDF format.

For more information, see [*Designing PixelPerfect report templates*](PixelPerfect/design-pixelperfect-templates.htm).

## HTML templates

With HTML reporting, you can embed HTML report output directly into email messages, in addition to generating and sending HTML report files.

For more information, see [*Designing HTML report templates*](HTML/design-html-reports.htm).

## PowerPoint templates

Author report templates in Microsoft PowerPoint format, for example to incorporate into slideshows. PowerPoint templates are created with the Qlik add-in for Microsoft PowerPoint.

Generated reports can be in .pptx or PDF format.

For more information, see [*Designing PowerPoint report templates*](PowerPoint/powerpoint-report-template.htm).

## Word templates

Author report templates in Word format using the Qlik add-in for Microsoft Word.

Generated reports can be in .docx or PDF format.

For more information, see [*Designing Word report templates*](Word/word-report-template.htm).
