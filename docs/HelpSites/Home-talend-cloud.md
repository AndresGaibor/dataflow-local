# Talend Cloud documentation

Talend Cloud provides web-based interfaces to design, manage, and monitor integration capabilities. It also includes Talend Studio.

[Release Notes](https://help.qlik.com/talend/en-US/release-notes/)[Key features video summary](https://www.youtube.com/watch?v=6zXDKxJxtgU)[Migrate to Qlik Cloud](/en-US/migration/Content/Migration/Home.htm#QCA)

Talend Cloud is a data integration cloud platform built to handle a wide range of use cases, from basic data replication to advanced big data transformations.

### [Talend Dynamic Engine Configuration Guide](https://help.qlik.com/talend/en-US/dynamic-engine-configuration-guide/Cloud/)
