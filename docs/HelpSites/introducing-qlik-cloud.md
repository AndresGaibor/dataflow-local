# Introducing Qlik Cloud

Welcome to the Qlik Cloud Data Integration and Analytics platform—a single-solution modern data stack with capabilities to move enterprise data from on-premises and cloud sources to Qlik's hosted self-service analytics solutions and other analytics environments.

Qlik Cloud is available in multiple subscription options to meet different customer needs, including the U.S. Public sector. For details about hosting locations and data residency, see [Qlik Cloud Regions](https://www.qlik.com/us/regions).

Qlik Cloud Government is only available for the U.S. Public sector. It differs from Qlik’s commercial Qlik Cloud offering due to the security protocols required to support the U.S. Public sector. Wherever possible, Qlik keeps both platform offerings in sync for product features and capabilities. For more information, see [*Qlik Cloud Government overview*](about-qs-government.htm).

## Qlik Cloud Analytics

Qlik Cloud Analytics, a hosted service, sets the benchmark for third-generation analytics platforms, empowering everyone in your organization to make data-driven decisions. Built on Qlik's unique Associative Engine, it lets you search and explore across all your data, revealing insights that can be missed with query-based tools. The Qlik engine supports self-service analytics, interactive dashboards, conversational analytics, custom and embedded analytics, mobile analytics, reporting, and alerting. For more information, see [*Analyzing data*](../../Sense_Hub/Introduction/analyzing-data.htm).

### Qlik Cloud Analytics subscription options

All analytics subscriptions bring the power of Qlik’s third-generation analytics platform to groups, teams, and businesses that want to quickly operationalize analytics and make data-driven decisions. You can easily co-develop applications and share insights, and grant groups of users access to create, edit, or interact with content.

Qlik Cloud Analytics is available in multiple subscription tiers. Tiers vary by features, capacity, and limits. Subscriptions use a [capacity model](../../Sense_Hub/Admin/subscription-options-qlik-cloud.htm) that is primarily measured by the volume of data available for analysis in Qlik Cloud. For details, see [Qlik Cloud Analytics subscription options](/en-US/cloud-services/Subsystems/Hub/Content/Sense_Hub/Admin/subscription-options-analytics.htm) or visit [Qlik Pricing](https://www.qlik.com/us/pricing).

Qlik Sense Enterprise SaaS and Qlik Sense Business subscriptions are user-based and are primarily measured by the number of users. For more information about these subscriptions, see [*Qlik Cloud user-based subscriptions*](../../Sense_Hub/Admin/subscription-options-analytics-user-based.htm).

## Qlik Talend Data Integration

Qlik Talend Data Integration provides the ability to create data pipelines to perform a variety of data integration tasks in support of your data architecture and analytics requirements.

The refined data output from Qlik Talend Data Integration can be used for many purposes:

- Loading and ingesting data to a centralized data warehouse.
- Data mining.
- Automated creation of data for analytics in the cloud.
- Modernization of your data repository to support Machine Learning and other initiatives.

For more information, see [*Integrating data*](../../Sense_Hub/DataIntegration/Introduction/Data-services.htm).

### Qlik Talend Data Integration subscription options

Qlik Talend Cloud combines the capabilities of Qlik Talend Data Integration and Talend Cloud. It is available through multiple subscription options that vary by capabilities, such as supported data sources and transformations, governance, AI, and deployment capabilities. All subscriptions include access to default analytics capabilities in Qlik Cloud.

For more details on what is included in the subscriptions, see [Qlik Talend Cloud subscription options](/en-US/cloud-services/Subsystems/Hub/Content/Sense_Hub/Admin/subscription-options-QTC.htm), or [*What is Qlik Talend Cloud*](Talend-capabilities.htm).

## Qlik Talend Data Integration and Qlik Cloud Analytics: How they work together

The combination of data movement and transformation with integrated analytics represents a holistic and comprehensive enterprise data life-cycle. Qlik Talend Data Integration delivers data with unified metadata and lineage into the metadata catalog in a readily consumable format for immediate application creation and analysis. Cloud and enterprise data sources are securely transferred through automated data pipelines created, managed, and monitored within Qlik Cloud.

Qlik Automate provides a no-code visual interface that helps you easily build automated analytics and data workflows. For more information, see [Qlik Automate](/en-US/cloud-services/Subsystems/Hub/Content/Sense_QlikAutomation/introduction/home-automation.htm).

## Reporting

A number of options are available for report developers to deliver customized, burst reports of Qlik Cloud Analytics data to internal and external stakeholders.

The Qlik Reporting Service is a value-add set of services within a Qlik Cloud subscription that provides enterprise-scale reporting capabilities from Qlik Cloud. On a smaller scale, business users can also generate scheduled subscriptions to charts and sheets in a Qlik Sense application.

To learn more, see [Reporting from Qlik Cloud Analytics](/en-US/cloud-services/Subsystems/Hub/Content/Sense_Hub/Reporting/SaaS-reporting-intro.htm).

## Qlik Answers

A plug-and-play generative AI (GenAI) add-on subscription that adds knowledge assistants for Qlik Cloud.

Qlik Answers assistants provide a chat interface for asking questions and getting personalized, relevant answers using GenAI from the unstructured data sources to which they are connected. Answers are sourced using retrieval augmented generation (RAG) from curated knowledge bases of unstructured data, ensuring the responses are relevant to a user's needs.

To learn more, see [*Qlik Answers*](../../Sense_Hub/QlikAnswers/Qlik-Answers.htm).
