# Qlik documentation feedback

The Qlik Technical Documentation group takes great pride in developing content to help the Qlik Cloud user community gain insights, empower teams, and lead data-driven transformation.

Each page on [help.qlik.com](https://help.qlik.com/) provides you an opportunity to rate the topic. You can also provide suggestions, comments, or improvement ideas. We appreciate you taking the time to send us feedback, and we’ll use it to improve the content.

Information noteIf you’re interested in providing product feedback or suggestions, visit [Qlik Ideation](https://community.qlik.com/t5/Suggest-an-Idea/idb-p/qlik-ideas).
