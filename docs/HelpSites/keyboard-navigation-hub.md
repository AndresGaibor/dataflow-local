# Keyboard navigation and shortcuts in Qlik Cloud

Qlik Cloud supports keyboard accessibility. You can use a keyboard to navigate in your [activity centers](#glossary-0 "Glossary term"), the application overview, the toolbar, sheets, data, and visualizations.

For information on keyboard navigation in applications, see [*Keyboard navigation and shortcuts in apps*](../../Sense_Hub/UserInterface/keyboard-navigation-and-shortcuts.htm).

Keyboard controls in Qlik Cloud activity centers

| Keyboard navigation | Description |
| --- | --- |
| Tab | Moves focus forward. In an active menu, Tab will cycle between the menu options. |
| Shift + Tab | Moves focus back. |
| Up + down arrows | Shifts through a vertical list in focus, such as list view. |
| Enter or Space | Selects or enters the item in focus. In the tab navigation menu, press Enter or Space a second time to open the drop-down menu. |
| Esc | Closes a dialog or context menu. |
