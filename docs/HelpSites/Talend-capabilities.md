# What is Qlik Talend Cloud

Qlik Talend Cloud combines the capabilities of Qlik Talend Data Integration, Talend Cloud, and Talend Studio. Talend capabilities are available in the Premium, and Enterprise tiers of Qlik Talend Cloud.

This page presents all available capabilities, for more detailed information about availability, see [Qlik Talend Cloud subscription options](/en-US/cloud-services/Subsystems/Hub/Content/Sense_Hub/Admin/subscription-options-QTC.htm).

## [Introducing Qlik Talend Data Integration](/en-US/cloud-services/Subsystems/Hub/Content/Sense_Hub/DataIntegration/Introduction/Data-services-introduction.htm)

Create data pipelines to perform a variety of data integration tasks in support of your data architecture and analytics requirements. You can also streamline your data management using data products.

## [Getting started with Qlik Talend Data Integration](http:///en-US/cloud-services/Subsystems/Hub/Content/Sense_Hub/DataIntegration/Introduction/Getting-started-QTC.htm)

Learn more about the first steps of setting up your tenant and getting started with data integration capabilities in Qlik Talend Data Integration.

## [Platform engines](https://help.qlik.com/talend/en-US/management-console-user-guide/cloud/tmc-engines)

Talend Cloud platform engines provide computational capabilities that allow organizations to securely run data integration processes natively from cloud to cloud, on-premises to cloud, or cloud to on-premises environments.

## [App integration](https://help.qlik.com/talend/en-US/studio-user-guide/designing-jobs-and-routes)

Talend Studio app integration lets you share services and trusted data across internal departments and external groups with user-friendly APIs, using jobs and routes.

## [API design](https://help.qlik.com/talend/en-US/api-designer-user-guide/Cloud/api-design)

Create secure, user-friendly APIs to open your platform to new business opportunities, implement a microservice architecture, and validate API behavior with Talend Cloud API Designer - all in the cloud.

## [API testing](https://help.qlik.com/talend/en-US/api-tester-user-guide/Cloud/introduction-to-api-tester)

Create complex scenarios that emulate real-life uses of your API: combine multiple API requests, or reuse data from previous responses with Talend Cloud API Tester.

## [Big data](https://help.qlik.com/talend/en-US/studio-user-guide/8.0/big-data)

Handle big data easily by leveraging Hadoop and its databases or technologies such as HBase, HCatalog, HDFS and Hive with Talend Studio Big Data.

## [Data mapping](https://help.qlik.com/talend/en-US/data-mapper-user-guide/8.0/what-is-talend-data-mapper)

Talend Data Mapper allows you to map complex data records and documents and execute transformations.

## [Data preparation](https://help.qlik.com/talend/en-US/data-preparation-user-guide/Cloud/about-talend-cloud-data-preparation)

Talend Cloud Data Preparation is a self-service application that simplifies preparing data for analysis or other data-driven tasks.

## [Data stewardship](https://help.qlik.com/talend/en-US/data-stewardship-user-guide/Cloud/talend-cloud-data-stewardship-introduction)

Talend Cloud Data Stewardship lets you manage data assets to organize the interactions on data required to collaborate on data curation, arbitration or validation.

## [Data quality](https://help.qlik.com/talend/en-US/studio-user-guide/8.0-R2024-07/profiling-and-data-quality)

Talend Studio Data Quality profiles, cleans, and masks data in real time. Machine learning powers recommendations for addressing data quality issues as data flows through your systems.
