# Qlik Talend Data Integration activity center

The Qlik Talend Data Integration activity center provides options for delivering data ready to Qlik Cloud or to cloud data warehouses. It combines the previous Home with Getting started, and includes new options and features.

Overview of the Qlik Talend Data Integration activity center

![Qlik Talend Data Integration activity center](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Navigation/qtdi-home.png "Click to view full size")

## Home

In Home, you can view getting started content, creation options, recently modified objects, and notifications. Home also includes a learning path for getting started and understanding Qlik Talend Data Integration.

Home section of Qlik Talend Data Integration

The creation options in Home replace the options that were previously available from the Add new button in the old navigation bar. You can also create Data Integration content from the individual sections.

## Data marketplace

In Data marketplace, you can consume data products to use them as sources in your analytic content. Data products allow you to gather and package trusted datasets related to the same domain.

For more information, see [*Working with data products*](../DataIntegration/DataProducts/Data-products.htm).

## Create

The Create page provides all options for creating data integration content in Qlik Talend Cloud. Click the content you want to create or upload. Click Learn more to read a description of the content, with links to the helpsite.

## Catalog

In Catalog, you can view the data products, applications, and spaces to which you have access, as well as other analytic content.

Catalog allows you to filter on:

- Spaces
- Search terms
- Content types:
  - Charts
  - Applications
  - Datasets
  - Scripts
  - Notes
  - Links
  - Automations
  - ML deployments
  - ML experiments
  - Glossaries
  - Assistants
  - Knowledge bases
  - Data products
- Owners
- Creators
- Tags

You can select individual spaces from the spaces drop-down to view content from that space. Select All filters to display the filter pane. When the filter pane is active the All filters box is grayed out. The box displays the number of active filters.

You can view content in either the Tile ![Select tile icon for tile view](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ic_profile_tile.svg) or List ![Select list icon for list view](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ic_profile_list.svg) view.

Applications and other content can be sorted alphabetically, by creation date, by modification date, or recently used. You can filter content by those you own or by those others own.

To learn more about Catalog, see [*Understanding your data with catalog tools*](../Catalog/catalog-overview.htm).

## Data quality

In Data quality, you can take a look at several parts of the overview of a dataset to learn more about its overall quality, its schema, the quality statistics, and semantic types of each columns.

For more information, see [*Assessing data quality*](../DataIntegration/DataProducts/Data-quality-and-data-discovery.htm).

## Data products

In Data products, you can create, activate, and modify data products. Data products allow you to gather and package trusted datasets related to the same domain.

For more information, see [*Working with data products*](../DataIntegration/DataProducts/Data-products.htm).

## Pipeline projects

In Pipeline projects, you can create and manage data pipelines and data replication tasks.

- Data pipelines move data into a project from data sources that are on-premises or in the cloud, and store the data in datasets. Transformations can be performed on your pipelines and you can create data marts to leverage your generated and transformed datasets. For more information, see [*Creating and managing data pipeline projects*](../DataIntegration/Introduction/Data-projects.htm).
- Data replication tasks efficiently and securely move data between supported data sources and targets. Data replications can replicate data or land data in a data lake. For more information, see [*Creating a replication project*](../DataIntegration/Replicating/data-replication-task.htm).

Information noteThe Modified column in list view shows when general project information, such as Name or Description, was modified. It does not relate to changes in tasks in the project.

## Monitor views

In Monitor views, you can monitor and operate the status and progress of your data tasks. Monitor views let you view and monitor the status of a subset of the data tasks that you have access to in the tenant, based on a filter. You can create several views to monitor different aspects of your data pipelines.

For more information, see [*Monitoring an individual data task*](../DataIntegration/Introduction/Monitoring-data-tasks.htm).

## Connections

In Connections, you can create and manage connections to data sources, such as SaaS applications and databases, and targets, such as data warehouses, cloud storage, and databases.

For more information, see [*Setting up spaces and connections*](../DataIntegration/Introduction/Settingup-spaces-connections.htm).

For more information, see [*Setting up connections*](../DataIntegration/Introduction/Sources-and-targets.htm).

## Lakehouse clusters

In Lakehouse clusters, you create and manage network integrations and lakehouse clusters for your Qlik Open Lakehouse projects.

- A network integration is a prerequisite for creating Qlik Open Lakehouse pipeline projects. The integration connects to your AWS-based VPC and you configure permissions to allow Qlik to manage resources on your behalf.
- A lakehouse cluster is created as part of the network integration setup, and you can also create new lakehouse clusters.

For more information, see [*Managing network integrations and lakehouse clusters*](../DataIntegration/Lakehouse/Managing-integration-clusters.htm).

## Automations

In Automations, you can view, create, and test automations. You require the Automations Creator role to create automations.

For information, see [Qlik Automate](/en-US/cloud-services/Subsystems/Hub/Content/Sense_QlikAutomation/introduction/home-automation.htm) and [*Automating your data workflow*](../DataIntegration/Introduction/Automate-data-workflow.htm).

## Talend

Under Talend, you can access Talend Management Console services from Qlik Cloud for Qlik Talend Cloud subscription.

For more information, see [Administering Talend Management Console in Qlik Cloud](https://help.qlik.com/en-US/cloud-services/Subsystems/Hub/Content/Sense_Hub/Admin/administer-tmc-from-qc.htm).
