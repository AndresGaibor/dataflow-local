# How to change the number of loaded rows in your table

You can configure how many rows of your source dataset you want to display in Table recipe.

Use the Rows settings button in order to reduce the number if you want to work on a smaller sample, or to increase the number if the default setting is too low:

1. Click the Rows settings button.
2. In the Rows to load field, enter the new value.
3. Click Load

![Entering a new value for the number of rows to load in table recipe](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/TableRecipe/table_recipe_how_to_change_number_rows.png)

The table reloads an you can work on your preferred sample size.
