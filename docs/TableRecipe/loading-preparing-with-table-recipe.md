# Loading and preparing data with Table recipe

A table recipe allows you to easily prepare tabular datasets within a no-code, spreadsheet-like interface. Iteratively explore, clean, and transform data through a series of reusable steps to produce a recipe.

Work on a sample of your single table and choose from more than 50 functions to apply at the column level. You can choose among functions tailored for strings, numbers or date data types, and benefit from profiling information.

Table recipe also provides built-in data quality features to help you detect and correct invalid or inconsistent values, with quality indicators in column headers and cells, and quick actions to filter or apply functions to valid, invalid, empty, or null values.

Run the resulting recipe to output the clean data to your catalog. If the source data is modified, easily run your recipe again for always up to date data.
