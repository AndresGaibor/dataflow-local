# Tutorial - Build an analytics application

In this tutorial, you will build a Qlik Sense application in Qlik Cloud Analytics. You will add data, create [charts](#glossary-1 "Glossary term"), and build a storytelling presentation.

## What you will learn

Once you have completed this tutorial, you will understand the different steps involved in building an application, including creating [visualizations](#glossary-2 "Glossary term") with Insight Advisor. You will also learn principles of application design.

## Who should complete this tutorial

Users who are familiar with the basics of Qlik Cloud Analytics. You know how to make [selections](#glossary-3 "Glossary term") and how to interpret those results.

## What you need to do before you start

You need:

- Access to Qlik Cloud Analytics.
- If you have a user-based subscription, you need Professional user entitlement. To find out what type of user you have, contact your tenant administrator. For more information, see [*Managing user entitlements*](../Admin/SaaS-user-allocations.htm).
- Permissions for accessing Insight Advisor in applications. These permissions are set by your tenant administrator. For more information, see:

  - [*Default permissions and custom roles*](../Admin/permissions-scopes-capacity-model.htm) (capacity-based subscriptions)
  - [*Default permissions and custom roles*](../Admin/permissions-scopes.htm) (user-based subscriptions)
  - [*Default permissions and custom roles*](../Admin/permissions-scopes-anonymous.htm) (Qlik Anonymous Access subscriptions)
- The tutorial data files. Download this package and unzip it:

  [Tutorial - Building an application files](/en-US/cloud-services/tutorials/BuildingAnAppFiles.zip)
- For the steps for sharing an application with other users, you need membership in a shared space, with the permission Can edit or greater.

## Lessons in this tutorial

The topics in this tutorial are designed to be completed in sequence. However, you can step away and return at any time.
