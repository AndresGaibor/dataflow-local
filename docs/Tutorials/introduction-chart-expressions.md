# Tutorial - Chart expressions

This tutorial introduces [chart](#glossary-0 "Glossary term") expressions in Qlik Sense. Expressions are a combination of functions, [fields](#glossary-1 "Glossary term"), and mathematical operators, used to process data and produce a result that can be seen in a [visualization](#glossary-2 "Glossary term").

Chart expressions are mostly used in [measures](#glossary-3 "Glossary term"). You can also build [visualizations](#glossary-4 "Glossary term") that are more dynamic and powerful by using expressions for titles, subtitles, footnotes, and even [dimensions](#glossary-5 "Glossary term").

## What you will learn

When you have completed the tutorial, you will be comfortable using expressions in visualizations.

## Who should complete this tutorial

You should be familiar with Qlik Sense basics. For example, you have loaded data, created applications, and created visualizations on different [sheets](#glossary-7 "Glossary term").

You will need access to the data load editor and should be allowed to load data in Qlik Cloud.

## What you need to do before you start

Download this package and unzip it on your computer:

[Chart expressions application](/en-US/cloud-services/tutorials/ChartExpressionsApp.zip)

The QVF file contains preloaded data.

Upload the QVF file and open the available application.
