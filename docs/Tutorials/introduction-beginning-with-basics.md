# Tutorial - Beginning with the Basics

Welcome to this tutorial, which will introduce you to analytics applications.

Analytics applications are data visualization and discovery tools in Qlik Cloud Analytics. It allows you to create flexible, interactive visualizations that lead to meaningful decisions.

For additional information about Qlik Cloud, see [Introducing Qlik Cloud](/en-US/cloud-services/Subsystems/Hub/Content/Global_Common/HelpSites/introducing-qlik-cloud.htm).

## What you will learn

When you have completed the tutorial, you will understand the basics of analytic applications and be able to use applications to analyze your data and visualizations.

## Who should complete this tutorial

In this tutorial, you will learn how to work with applications as a business user or application consumer. You will not learn how to create or edit [charts](#glossary-0 "Glossary term"). No previous Qlik Cloud experience or database knowledge is required. You will be guided through an existing application, focusing on how applications work.

## What you need to do before you start

Before you can start working with applications, you need access to Qlik Cloud.

You access Qlik Cloud by entering a web address in your browser, such as https://<server name>/hub. The exact address and credentials that you enter depend on how your organization has deployed Qlik Cloud.

To complete this tutorial, you need to be able to upload applications in the Analytics [activity center](#glossary-2 "Glossary term").
If you cannot upload applications, contact your  [tenant admin](#glossary-3 "Glossary term").

**Before you start**

To complete this tutorial, your role must allow you to upload (import) apps in the Analytics and open apps in the target space. If either action is unavailable, contact your tenant admin or space admin.

This package contains a copy of the Beginning With the Basics Tutorial application. Download this package and unzip it on your desktop:

[Beginning with the Basics tutorial](/en-US/cloud-services/tutorials/BeginningWithBasics.zip)

Then, you can upload the application.

### Find and open the tutorial application

1. In the Analytics activity center, open the space where you uploaded the tutorial application.
2. Select Beginning With the Basics Tutorial to open the application.

**I cannot see the app**

If you cannot find the app, check that you are in the correct space and that your role allows access to apps in that space. If needed, contact your tenant admin or space admin to request access.

### Come back and continue

- In the Insights activity center, find Beginning With the Basics Tutorial.
- Mark the app as a favorite so you can find it quickly later.
- When you return, open the app and continue with the next lesson in the list below.

## Lessons in this tutorial

The topics in this tutorial are designed to be completed in sequence. However, you can step away and return at any time.

### If you get stuck

- If you pause or lose your place, reopen Beginning With the Basics Tutorial from Favorites, then continue with the next lesson in this list.
- In the activity center, use Help in the top bar to open product help.
- To continue learning, see [Getting started using Qlik Sense](/en-US/sense/November2026/Subsystems/Hub/Content/Sense_Hub/Introduction/get-started.htm).
