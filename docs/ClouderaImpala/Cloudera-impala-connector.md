# Cloudera Impala

Connections to a Cloudera Impala database are made by selecting Cloudera Imapala from the list of drivers in the Qlik Sense Add data or Data load editor dialogs.

Information noteIndustry-accepted best practices must be followed when using or allowing access through the ODBC Connector. Administrators must follow The Principle of Least Privilege when setting up source database privileges and permissions.

## Supported Cloudera Impala versions

The followings database versions are supported:

- 2.8 to 3.4

## Support Cloudera Impala data types

The following Cloudera Impala data types are supported by the Cloudera Impala Connector.

- BigInt
- Binary
- Boolean
- Char (CDH 5.2 or above)
- Decimal (CDH 5.2 or above)
- Double (CDH 5.2 or above)
- Float
- Integer
- Real
- SmallInt
- String
- Timestamp
- TinyInt
- Varchar (CDH 5.2 or above)
- Array (CDH 5.5 or above)
- Map (CDH 5.5 or above)
- Struct (CDH 5.5 or above)
