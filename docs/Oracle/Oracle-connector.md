# Oracle

Connections to an Oracle database are made by selecting Oracle from the list of drivers in the list of connectors in the Qlik Sense Add data or Data load editor dialogs.

Information noteIndustry-accepted best practices must be followed when using or allowing access through the ODBC Connector. Administrators must follow The Principle of Least Privilege when setting up source database privileges and permissions.

## Supported Oracle versions

The followings data versions are supported:

- 11g
- 12c
- 18c
- 19c

## Supported Oracle data types

The following Oracle data types are supported by the Oracle Connector.

- Binary\_Double
- Binary\_Float
- BFile
- Char
- CLOB
- Date
- Decimal
- Double Precision
- Float
- Integer
- Nchar
- Number
- Nvarchar2
- Real
- RowID
- Timestamp With Local Time Zone
- Timestamp With Time Zone
- Timestamp
- URowID
- VarChar
- Varchar2
