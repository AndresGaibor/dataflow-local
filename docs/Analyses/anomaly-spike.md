# Anomaly (spike) analysis

Detect and show large data variations, including spikes and dips in a time series.

Anomaly (spike) analysis

![An anomaly spike analysis, showing spikes in gross profits between 2019 and 2021](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_anomaly-spike-analysis.png "Click to view full size")

## Creating anomaly (spike) analyses

Do the following:

1. In Assets, click Analysis.
2. Drag and drop Anomaly (spike) into the sheet.
3. Click Add dimension and select a temporal dimension.
4. Click Add measure and select a measure.
5. Optionally, in the properties panel, under Appearance, adjust the appearance of the analysis.
