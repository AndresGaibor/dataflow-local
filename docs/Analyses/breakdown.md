# Breakdown analysis

Show multiple dimensions in order of contribution.

Breakdown analyses show nested dimensions of data that provide a breakdown of relative contributions to a measure.

Breakdown analysis

![Breakdown analysis showing the breakdown of gross profit by country and city for fourth quarter 2021.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_analysis-breakdown.png "Click to view full size")

## Creating breakdown analyses

Do the following:

1. In Assets, click Analysis.
2. Drag and drop Breakdown into the sheet.
3. Click Add dimension and select a dimension.
4. Optionally, click Add dimension to add an additional dimension.
5. Click Add measure and select a measure.
6. Optionally, to add an analysis period, do the following:

   1. In the properties panel, under Analysis properties, turn on Analysis period.
   2. Under Calendar period, select the calendar period to use.
   3. Under Period, select a specific period to use.

   Information noteAnalysis periods requires calendar periods in the logical model. For more information, see [*Defining analysis periods with calendar periods in Insight Advisor*](../BusinessLogic/business-logic-calendar.htm).
7. Optionally, in the properties panel, under Appearance, adjust the appearance of the analysis.
