# Breakdown (geospatial) analysis

Show geographical contributions to a measure.

Breakdown (geospatial) groups data by simple and hierarchical geographic divisions.

Breakdown (geospatial) analysis

![Geospatial analysis showing the average gross profit by country and city on a map.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_analysis-breakdown-geospatial.png "Click to view full size")

## Creating geospatial breakdown analyses

Do the following:

1. In Assets, click Analysis.
2. Drag and drop Breakdown (geospatial) into the sheet.
3. Click Add dimension and select a dimension containing geographic data.
4. Optionally, in the properties panel, in Data, add an additional dimension containing geographic data.
5. Optionally, in the properties panel, in Data, under Measure, click Add and select a measure.
6. Optionally, to add an analysis period, do the following:

   1. In the properties panel, under Analysis properties, turn on Analysis period.
   2. Under Calendar period, select the calendar period to use.
   3. Under Period, select a specific period to use.

   Information noteAnalysis periods requires calendar periods in the logical model. For more information, see [*Defining analysis periods with calendar periods in Insight Advisor*](../BusinessLogic/business-logic-calendar.htm).
7. Optionally, in the properties panel, under Appearance, adjust the appearance of the analysis.
