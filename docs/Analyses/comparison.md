# Comparison analysis

Show multiple measures for a dimension.

You can compare:

- Two to four measures for a single dimension.
- Two to three measures for two dimensions.

Comparison analysis

![Comparison analysis showing a comparison of cost of sale and gross profit for city](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_analysis-comparison.png "Click to view full size")

## Creating comparison analyses

Do the following:

1. In Assets, click Analysis.
2. Drag and drop Comparison into the sheet.
3. Click Add dimension and select a dimension.
4. Click Add measure and select a measure.
5. Click Add measure and select the second measure.
6. Optionally, in the properties panel, under Alternative charts, select the chart to use in the analysis.
7. Optionally, in Data, click Add and select additional dimensions or measure.
8. Optionally, to add an analysis period, do the following:

   1. In the properties panel, under Analysis properties, turn on Analysis period.
   2. Under Calendar period, select the calendar period to use.
   3. Under Period, select a specific period to use.

   Information noteAnalysis periods requires calendar periods in the logical model. For more information, see [*Defining analysis periods with calendar periods in Insight Advisor*](../BusinessLogic/business-logic-calendar.htm).
9. Optionally, in the properties panel, under Appearance, adjust the appearance of the analysis.
