# Calculated measure (KPI) analysis

Show a calculated measure.

Calculated measure (KPI) summarizes the performance of a given business segment or dimension using a key performance indicator (KPI).

Calculated measure (KPI) analysis

![](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_analysis-calculated-measure.png "Click to view full size")

## Creating calculated measure (KPI) analyses

Do the following:

1. In Assets, click Analysis.
2. Drag and drop Calculated measure (KPI) into the sheet.
3. Click Add measure and select a measure.
4. Optionally, to add an analysis period, do the following:

   1. In the properties panel, under Analysis properties, turn on Analysis period.
   2. Under Calendar period, select the calendar period to use.
   3. Under Period, select a specific period to use.

   Information noteAnalysis periods requires calendar periods in the logical model. For more information, see [*Defining analysis periods with calendar periods in Insight Advisor*](../BusinessLogic/business-logic-calendar.htm).
5. Optionally, in the properties panel, under Appearance, adjust the appearance of the analysis.
