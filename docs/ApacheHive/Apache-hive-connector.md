# Apache Hive

Connections to an Apache Hive database are made by selecting Apache Hive from the list of connectors in the Qlik Sense Add data or Data load editor dialogs.

Information noteIndustry-accepted best practices must be followed when using or allowing access through the ODBC Connector. Administrators must follow The Principle of Least Privilege when setting up source database privileges and permissions.

## Supported Apache Hive database versions

The following database versions are supported:

- Apache Hive 0.11 to 3.1

## Supported Apache Hive data types

The following Apache Hive data types are supported by the Apache Hive Connector.

- BigInt
- Binary
- Boolean
- Char
- Date
- Decimal
- Double
- Float
- Integer
- SmallInt
- String
- Timestamp
- TinyInt
- Varchar
