# Supported editions

The following Microsoft SQL Server editions are supported:

- Enterprise Edition
- Standard Edition
- Workgroup Edition
- Developer Edition
- SQL Server Web Edition (supported with Full Load tasks only)

## Supported versions

The following Microsoft SQL Server versions are supported:

- SQL Server 2016
- SQL Server 2017
- SQL Server 2019
- SQL Server 2022
- SQL Server 2025
