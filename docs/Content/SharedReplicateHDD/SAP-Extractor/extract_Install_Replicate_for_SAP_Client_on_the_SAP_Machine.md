# Download the required transports to the SAP Machine

This topic describes how to download and install the required transports.

## Downloading the Replicate for SAP transports

Do the following:

1. Go to [Product Downloads](https://community.qlik.com/t5/Downloads/tkb-p/Downloads).
2. Select Qlik Data Integration.
3. In the Show Release list, select All releases with latest patch.
4. In the Product list, select Qlik Replicate.
5. In the Release list, select the Qlik Replicate version that corresponds to the release date (year and month) of your Data Movement gateway version. For example, if your Data Movement gateway version is 2024.11.54 (Year.Month.Build), select November 2024.
6. In the Download Link column, click the QlikReplicate\_<version-build>\_R4SAPExtractor.zip link to start your download.

## Downloading the Qlik SAP connector transports

Do the following:

1. Go to the [Product Downloads](https://community.qlik.com/t5/Downloads/tkb-p/Downloads).
2. Select Qlik Data Analytics, and then select Qlik Connector for use with SAP NetWeaver.
3. Use the Release filters to narrow your list of possible downloads.
4. Download the latest version of the transports: 8.x.x.SAP.transports.zip

   where x will be replaced with numbers. For example, if you are downloading version 8.2.0 of the transports, the file will be 820.SAP.transports.zip.
