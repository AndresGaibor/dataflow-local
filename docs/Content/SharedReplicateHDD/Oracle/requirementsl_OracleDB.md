# Supported Oracle database editions

The following Oracle database editions are supported:

Information noteOracle AI Database 26ai is supported with Oracle Standard and Enterprise editions only.

- Oracle Enterprise Edition
- Oracle Standard Edition
- Oracle Standard Edition 2
- Oracle Express Edition

  Information noteCDC from Oracle Express Edition is not supported.
- Oracle Personal Edition
