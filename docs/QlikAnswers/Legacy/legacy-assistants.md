# Working with legacy assistants

Legacy assistants are a non-agentic version of the Qlik Answers assistant. They offer an interface to interact with a range of unstructured data sources through natural language questions. Legacy assistants use retrieval augmented generation (RAG) to generate answers to user question.

Legacy assistants can be useful if you only intend to use unstructured data sources with them.

Legacy assistants are available through Qlik Cloud, but can be embedded into your workflows and systems. The chat can be embedded into other web interfaces in other systems using Qlik Embed. You can also create custom UI using APIs. For more information, see [Qlik Developer](https://qlik.dev/).

## Navigating legacy assistants

Legacy assistants are divided into the following sections:

- Overview
- Chat
- Review
- Conversation starters
- Settings

### Overview

Overview provides basic information about the legacy assistant. You can manage your legacy assistant's knowledge bases from Overview.

### Chat

Chat is available on all tabs except for Review. This allows you to test the chat as you create your legacy assistant. To hide chat, click Hide chat. To make the chat full screen, click ![Expand chat](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_expand_3_outline.svg).

Assistant chat

![A collapsed assistant chat window, with 3 conversation starters.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/QlikAnswers/ui_assistant-chat.png "Click to view full size")

Full screen chat

![An assistant showing the full-screen chat.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/QlikAnswers/ui_assistant-full-chat.png "Click to view full size")

You can view previous conversations and saved conversations in Conversations. Conversations is available in the full screen view or by clicking Chat > Conversations. Conversations shows your previous history of interactions with the legacy assistant as conversation threads. You can select conversations to view the individual interactions between you and the legacy assistant from that session. You can still interact with the responses to each of your questions, such as liking or disliking them, just as you can with responses in an active conversation.

Conversations  has two sections, Saved and History. History contains your most recent conversations with the legacy assistant. Conversations in your history are removed after a period of time, but you can save important conversations to Saved.

Conversations are named with the first conversation in the thread, but can be renamed.

For more information on using chat, see [*Answering questions with Qlik Answers*](../answering-questions-qlik-answers.htm).

### Conversation starters

You add starter questions for your legacy assistant users in Conversation starters. Starter questions help your legacy assistant's users understand what kinds of answers they can get from the legacy assistant.

### Settings

You can adjust assistant settings in Settings. You can:

- Update the name, description, and tags.
- Customize an avatar icon.
- Customize error messages.
- You can also add a welcome message.
