# Using Qlik Answers and choosing your context

Open Qlik Answers from the navigation bar by clicking Qlik Answers. After you open Qlik Answers, you can choose the context in which you want to work with it.

Qlik Answers with available contexts to work with

![An open Qlik Answers agentic chat, with the following contexts to choose from: Help, Predict, Data Product, Glossary, Data quality, Application analysis, and Answers assistants](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/QlikAnswers/ui_QlikAnswersAgents-rev.png "Click to view full size")

Qlik Answers provides a range of contexts to choose from, depending on what you want to use it for:

- Help: Get answers from Qlik Help. This is selected by default.

  [*Answering questions with Qlik Answers*](answering-questions-qlik-answers.htm)
- Application analysis: Get answers from applications available with Qlik Answers.

  [*Answering questions with Qlik Answers*](answering-questions-qlik-answers.htm)
- Answers assistants: Get answers from assistants that use applications and knowledge bases as data sources.

  [*Answering questions with Qlik Answers*](answering-questions-qlik-answers.htm)
- Predict: Use Qlik Predict workflows in natural language.

  [*Working with machine learning in Qlik Answers*](predict-agent.htm)
- Data product: Create and manage data products in natural language.

  [*Managing data products with Qlik Answers*](data-product-agent.htm)
- Glossary: Create and manage business glossaries.

  [*Managing business glossaries with Qlik Answers*](glossary-agent.htm)
- Data quality: Manage and monitor data quality.

  [*Managing data quality with Qlik Answers*](data-quality-agent.htm)

Information noteIf you open Qlik Answers with an application open, and that application is available for Qlik Answers open, Qlik Answers automatically starts a chat using that application as the source.

You may also have access to legacy assistants. Legacy assistants are assistants created for the initial version of Qlik Answers and offer a different non-agentic chat experience. You can find them in the catalog and chat with each assistant directly. For information on using legacy assistants, see: [*Answering questions with legacy assistants*](Legacy/using-assistants-legacy.htm).

## Help

Help answers your questions about Qlik Cloud, based on the Qlik Cloud documentation. Help questions are free and are not counted toward usage consumption limits.

It is the default context when you open Qlik Answers outside of an application in an activity center.

Help is context sensitive; it filters the help content based on what activity center you are in. For best results, if you want to ask a question about Analytics for example, you need to go to the Analytics activity center. If the answer is not what you need, you can click Ask again without previous context at the end of the answer, to make Qlik Answers run the question again without using the previous context.

It includes links to relevant help topics at the end of the answer. When you click one of the links, the help topic appears in the chat. You can also click Go to topic to open Qlik Cloud documentation outside of the chat in a new tab in your browser.

Requirements: User must have a role with the permission Qlik product help set to Allowed.

For more information, see [*Answering questions with Qlik Answers*](answering-questions-qlik-answers.htm).

## Application analysis

Application analysis provides you with access to all the Qlik Answers-enabled applications to which you have access. You can select an application and then start asking questions. Qlik Answers will generate answers based on the data within the application.

If you have the corresponding application open when chatting with Qlik Answers, you can also add charts and sheets to that application using Qlik Answers.

## Answers assistants

Answers assistants provides you with access to all the Qlik Answers assistants to which you have access. Assistants can use two kinds of data sources:

- Knowledge bases, which contain unstructured data in files such as:

  - TXT
  - PDF
  - DOC, DOCX
  - PPTX
  - HTM, HTML
  - MD
  - ODT
  - RTF
- Applications, which contain structured data.

An assistant can use one or both kinds of data. If you have the corresponding application open when chatting with Qlik Answers, you can also ask Qlik Answers to create charts and sheets for you in that application.

## Predict

Predict lets you use Qlik Predict from chat. You can explore datasets, configure and train experiments, and run predictions.

## Data product

Data product lets you manage data products in natural language from chat. You can create, update, activate, and deactivate data products by using prompts.

For more information, see [*Managing data products with Qlik Answers*](data-product-agent.htm).

## Glossary

Glossary lets you create and maintain business glossaries from chat. You can add and refine glossary terms, improve definitions, and organize glossary content for your data and analytics workflows.

For more information, see [*Managing business glossaries with Qlik Answers*](glossary-agent.htm).
