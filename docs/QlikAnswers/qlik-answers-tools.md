# Managing Qlik Answers tools

Qlik Answers uses tools to perform actions and answer user questions in each context. The first time Qlik Answers needs to use a tool, it asks you to approve or deny the tool.

Request for approval

![A request to approve the tool Forget, with the options Deny, Always allow, and Allow once.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/QlikAnswers/ui_tool-use.png "Click to view full size")

You have the following options:

- Deny: The tool is not used, and the action is not completed.
- Allow once: The tool is used for the current action only.
- Allow always: The tool is used now and is automatically allowed for all future requests.

You can manage your tool approvals in Settings. Click ![Open menu](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_menu.svg) > Settings > Tool permissions. In Tool permissions, you can view and change your tool permissions.
