# Managing skills

You can manage skills from the catalog. You can:

- Add skills to collections
- Move skills between spaces
- Change the name, description, or tags of skills
- Delete skills

Information noteTo manage skills in Qlik Cloud, you need the Manage skills user permission set to Allowed. For more information, see [*Managing user access to Qlik Answers*](../administering-qlik-answers.htm#Access).

## Adding skills to collections

Collections allow you to group related content together. For more information, see [*Collections*](../../QlikCloudNavigation/Analytics-activity-center.htm#Collecti).

Do the following:

1. In the catalog, click ![More actions](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) on a skill.
2. Select Manage > Add to collection.
3. Select a collection or create a new collection.
4. Click Done.

## Moving skills

Do the following:

1. In the catalog, click ![More actions](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) on a skill.
2. Select Manage > Move.
3. Under Space, select a destination space.
4. Click Move.

## Changing skill details

You can change the names and descriptions of your skills. You can also change the tags used with the skill. Tags are used to group skills with related content. When you add new tags, you can view all tags that exist in the tenant.

Information noteYou cannot edit a skill after it is created. To change the instructions in a skill, upload a new version of the Markdown file. For more information, see [*Creating custom skills*](creating-custom-skills.htm).

Do the following:

1. In the catalog, click ![More actions](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) on a skill.
2. Select Manage > Edit details.
3. After Name, enter a new name.
4. After Description, enter a new description.
5. After Tags, add tags.
6. Click Done.

## Deleting skills

Deleting a skill removes it from the catalog. To stop using a skill in a specific application or assistant without deleting it, remove the skill instead. For more information, see [*Adding skills to applications and assistants*](adding-skills.htm).

Do the following:

1. In the catalog, click ![More actions](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) on a skill.
2. Select Delete.
3. Click Delete.
