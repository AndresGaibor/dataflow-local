# Best practices for preparing knowledge base content

You can improve the quality of assistants' answers by ensuring the content of its knowledge base meets certain key criteria.

## Content structure

Using content with a strong structure can help assistants identify the most relevant sources for their responses when processing the material. Consider the following best practices when preparing content for knowledge bases:

- Use clear, descriptive headings and subheadings with relevant keywords.
- Use simple table structures.
- Use standardized terminology.

## Content accuracy

The content of knowledge bases should be as accurate as possible. Regularly review and update the content to keep it relevant and correct.

## Content type

Leverage different types of content in your knowledge bases depending on the purpose of the assistant that will use it. Here are some examples:

- Frequently Asked Questions (FAQs) can address recurring questions and issues.
- Glossary definitions can explain technical terms or company-specific concepts.
- How-to procedures can provide step-by-step instructions for completing tasks.
- Tables can provide reference information.
