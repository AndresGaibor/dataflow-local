# Configuring Qlik Answers behavior with business logic

Use Settings to configure assistant behavior, reasoning mode defaults, and starter questions for application chat experiences.

You can open Settings from AI optimization in the navigation menu.

## Setting a default assistant

If your application is used in assistants, you can configure a default assistant for Qlik Answers with your application. The default assistant determines which assistant answers when a user opens Qlik Answers in an application.

Information noteThe default assistant must use the application as a content source.

Do the following:

- In Settings, under Default assistant, select an assistant.

## Allowing assistant switching

Allow assistant switching controls whether users can change to a different assistant during the same chat session.

- If turned on, users can switch assistants during chat.
- If turned off, users stay on the default assistant for the session.

Do the following:

- In Settings, turn Allow assistant switching on or off.

## Using application theme for charts

Use application theme for charts controls whether generated charts and sheets use the application theme or not.

Do the following:

- In Settings, turn Use application theme for charts on or off.

## Adding starter questions

Starter questions help users understand what they can ask Qlik Answers, enabling them to get the most out of your assistant.

Starter questions are available at the start of the chat. Selecting a starter question asks the assistant that question. Starter questions allow you to add a curated list of questions available to your assistant's users. These questions help show your users what is possible with your assistant.

You can add a maximum of five starter questions to your application.

If starter questions are left empty, Qlik Answers uses the generic defaults.

Do the following:

1. In Settings, under Starter questions, click Create starter question.
2. Enter a question and press Enter.
