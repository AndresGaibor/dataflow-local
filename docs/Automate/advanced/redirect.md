# Redirect block

The redirect block is used for automations that are executed manually, and where a redirect needs to occur to a certain webpage.

![redirect block](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Sense_QlikAutomation/img/redirect-block.png)

Information note

This block can only be used for automations that are run manually.

A redirect block is commonly used in the following situations:

- When your automation requires a redirect to a webpage.
- When your automation needs to send items in batch to another destination.

## Configuring a redirect block

Configure the block to redirect a user to a webpage.

### Inputs

The redirect block requires a URL. You can include field mapped values from preceding blocks into the URL field.
