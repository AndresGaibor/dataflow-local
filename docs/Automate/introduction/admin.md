# Managing automations

Users who are responsible for managing and administering automations from the Qlik Cloud tenant must have the analytics admin or tenant admin role to access the automations section of the Administration activity center, and tenant admin role to access the webhooks section. The automations section lists all automations that are created on the tenant, and the webhooks section includes any webhooks coming from an automation.
