# Blocks

An automation is a sequence of blocks, where each block completes an action or acts as a trigger. What each block does is described here.

Automations are designed to be simple to build and easy to visualize. You can build automations with the no-code automations editor by selecting workflow blocks and ordering them into a logical sequence. Each block is configurable, which lets you create specific workflows that meet your specific use cases.
