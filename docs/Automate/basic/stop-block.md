# Stop block

The stop block stops the automation. There are no options to configure a stop block.

![stop block](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Sense_QlikAutomation/img/stop-block.png)

A stop block is commonly used in following situation:

- When an automation should stop when a certain condition is met.
- When an automation has no more blocks to execute.
