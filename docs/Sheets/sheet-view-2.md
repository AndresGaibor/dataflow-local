# Sheet view

Sheets are components of analytics applications. They present [visualizations](#glossary-1 "Glossary term") to application users so they can explore, analyze, and discover data. Sheets can be public or private. This is also where you create, design, and structure the visualizations when you build applications.

The navigation bar contains options for you to navigate in your application. The toolbar contains options to navigate your [sheets](#glossary-2 "Glossary term"), make and clear [selections](#glossary-3 "Glossary term"), and search for data. Insight Advisor is where you can access assisted creation of visualizations and analyses. The sheet is where you interact with the visualizations.

## Toolbar

The toolbar contains options to create and navigate in your sheet and application. Within the toolbar, the selections bar contains options to make selections in your data and to clear those selections, and to search for data. The selections tool also displays all selections that have been made.

Toolbar in a sheet in analysis mode

![Toolbar in analysis mode.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_gen-sheet-view-toolbar-qcs.png "Click to view full size")

## Assets

The assets panel contains options to navigate in your sheet and application. From Assets, you can navigate and create new sheets and bookmarks. You can also view and create notes, and use key driver analysis. If a report developer has activated any of the application's [report templates](#glossary-4 "Glossary term") for on-demand reporting, you can also view available templates and generate reports. Click Sheets or Bookmarks to open the assets panel to those sections.

## Options menu

You can use the options menu to perform actions related to the visualization.

Options menu next to a chart

![Options menu for a chart.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Sheets/ui_options-menu-chart.png "Click to view full size")

You can open the options menu by:

- Right-clicking on a chart.
- Clicking the hover menu ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg).

Menu options will be different depending on:

- Whether you are editing or analyzing (viewing) charts in an application.
- The chart type.
- The privileges that have been assigned to you by your administrator.
- Custom settings for visualization menus that have been configured by the application developer (see [*Hiding items in visualization menus*](../Apps/style-app.htm#HidingContext)).

Options menu for a chart with hover menu expanded

![Options menu when the 'more' icon next to a chart is selected.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_gen-options-menu-opened-cloud.png "Click to view full size")

The menu looks different if you have touch screen mode enabled on a supported device. You can toggle touch support on and off by clicking or tapping the application navigation button (![Navigation](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg)) and using the toggle for ![Touch screen mode](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_touch_outline.svg) Touch screen mode.

## Insight Advisor

Insight Advisor allows you to quickly create new visualizations from the data, helping you find analyses that might not be present in the application. You can access Insight Advisor by clicking ![Insight Advisor](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_cognitive.svg) or, if you want to use search-based analysis, entering a query into the Ask Insight Advisor search bar.

Information note

**Agentic experience tenants**

If your tenant uses the Qlik Answers agentic experience, skip this section. Natural language questions for app data are handled through Qlik Answers, not Insight Advisor Chat.

Learn how to ask questions in Qlik Answers: [Answering questions with Qlik Answers](/en-US/cloud-services/Subsystems/Hub/Content/Sense_Hub/QlikAnswers/answering-questions-qlik-answers.htm).

To use application data in Qlik Answers, the application must first be made available for Qlik Answers and finish indexing. See [Working with applications in Qlik Answers](/en-US/cloud-services/Subsystems/Hub/Content/Sense_Hub/QlikAnswers/working-with-apps-in-qlik-answers.htm).

Information note

**Insight Advisor access**

What you can search for and view in Insight Advisor Chat depends on the application, your space permissions, and whether the application uses a logical model.

For the access requirements, see [Insight Advisor availability](/en-US/cloud-services/Subsystems/Hub/Content/Sense_Hub/Insights/insight-advisor-available-chat.htm).

Insight Advisor

![Insight Advisor.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_insight-advisor_qcs.png "Click to view full size")

Insight Advisor Analysis Types helps you create [charts](#glossary-5 "Glossary term") from a range of possible analysis types. You select the analysis you want to see, the data types that should be used, and Insight Advisor creates charts from your parameters.

Insight Advisor Analysis Types

![Insight Advisor Analysis Types, showing options for creating a breakdown analysis.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_IA_analysis_options_qcs.png "Click to view full size")

You can make natural language searches with Insight Advisor Search. Insight Advisor queries application data and returns results that match your question. You can also select fields and let Insight Advisor Search create charts.

If your browser is not set to a supported language, English is used.

You can change the language used by Insight Advisor by selecting a language from the Language button.

Information note

Qlik Cloud supports several languages in Insight Advisor Search. For more information on supported languages in Insight Advisor Search, see [Supported languages](/en-US/cloud-services/Subsystems/Hub/Content/Sense_Hub/Insights/insight-advisor-create-visualizations.htm#anchor-8).

If your browser is not set to a supported language, English is used. You can change the language used by Insight Advisor by selecting a language from the Language button.
