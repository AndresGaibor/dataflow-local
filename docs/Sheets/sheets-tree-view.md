# Managing sheet content in tree view

[Feature in Preview](../Introduction/feature-preview-program-overview.htm)

With ![Tree view](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_tree_view.svg)Tree view, view and manage sheet content using a hierarchical structure.

In tree view, you can:

- Create a new sheet by clicking ![Create new sheet](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_add.svg).
- Make sheets public and private by dragging them between sections.
- Move and reorder charts by dragging them between and within sheets.
- Manage sheets and charts—such as copying, pasting, deleting—with the right-click and options menus. You also have access to options for managing the entire application, such as reloading and publishing.

  [*Managing content in tree view*](#Managing)
- Organize content within containers.

  [*Managing content within containers*](#Layout)

## Opening tree view

Do the following:

1. Open sheet view in edit mode.
2. Expand the Assets panel.
3. Open the Sheets tab.
4. Click ![Tree view](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_tree_view.svg) to switch to tree view.

## Navigating tree view

Expand and collapse sections in the tree view to drill into content. Content is organized in tree view as follows, from top-most to most nested:

- Application
- Public and private content
- Sheet groups
- Sheets
- Charts
- Charts within containers

## Managing content in tree view

From tree view, you can manage applications, sheets, sheet groups, charts, and charts within containers.

Do the following:

1. Open Sheets in tree view.

   [*Opening tree view*](#Opening)
2. Right-click or hover over an item.
3. Click ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) and select an option. For a list of common options, see [*Options*](sheet-view.htm#Options).

## Managing content within containers

You can manage the content in tab containers and layout containers. For example, you can copy and paste content between containers.
