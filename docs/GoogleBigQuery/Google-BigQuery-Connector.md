# Google BigQuery

Connections to a Google BigQuery database are made by selecting Google BigQuery from the list of drivers in the list of connectors in the Qlik Sense Add data or Data load editor dialogs.

Information noteIndustry-accepted best practices must be followed when using or allowing access through the ODBC Connector. Administrators must follow The Principle of Least Privilege when setting up source database privileges and permissions.

## Supported Google BigQuery data types

The following Google BigQuery data types are supported by the Google BigQuery Connector.

- Boolean
- Bytes
- Char
- Date
- Datetime
- Float64
- Int64
- String
- Time
- Timestamp
