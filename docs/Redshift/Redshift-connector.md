# Amazon Redshift

Connections to an Amazon Redshift database are made by selecting Amazon Redshift from the list of connectors in the Qlik Sense Add data or Data load editor dialogs.

Information noteIndustry-accepted best practices must be followed when using or allowing access through the ODBC Connector. Administrators must follow The Principle of Least Privilege when setting up source database privileges and permissions.

## Supported Amazon Redshift data types

The following Amazon Redshift data types are supported by the Amazon Redshift Connector.

- Bigint
- Binary
- Boolean
- ByteDict
- Char
- Date
- Decimal
- Double Precision
- Integer
- Real
- Smallint
- Text
- Timestamp
- Varchar
