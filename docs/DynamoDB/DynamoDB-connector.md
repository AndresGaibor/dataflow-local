# DynamoDB

Connections to a DynamoDB database are made by selecting DynamoDB from the list of connectors in the Add data or Data load editor dialogs.

## Supported DynamoDB data types

The following DynamoDB data types are supported by the DynamoDB Connector.

- Big Int
- Binary
- Bit
- Char
- Decimal
- Double
- Float
- Integer
- LongVarBinary
- LongVarChar
- Numeric
- Real
- Small Int
- Tiny Int
- VarBinary
- VarChar
- WChar
- WLongVarChar
- WVarChar
