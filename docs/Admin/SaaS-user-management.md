# Managing users - User-based subscriptions

Qlik Cloud provides several ways to organize the users that you add to the [tenant](#glossary-0 "Glossary term"). The available user types and how you manage users depend on your subscription. With the user-based Qlik Cloud Analytics subscriptions, the users are assigned Analyzer or Professional user entitlement.

Information note

This topic is applicable to Qlik Sense Enterprise SaaS, Qlik Sense Business, and Qlik Cloud Government. If you have a subscription for the Standard, Premium, or Enterprise edition of Qlik Cloud Analytics or Qlik Talend Data Integration, see [*Managing users - Capacity-based subscriptions*](SaaS-user-management-capacity-model.htm).

Add users through an identity provider or send email invitations. Once users are added to the tenant, categorize them as either application consumers or content creators by assigning Analyzer or Professional user entitlement.

Additionally, you can grant specific permissions for actions in Qlik Cloud. Permissions are grouped into roles that you can assign to individuals or groups of users.
