# Administering reporting and subscriptions

Administrators can manage reporting and subscriptions in the Administration activity center.

Administering reporting and subscriptions involves:

- Administering user resources, including in-application [report tasks](#glossary-0 "Glossary term") and subscriptions.
- Setting user permissions for working with metered reporting features, including global reporting access settings.
- Managing installation manifests for in-application reporting.

## Enabling and disabling reporting, subscriptions, and sharing features

Tenant administrators can turn off specific capabilities for the entire tenant. See [*Enabling and disabling reporting, subscriptions, and sharing features*](mc-enable-reporting-features.htm).

Information noteThe tenant-level feature control for In-application reporting has been removed. To replace this feature control setting, configure default permissions and custom roles to control access to in-application reporting. For more information, see [*Setting permissions for metered reporting features*](mc-permissions-reporting.htm).

## Administering user report tasks and subscriptions

Tenant and analytics administrators can manage user resources related to reporting and subscriptions. See [*Administering report tasks and subscriptions*](mc-administer-report-subscription-items.htm).

## Setting permissions for metered reporting features

Tenant administrators can set permissions at the user level to provide full, partial, or no access to metered (paid) reporting features. See [*Setting permissions for metered reporting features*](mc-permissions-reporting.htm).

## Managing reporting installation manifests

Tenant administrators can generate and manage manifests needed for installing reporting add-ins. See [*Managing installation manifests for Qlik add-ins for Microsoft Office*](mc-administer-add-in.htm).

## Other relevant information for administrators

For users to receive reports and subscriptions by email, an email provider must be configured for the tenant. This is a configuration that is performed by the tenant administrator. See [*Configuring email for reports and notifications*](mc-configure-email-support.htm).
