# Adding a direct navigation link to Talend Cloud

You can help users access Talend Cloud more easily by adding a direct link in the Qlik Cloud navigation menu.

Information noteThis topic applies if unified administration is not yet enabled for your account. Once it is enabled, Qlik Cloud and Talend Cloud are linked automatically, and these steps are no longer required.

## Setting up a direct link

Do the following:

1. In the Administration activity center, go to the Settings page, then select the Talend Cloud tab.

   Talend Cloud settings.

   ![Settings pane showing settings for Talend Cloud](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_settings_talend-link-with-token.png "Click to view full size")
2. Choose a Talend Cloud region in the dropdown list.
3. Enter the Talend Cloud account ID.

   You can find the account ID in the Talend Management Console under Subscription.

   Account information on the Subscription page in the Talend Management Console.

   ![Subscription pane with account information in Talend Management Console](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui-talend-account-id.png "Click to view full size")
4. Turn on the Link to Talend Cloud toggle.

After setup, a new Talend Cloud button appears in the Qlik Cloud navigation menu (![Navigation menu](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_grid_menu.svg)). Clicking this button takes you directly to the Talend Cloud login page.

Navigate to Talend Cloud from the Data Integration activity center.

![Navigation menu with Data Integration section selected showing the link to Talend Cloud.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui-navigation-menu-talend-link.png "Click to view full size")
