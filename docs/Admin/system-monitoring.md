# Monitoring system and resources

Stay informed about system events and resource consumption to ensure optimal operation and identify potential issues.

This topic covers monitoring in Qlik Cloud Analytics, including system events, resource consumption, detailed consumption reports for capacity-based subscriptions, and application performance. If you use Qlik Sense Enterprise on Windows, see [Monitoring a Qlik Sense Enterprise on Windows site](/en-US/sense-admin/November2026/Subsystems/DeployAdministerQSE/Content/Sense_DeployAdminister/QSEoW/Administer_QSEoW/Monitoring_QSEoW/Monitor-Qlik-Sense-site.htm) for information about Monitoring apps provided in the QMC, such as Operations Monitor and License Monitor.

The monitoring topics in this section describe metrics about your tenant, such as system events, resource consumption, and application performance. To calculate a metric from your own data, create a measure; see the topic [*Measures*](../Measures/measures.htm).

## [*Monitoring system events*](mc-administer-events.htm)

Monitor system events to track activities in your Qlik Cloud tenant.

## [*Monitoring resource consumption*](mc-monitor-consumption.htm)

Regularly monitor consumption of user entitlements, data, and other resources.

## [*Monitoring detailed consumption for capacity-based subscriptions*](usage-metrics-app.htm)

Track specific usage metrics for capacity-based subscriptions in detail using the Data Capacity Reporting App.

## [*Monitoring application performance and managing access control*](mc-administer-apps.htm#Monitori)

Monitor user interactions, application access, performance, and resource usage to optimize efficiency and user experience.
