# Providing application-opening progress

You can show users real-time progress when opening applications. The progress display shows the steps being completed as the application loads, helping users understand what's happening. This improves the experience and sets expectations, especially for larger applications that take longer to open.

Information note

Application-opening progress does not display when opening QlikView applications.

Application opening progress

![App opening progress, showing 29 of 94 fields loaded](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_app-opening-feedback.png "Click to view full size")

Do the following:

1. In the Administration activity center, go to the Settings page
2. Select the Feature control tab.
3. Turn on the App opening progress information toggle.
