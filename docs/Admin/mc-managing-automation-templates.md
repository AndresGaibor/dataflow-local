# Managing automation templates

Tenant admins can review automation templates created by users, including personal and shared templates. You can review templates regardless of who owns them, change template owners, or delete them.

To create and save an automation template, see [*Save automations as templates*](../../Sense_QlikAutomation/introduction/creating-automation.htm#saving-automations-as-templates).

## Viewing automation templates

In the Administration activity center, go to Automations > Templates.

The page lists the template name and description, visibility, owner, creation date, last modified date, and available actions.

To find templates, enter a name in Filter by name. To narrow the list, filter by owner, visibility, or last modified date. Visibility indicates whether the template is shared or personal.

## Changing template owner

Do the following:

1. In the Administration activity center, go to Automations > Templates.
2. Find the template whose owner you want to change.
3. In the template row, click ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) and select Change owner.
4. In the Change owner dialog, enter the user's name or email address in Filter by name or email, and select the user.
5. Click Apply.

## Deleting a template

Do the following:

1. In the Administration activity center, go to Automations > Templates.
2. Find the template that you want to delete.
3. In the template row, click ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) and select Delete.
4. Confirm the deletion in the confirmation dialog.
