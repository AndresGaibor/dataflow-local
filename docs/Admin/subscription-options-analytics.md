# Qlik Cloud Analytics subscription options

Qlik Cloud Analytics offers four subscription tiers—Starter, Standard, Premium, and Enterprise—to support businesses of all sizes, from small teams to large enterprises. The subscriptions use a capacity-based model with Data for Analysis as the primary value meter. Each tier provides additional features and increased capacity.

Tip note

Not sure which subscription plan (pricing plan, tier, or edition) your organization is on? Ask your service account owner (SAO) to check in [My Qlik](https://account.myqlik.qlik.com/). In the subscription overview, the SAO can see the current plan and subscription type. To learn more about available pricing plans, see [Qlik Pricing](https://www.qlik.com/us/pricing).

## Qlik Cloud Analytics editions

Qlik Cloud Analytics is available in the following subscription tiers:

- Starter
- Standard
- Premium
- Enterprise

Higher-tier editions include additional features, increased data capacity, and higher limits on various capacities such as number of generated reports or automation runs. All editions provide the same speed, performance, and availability, with the same user interface and activity centers. Qlik hosts and manages the cloud infrastructure.

All analytics subscriptions also include access to Qlik Talend Data Integration, allowing users to create QVD files in the Qlik Cloud data platform for use in analytics applications.

You can start a free trial of Qlik Cloud Analytics from [Qlik Free Trials](https://www.qlik.com/us/free-trial).

## Qlik Cloud Analytics Starter

Qlik Cloud Analytics Starter is designed for smaller analytics use cases, allowing teams to build and share applications. Subscription pricing is based on the number of users, with a fixed data capacity of 10 GB.

Features:

- Full analytic capabilities, including Insight Advisor, Alerting, and Notes
- Augmented intelligence with insight suggestions
- Drag-and-drop application creation and fully interactive applications
- Automations in Qlik Automate, including:

  - Standard automations
  - Up to 25 third-party automations
- Up to 250 reports
- Up to 25 questions for use with Qlik MCP
- Automated data refreshes
- Personal space for individual content creation
- Shared spaces for team collaboration
- Direct connectivity to over 40 data sources
- Data movement to Qlik Cloud from [relational database sources](../DataIntegration/SourcesConnections/supported-sources.htm) and [SaaS sources](../DataIntegration/Landing/connecting-web-applications.htm#Supporte)

## Qlik Cloud Analytics Standard

Building on the Starter edition, Qlik Cloud Analytics Standard provides additional capabilities and increased data capacity. Subscription pricing is based on analyzed data capacity.

Includes all Starter features, plus:

- Qlik Answers generative AI assistants
- Standard and third-party automations in Qlik Automate
- Report generation and distribution
- Managed spaces for controlled access

## Qlik Cloud Analytics Premium

Qlik Cloud Analytics Premium is designed for medium to large organizations requiring a comprehensive analytics solution. It can be deployed independently or as part of a multi-cloud deployment with cloud and on-premises deployments. Subscription pricing is based on analyzed data capacity.

Includes all Standard features, plus:

- Machine learning capabilities with Qlik Predict for predictive analytics.
- Data movement to Qlik Cloud from all sources, including [SAP and mainframe sources](../DataIntegration/SourcesConnections/supported-sources.htm)
- Multiple tenants within a single license
- Data quality and governance capabilities.
- Data marketplace for activation and consumption of data products.

## Qlik Cloud Enterprise

Qlik Cloud Enterprise includes all features from Qlik Cloud Analytics Premium and Qlik Talend Cloud Enterprise. It offers increased capacity for:

- Large application support
- Machine learning
- Reports
- Anonymous access
- Multi-region tenants
- And more

You can subscribe based on:

- Data for Analysis capacity
- Data Moved capacity
- Both, depending on your needs

### Qlik Automate

All Qlik Cloud Analytics subscriptions include automated workflows with Qlik Automate. Higher-tier editions provide more automation runs.

For more information on limits, see [*Qlik Automate limitations*](../../Sense_QlikAutomation/introduction/platform-limitations.htm).

### Qlik Predict

Qlik Predict is available in the Premium and Enterprise editions of Qlik Cloud Analytics. The number of reports and deployed models increases with higher-tier editions.

For more information on limits, see [*Introducing automated machine learning*](../AutoML/introduction.htm#AutoML).

### Qlik Answers

Qlik Answers generative AI assistants are included with the Standard, Premium, and Enterprise editions. The number of included questions and indexed pages depends on the edition.

For more information on limits, see [*Qlik Answers guardrails*](../QlikAnswers/Qlik-Answers.htm#Qlik).

### Reporting Service

The Qlik Reporting Service is available with Qlik Cloud Analytics subscriptions. Higher-tier editions include more reports.

For more information on limits, see [*Qlik Reporting Service specifications and limitations*](../Reporting/Reporting-service-specifications-limitations.htm).
