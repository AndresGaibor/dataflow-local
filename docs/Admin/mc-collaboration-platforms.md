# Adding connections to external collaboration platforms

Add external platforms as collaboration channels to allow users to interact with the Qlik Cloud tenant using conversational analytics.

You can add the following external platform tenants as collaboration channels:

- Microsoft 365 (Microsoft Teams)

In addition to adding the external environment as a collaboration channel, you also need to assign the Collaboration Platform User role to users and groups who will be interacting with Qlik Cloud through the external platform.

For information, see:

- [*Assigning security roles and custom roles*](SaaS-roles-capacity-model.htm) (capacity-based subscriptions)
- [*Assigning security roles and custom roles*](SaaS-roles.htm) (user-based subscriptions)
- [*Assigning security roles and custom roles*](SaaS-roles-anonymous.htm) (Qlik Anonymous Access subscriptions)

## Adding collaboration channels

Add tenant IDs for external collaboration platforms in the Administration activity center.

Do the following:

1. In the Administration [activity center](#glossary-0 "Glossary term"), go to the Settings page.
2. Select the Tenant tab.
3. In the Collaboration platforms section, find the collaboration platform you are using (for example, Microsoft 365).
4. Add the tenant ID for the collaboration platform, and then press the Enter or Tab key.
5. Click Save.
