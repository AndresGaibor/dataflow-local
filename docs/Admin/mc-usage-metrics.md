# Displaying content usage metrics

Usage metrics help users understand how content is being used across the tenant over the past 28 days.

The Viewed by KPI shows how many users have opened the content. The Used in KPI applies to datasets and shows how many applications have used the data. For more information, see [*Managing dataset metadata*](../Catalog/managing-dataset-metadata.htm#Viewing).

Usage metrics are turned on by default. If you want to hide these metrics from users, you can turn the setting off. When usage metrics are turned off:

- They no longer appear in the tenant.
- They are also hidden in copies of the content published after disabling the setting.

## Turning off usage metrics

Do the following:

1. In the Administration activity center, go to the Settings page.
2. Select the Feature control tab.
3. Turn off the Usage metrics toggle to hide KPIs in the tenant.
