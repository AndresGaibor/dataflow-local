# Amazon Athena

Connections to an Amazon Athena database are made by selecting Amazon Athena from the list of connectors in the Add data or Data load editor dialogs.

## Supported Amazon Athena data types

The following Amazon Athena data types are supported by the Amazon Athena Connector.

- Array
- Big Int
- Binary
- Boolean
- Char
- Date
- Decimal
- Double
- Float
- Integer
- Small Int
- String
- Time Stamp
- Tiny Int
- Varchar
