# Set

The set statement is used for
defining script variables. These can
be used for substituting strings, paths, drives, and so on.

Syntax:

Set variablename=string

Example 1:

Set FileToUse=Data1.csv;

Example 2:

Set Constant="My
string";

Example 3:

Set
BudgetYear=2012;
