# Field/Fields

The Field and Fields script keywords are used in Declare, Derive, Drop, Comment, Rename and Tag/Untag statements. In Qlik Cloud Analytics, Fields is also used within IncludeModel statements to integrate a data product's semantic model into an analytics application.
