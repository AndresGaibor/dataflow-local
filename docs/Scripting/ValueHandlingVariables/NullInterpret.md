# NullInterpret

The defined symbol will
be interpreted as NULL when it occurs in a text file, CSV file, or an inline statement. This is a user-defined variable.

Syntax:

NullInterpret

Examples:

set NullInterpret=' ';

set NullInterpret =;

set NullInterpret ='';
