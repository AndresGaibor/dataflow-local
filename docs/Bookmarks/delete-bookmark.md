# Deleting bookmarks

There are several different ways to delete [bookmarks](#glossary-0 "Glossary term").

## Deleting a bookmark in sheet view

Do the following:

1. In a sheet, click Bookmarks in the asset panel.
2. Click ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) next to the bookmark you want to delete and select Delete.
3. To confirm that you want to delete the bookmark, click Delete in the dialog.

The bookmark is deleted.

## Deleting a bookmark from application overview

Do the following:

1. From the application overview, click Bookmarks to view the bookmarks.
2. Click ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) next to the bookmark you want to delete and select Delete.
3. To confirm that you want to delete the bookmark, click Delete in the dialog.

The bookmark is deleted.

Tip noteIn the bookmarks dialog, you can right-click on a bookmark and select Delete.
