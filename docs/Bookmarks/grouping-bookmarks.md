# Grouping bookmarks

Organize bookmarks in the assets panel using grouping.

Application developers can group bookmarks in the assets panel. Groups are collapsible, allowing you to organize large numbers of bookmarks into a manageable hierarchy. Bookmarks can only belong to a single group. Groups are only available for public bookmarks. In shared spaces, you can publish private bookmarks to Public and add them to groups. In managed spaces, you cannot change the membership of groups.

You can reorder groups and the bookmarks within groups by clicking and dragging them.

Tip noteAs a best practice, it is recommended that for collaboratively developed applications, a single user manage bookmark groups.

## Adding bookmarks to groups

Do the following:

1. In the assets panel, do one of the following:

   - Right-click a bookmark in My own and select Publish to group.
   - Right-click a bookmark in Public and select Add to group.
2. Select a new group or an existing group.

Tip noteYou can also click and drag bookmarks into groups.

## Removing bookmarks from groups

Do the following:

- In the assets panel, right-click a bookmark in a group and select Remove from group.

Tip note

You can also click and drag bookmarks to remove them from groups.

## Renaming groups

Do the following:

1. In the assets panel, right-click a group and select Rename.
2. Enter a new name for the group.

## Ungrouping bookmarks

Do the following:

1. In the assets panel, right-click a group and select Ungroup.
2. Click Ungroup.

## Limitations

Grouped bookmarks have the following limitations:

- Grouped bookmarks are not supported in Qlik Sense Mobile. Bookmarks within groups will be displayed in the list of bookmarks alongside non-grouped bookmarks.
