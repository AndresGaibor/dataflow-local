# Dataset support in Qlik Cloud

Qlik Cloud supports a range of file types as datasets. Some types of datasets must be added from specific areas in Qlik Cloud however. The following table summarizes where you can add different datasets in Qlik Cloud.

Information note

QVS files can be added in:

- The Create page of the Analytics [activity center](#glossary-0 "Glossary term")
- Data manager
- Data load editor
- Script.

As they contain scripts and not data, however, they should only be used in Data load editor or Script.
