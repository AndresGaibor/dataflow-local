# Canceling data retrieval

When you use Qlik Sense to explore your data on a server, you might experience a delay. If the waiting time is long, a Cancel button displays on each [visualization](#glossary-0 "Glossary term"). Use the Cancel buttons to stop the data retrieval. You must stop each visualization separately. When you stop a data retrieval, a Retry button appears so you can try again.
