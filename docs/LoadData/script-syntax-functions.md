# Script syntax and chart functions

You can use statements and functions in the load script to load and transform data into your application or script. You can also use functions in visualization expressions to build dynamic visualizations.

## Load scripts

Qlik Cloud Analytics and Qlik Sense use a data load script to connect to and retrieve data from various data sources. In applications, the load script is managed in Data load editor. In scripts, the load script is managed in Script. In the script, the fields and tables to load are specified. You can also manipulate the data structure by using script statements, expressions, and variables.

## Visualization expressions

You can use expressions to process data in the application in order to produce a result that can be seen in a visualization. You can build visualizations that are more dynamic and powerful, with expressions for dimensions and measures. You can also use expressions to change the presentation of visualizations dynamically.
