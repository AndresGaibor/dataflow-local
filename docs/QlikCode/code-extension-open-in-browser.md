# Open applications in the browser

Qlik for VS Code provides commands to open analytics applications (or QVF script assets) in Qlik Cloud, without switching context manually.

Do the following:

1. In the VS Code [Explorer](https://code.visualstudio.com/docs/editing/getting-started/userinterface#_explorer-view), expand Qlik Cloud.
2. Find an application or (or QVF script asset), and right-click it.
3. Select Open in browser, and then choose one of the following:

   - Data Load Editor (for QVF script assets, this instead opens the Editor in Script)
   - Data Model Viewer in Browser (not applicable to QVF script assets)
   - App overview (not applicable to QVF script assets)
