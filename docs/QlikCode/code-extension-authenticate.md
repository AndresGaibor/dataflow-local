# Authenticate with Qlik Cloud

Qlik for VS Code needs to sign in to your Qlik Cloud tenant before you can browse or edit anything.

## Sign in

Do the following:

1. Open the [Explorer](https://code.visualstudio.com/docs/editing/getting-started/userinterface#_explorer-view) sidebar in VS Code. If you are not signed in, Qlik for VS Code shows a Qlik Cloud Login panel.
2. Enter your Qlik Cloud tenant URL and follow the sign-in prompt. Qlik for VS Code uses VS Code's built-in account sign-in flow (the same mechanism VS Code uses for GitHub or Microsoft accounts), so your session is managed by VS Code's Accounts menu alongside any other signed-in services.
3. Once signed in, the Qlik Cloud Login panel is replaced by the Qlik Cloud panel, showing the spaces and apps available to you.

## Sign out

Do the following:

- Run Qlik: Sign Out from Qlik Cloud from the [Command Palette](https://code.visualstudio.com/docs/editing/getting-started/userinterface#_command-palette), or use the equivalent entry in VS Code's Accounts menu.
