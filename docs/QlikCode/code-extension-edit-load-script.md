# Editing load scripts in Qlik for VS Code

Qlik for VS Code provides Qlik Script language support for .qvs files, whether you are editing a local working copy or inspecting a cloud-backed script.

This support includes:

- Syntax highlighting
- Autocomplete
- Hover help
- Diagnostics for script errors
- Code folding
