# Performing Qlik for VS Code commands

A Qlik for VS Code command is, simply put, any action that you perform in the interface. Qlik for VS Code commands can be used alongside native VS Code commands.

## How to perform commands

In the extension, you can perform commands in multiple ways:

- In the file browser and Qlik Cloud panel in the VS Code [Explorer](https://code.visualstudio.com/docs/editing/getting-started/userinterface#_explorer-view).
- On the text editing canvas—for example, right-clicking the canvas and accessing Qlik for VS Code actions.
- Using the [Command Palette](https://code.visualstudio.com/docs/editing/getting-started/userinterface#_command-palette). This provides a full list of all actions you can perform. Qlik for VS Code-specific commands are grouped under the Qlik section.
