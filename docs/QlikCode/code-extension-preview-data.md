# Preview data

The Data Preview panel shows live table data from the app in a dedicated panel alongside your Terminal and Output panels, so you can check the shape of your data without leaving Visual Studio Code. The Data Preview panel stays synchronized with your selection in the data model diagram.

Information noteNot applicable to QVF script assets.

Do the following:

1. Open the data model diagram for an application. See [*Visualize the data model*](code-extension-visualize-data-model.htm).
2. In the VS Code Panel (see [VS Code's user interface documentation](https://code.visualstudio.com/docs/editing/getting-started/userinterface)), go to Data Preview.
3. Choose which table you want to preview, either from the data model diagram or the Data Preview section itself.

   If the script changed since the last reload, Qlik for VS Code warns you that the data preview may be stale.
