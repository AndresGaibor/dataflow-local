# Settings reference

This page contains reference documentation for [settings](https://code.visualstudio.com/docs/configure/settings) related to the Qlik for VS Code extension.

Tip noteYou can find VS Code Settings under Extensions > Qlik for VS Code, or search for "Qlik for VS Code" in the Settings search box.

Settings overview—Qlik for VS Code

| Setting | Default | Description |
| --- | --- | --- |
| Qlik for VS Code: Default Working Copy Folder (qlikcode.defaultWorkingCopyFolder) | "qlik cloud" | The folder, relative to your workspace root, where Qlik for VS Code saves working copies downloaded from Qlik Cloud. Clear this setting to save copies directly in the [workspace](https://code.visualstudio.com/docs/editing/workspaces/workspaces) root instead. |
