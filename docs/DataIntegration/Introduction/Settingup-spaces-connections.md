# Setting up spaces and connections

In Qlik Talend Data Integration, spaces are designated areas used to organize content and control user access, while connections are the bridges used to access sources and targets.

## [*Working in spaces in Data Integration*](../DataSpaces/working-spaces.htm)

Data spaces are areas of Qlik Talend Data Integration that are used to create and store projects, connections, Data Movement gateways, and other content.

## [*Qlik Data Gateway - Data Movement*](../../Gateways/replication-gateway.htm)

Qlik Data Gateway - Data Movement facilitates data movement from your enterprise data sources and SaaS applications to supported targets, over a strictly outbound, encrypted and mutually authenticated connection.

## [*Setting up connections to data sources*](../Landing/connecting-data-2.htm)

Connect to a large number of SaaS applications and many databases.

## [*Setting up connections to targets*](../TargetConnections/data-project-connections.htm)

Connect to targets to facilitate data movement and various ELT operations, including data registration, data storage, transformations, and data mart creation.

## [*Setting up connections for knowledge marts*](../Landing/connecting-knowledge-mart.htm)

Connect to vector databases and LLM connections to use knowledge marts for structured and unstructured data.

## [*Set up connections to data catalogs*](../TargetConnections/data-catalog-connections.htm)

Data catalogs are supported as a target in projects writing to Iceberg tables and a necessary component for creating a Qlik Open Lakehouse.
