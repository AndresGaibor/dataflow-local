# Getting started with Qlik Talend Data Integration

Qlik Talend Data Integration provides a variety of data integration capabilities in support of your data architecture and analytics requirements.

## Setting up your Qlik Cloud tenant

Qlik Talend Data Integration is available in several subscription options of Qlik Talend Cloud. Qlik Talend Cloud also includes Talend capabilities. For more information, see [*Qlik Talend Cloud subscription options*](../../Admin/subscription-options-QTC.htm).

You need to set up a Qlik Cloud tenant with your Qlik Talend Cloud subscription. If you are migrating from Stitch to Qlik Talend Cloud you can find tools and information in the Migration Center.

## [*Deploying Qlik Cloud*](../../Introduction/qcs-for-owners-and-admins.htm)

To get started, choose the Qlik Talend Cloud subscription that best fits your needs, register for a subscription, and follow the steps for initial setup and configuration.

## [Migrating from Stitch to Qlik Talend Cloud](https://help.qlik.com/en-US/migration/Content/Migration/moving-from-stitch-to-QTC.htm)

The Migration Center provides you with the tools and information needed to prepare, manage, and execute a migration from Stitch to Qlik Talend Cloud.
