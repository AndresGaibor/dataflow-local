# API Contracts Management API

Use the public API to automate tasks in API Contracts.

The API Contracts public management API allows you to create, fetch, delete, or share your API
definitions. You can use it to automate these tasks with command line scripts and CI/CD
pipelines. For example, you can fetch your API to publish it to an API gateway.

For examples of the API in use, see [API Contracts Examples](ApiDesignerExamples.htm "The following use cases allow you to put into practice the features offered in API Contracts.").
