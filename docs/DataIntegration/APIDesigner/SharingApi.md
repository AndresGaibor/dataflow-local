# Sharing an API

API Contracts lets you share API contracts with users and groups.

You can share at
the repository level only. Sharing at the API contract or API contract version level is
not supported. For more information, see [Sharing an API repository](SharingApiRepository.htm "Share a repository with users or groups to give them full access to its content. This option applies only to repositories outside the Default repository.").

Users and user groups are managed in the Administration activity center. For more
information, see [*Administering Qlik Cloud*](../../Introduction/administer-deployment.htm).

Information noteNote: The feature Retrieve items without owners enables you to
reassign API contracts previously created by deleted users to an active connected user.
This option is only available for users that have the API Contracts -
Administrate permission enabled.

In the API Contracts
settings, click Launch job under Retrieve items
without owners. The job retrieves unassigned API contracts or projects
from former collaborators. You can then find them on your homepage and reassign them to
your team.![Retrieve items without owners option in the API Contracts settings.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/retrieve_items_without_owners.png)
