# Organizing API folders

You can organize your APIs into folders.

## Creating a folder

1. On the homepage, click New folder.
2. Enter a name and click Create.

   The name cannot contain any of the following characters: `" :
   < > \ | * ?`

   You can use slashes to create multiple subfolders like "sub/folder".
   There is a limit of 10 nested folders.

   ![New folder dialog box.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/new_folder_api.png)

A new folder is now created and opens on the general information page. You can
start adding APIs to the folder.

## Adding an API to a folder

You can add new or already existing APIs to your folders.

1. To add a new API in your folder:
   1. Access the general information page.

      This page opens automatically after creating your folder. You can
      also open it by clicking the name of your folder at the top of
      the left panel.
   2. Click New API.

      For more information, see [Creating a new API](WorkingWithNewApi.htm).

      ![New API button in the newly created folder.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/new_api_to_folder.png)
2. To add an existing API in your folder:
   1. On the left panel, click ![Menu](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/apis_menu.png) next to the API that you want to move in your
      folder.
   2. Click Move.
   3. Select the folder in which you want to move the API and click
      Move.

      ![Move dialog box.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/move_existing_api.png)

   Your API is visible in the folder you selected.

## Renaming a folder

1. On the left panel, click the ![Menu](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/apis_menu.png) button next to the folder that you want to rename and click
   Rename.

   ![Rename button.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/rename_folder.png)
2. Enter the new name and click Rename.

Your folder is renamed.

## Deleting a folder

You can delete a folder. However, if your folder's content is published or
shared, it is then impossible to delete the folder. First, make sure to move the
folder's content if needed.

1. On the left panel, click the ![Menu](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/apis_menu.png) button next to the folder that you want to delete and click
   Delete.

   If the folder is empty, it is immediately deleted.
2. To confirm your decision, enter the folder's name that you want to
   delete.

   ![Delete Folder dialog box.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/delete_folder_api.png)
3. Click Delete.

Your folder is deleted and removed from the left panel.
