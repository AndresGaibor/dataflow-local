# Sharing an API repository

Share a repository with users or groups to give them full access to its content.

Before sharing a repository, you must have created the repository or have permissions to share it.

1. In the left panel, click ![Repository actions menu](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/apis_menu.png) next to the repository name.
2. Click Share.
3. In the Sharing repository dialog box, select the user or
   group to grant access to the repository.

   ![Sharing repository dialog box.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/api-designer-sharing-repo.png)
4. Repeat with as many users or groups as necessary, then click
   Share.

The selected users and groups have full access to the repository. They can create,
update, copy, move, and delete folders, API contracts, and contract versions. They can
also share and unshare the repository.
