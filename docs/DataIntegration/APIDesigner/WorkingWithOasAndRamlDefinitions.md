# Working with OpenAPI Specification and RAML definitions

Create API definitions according to the OAS (formerly known as
Swagger) and RAML specifications.
The API Contracts editor allows you to use these specifications without knowing their
complicated syntax. From a single API design in API Contracts, you can export all types of API definitions.

## Import existing API definitions

If you have an existing API definition, API Contracts allows you to import the following
formats:

- OpenAPI Specification 3.0
- OAS/Swagger 2.0
- Availability-note[Deprecated](https://help.talend.com/r/en-US/Cloud/labels-on-talend-help-center/availability-deprecated)

  This content is deprecated.

  OAS/Swagger 1.2
- RAML 1.0

## Export your finished API

When you have finished designing your API, you can download the OAS/Swagger or RAML
directly to a file through the Export menu. You can also export
your API definition with Talend
extensions.
