# Using a path variable component

Add a path variable component to your resource path.

You have created a path variable component.

1. Open a resource or create a new one.
2. In the Path field, enter `/{` to
   show the drop-down list containing the available components.

   ![In this example, entering /pet/{ opens a drop-down list that contains the findByTags component.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/designer_use_path_variable.png)
3. Click the path variable you want to add.

The selected component is added to your resource. You can see it in the Path
variables section. In the Components view, you can
open your component and see the resources in which it is used.
