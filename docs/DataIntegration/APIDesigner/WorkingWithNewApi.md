# Working with a new API

## Creating a new API

Create a new API or work with an API example.

Information noteNote: For help on how to create a new API using AI Assistant, see [Creating an API with AI Assistant](CreatingANewApiWithAiAssistant.htm "You can create an API by interacting with an AI model using natural language. This option might help you to create the required API more rapidly.").

1. On the API Contracts
   homepage, click New API.
2. Select New API and click Empty API
   to design an API from scratch, or click Samples to choose
   one of the API examples provided.

   ![Create a new API dialog box.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/create_api_01_modal.png)
3. Enter a name and a version for your API.
4. Click Create.

A new API is now created and opens on the general information page. You can start
designing your API with the following procedures.

## Renaming an API

Change the name of an API in all its versions.

You are an owner or an editor of the API.

1. On the homepage, click ![Menu](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/apis_menu.png) next to the API that you want to rename and click
   Rename API.

   ![View of the Contacts API and the Menu icon.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/create_api_version_01_homepage.png)
2. Enter the new name and click Rename.

Your API is renamed and the change appears in all API versions.
