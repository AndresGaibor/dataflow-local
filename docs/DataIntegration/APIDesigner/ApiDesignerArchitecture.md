# API Contracts architecture

API Contracts
allows you to design, document, and share API definitions. By combining it the Administration activity center, you can
design, document, implement, and deploy your APIs.

## Cloud infrastructure

The cloud infrastructure includes the cloud applications.

- In API Contracts, you can
  design APIs or import existing definitions, publish their documentation and
  create mocks. You can then export your definitions in OpenAPI
  Specification/Swagger or RAML.
- In the Administration activity center,
  you can administrate roles, users, projects, and licenses. You can create new users
  for the cloud applications and assign them to custom groups. You can then define
  roles and assign them to your users. The Administration activity center is
  also used to import your license files.
