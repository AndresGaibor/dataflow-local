# API documentation

API Contracts allows you to document your API.
Documentation is an important step in the life cycle of an API. Writing and maintaining documentation can be difficult, but API Contracts allows you to get your documentation automatically.

## Who writes documentation and who reads it?

In API Contracts, you work in a team of API designers that are allowed to edit your API design. Your team members can contribute to the documentation of your API and generate a live preview.

Live Documentation can be shared with members of your team, partners, or anyone who might need to access it while it is still being developed.
