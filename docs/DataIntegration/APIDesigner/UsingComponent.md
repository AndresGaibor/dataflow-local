# Using a component

Add a component to your API definition.

You have created a component.

1. In your API, select the operation in which you want to add a component.
2. Click Use a component next to the corresponding
   element.

   ![View of the request parameter with Use a component button.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/designer_extract_as_component.png)
3. Select a component in the drop-down list.
4. Click Add.

The component is added to your definition. In the Components
tab, you can open your component and see the name of the operations that use it in the
Referenced by section.
