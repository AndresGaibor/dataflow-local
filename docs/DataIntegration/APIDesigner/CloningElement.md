# Cloning an element

Clone data types, resources, and operations to create complex APIs
faster.

You have created an API and at least one data type, resource, or operation.

1. Click the Clone button to the left of the name of your data
   type, resource, or operation.

   You can also do this by clicking the element and then clicking the menu in the
   top-right corner of the window.![Screenshot of the Clone button.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/designer_clone_element.png)

   A new element is created with the same parameters as the one you
   cloned.
2. Edit the parameters as needed.
