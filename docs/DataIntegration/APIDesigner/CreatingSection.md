# Creating a section

A section is used to group resources and data types together.

1. Click Create new in the top-right corner.

   ![Create new menu expanded.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/shows_the_menu_to_create_definition_elements_and_components.png)
2. Click Section.
3. Enter a Name for your section,
   `Contacts` for example, and enter a
   Description if needed.

   ![New section dialog box.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/creating_section.png)
