# Exporting a definition

Export your API definition in OAS/Swagger or RAML.

1. Open the API version you want to export.
2. Click Export.
3. In the Select a specification section, select either
   OpenAPI Specification or RAML.![Select a specification options](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/api-definition-specification.png)
4. In the Customize section:

   1. Select the Version and Format of
      the language in which you want to export your definition.
   2. Select whether you want to export your definition with Talend Extensions for OpenAPI Specification or Talend Annotations for RAML.![Customize options.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/api-definition-customize.png)
5. If needed, in the Select operations section, select the
   operations that you want to export.![Select operations options.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/api-definition-operations.png)
6. Click Export.

Your definition is exported and you can save it to a directory of your choice.
