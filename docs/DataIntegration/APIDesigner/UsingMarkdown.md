# Using markdown

Markdown is a simple markup language that allows you to enhance plain text by adding
formatting to it.

## Why should you use markdown?

With markdown, you can make plain text stand out by adding headers, bold, and italics,
images, links, and more.

API Contracts makes markdown easy, even for beginners. Thanks to the
built-in editor you do not need to know markdown syntax to use it.

There are different types of markdown, and API Contracts supports
[CommonMark](http://spec.commonmark.org/0.25), [tables](https://help.github.com/articles/organizing-information-with-tables/) and emojis, and a few others.

## Where can you use markdown?

You can use markdown in all description fields, as well as in text blocks.

An easy way to know if markdown is supported is when the markdown toolbar appears at the top of the text input box.

![When you write the description of an API for example, the markdown toolbar appears at the top of the text input box.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/markdowneditor.png)

Markdown-enabled text boxes allow you to enter full-screen mode with both markdown and
rendered views open at the same time. Just click the split window icon in the right part
of the markdown toolbar.
