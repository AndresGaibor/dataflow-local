# Creating a text block

A text block can be used to freely enter any text which can be placed anywhere in your API design.

1. Click Create new in the top-right corner.

   Information noteTip: If you want to create your text directly in a previously created
   section, you can do so by clicking the + button to the
   right of the section name.

   ![Create new menu expanded.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/shows_the_menu_to_create_definition_elements_and_components.png)
2. Enter a Title for your text.
3. Add a Section if needed.
4. Enter the Content of your text block.

   Information noteTip: You can format you text with markdown.
