# Using a response component

Add a response component to your operation.

You have created a response component.

1. Open an operation or create a new one.
2. In the Response section, click Use a
   component.

   ![Use a component button.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/designer_use_response_component.png)
3. Select a Status code.
4. In the Name drop-down list, select your component.
5. Click Add.

The selected component is added to your operation. In the
Components view, you can open your component and see the
operations in which it is used.
