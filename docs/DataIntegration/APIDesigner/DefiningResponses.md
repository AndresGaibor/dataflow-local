# Defining responses

Define one or several responses for your operation.

1. To add responses to your operation, click the name of the operation, scroll down to
   the Responses section and click
   Add.
2. Select a Status code and add a
   Description if needed.

   You can select:
   - A specific status code such as `200`.
   - A response range such as `2XX`.
   - A `Default` response.

   ![Responses section and Status code drop-down list.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/defining-responses-api.png)
3. To add a header, in the Headers section, click
   Headers.
4. Click Add header.

   ![Headers field in Responses section.](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/responses-headers-api.png)
5. Enter the following information:

   - Name: Start typing a name to see a drop-down list of
     headers.
   - Type: You can use a reusable data type.
   - More attributes are available to edit your header.

   ![Screenshot of the list of headers that start with "Content".](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ApiDesigner/defining_responses_1.png)
6. Click Add.
