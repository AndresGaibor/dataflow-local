# RECIPROCAL

Returns the reciprocal of the value (¹/ₓ).

## Syntax

```
RECIPROCAL(x)
```

## Arguments

| Name | Type | Description | Default Value |
| --- | --- | --- | --- |
| x | numeric |  |  |

## Returns

Returns a `double` value.

---

## Examples

| x | Output |
| --- | --- |
| 2 | 0.5 |
| 4 | 0.25 |
| 1 | 1 |
| 0 | null |
