# Mathematical functions

This section describes the following mathematical functions:

| Function | Description |
| --- | --- |
| [ABS](abs.htm) | Computes the absolute value of a number |
| [CBRT](cbrt.htm) | Computes the cube root of a number |
| [CEIL](ceil.htm) | Rounds a number up to the nearest integer |
| [CEILING](ceiling.htm) | Rounds a number up to the nearest integer |
| [DEGREES](degrees.htm) | Converts the specified radians to degrees |
| [EXP](exp.htm) | Computes Euler’s number raised to a certain power |
| [FLOOR](floor.htm) | Rounds a number down to the nearest integer |
| [GET\_SHARD\_NUMBER](get_shard_number.htm) | Returns the shard number of the output/lookup table |
| [LN](ln.htm) | Returns the natural logarithm of a number |
| [LOG](log.htm) | Return the logarithm of x to the given base |
| [LOG2](log2.htm) | Returns the base 2 logarithm of x |
| [LOG10](log10.htm) | Returns the base 10 logarithm of x |
| [MOD](mod.htm) | Returns the modulus (remainder) of one number divided by another |
| [MODULO](modulo.htm) | Returns the remainder of the first number divided by the second |
| [POW](pow.htm) | Raises one number to the power of another |
| [POWER](power.htm) | Raises one number to the power of another |
| [RADIANS](radians.htm) | Converts an angle in degrees to radians |
| [RAND](rand.htm) | Returns a pseudo-random value in the range 0.0 <= x < 1.0 |
| [RANDOM](random.htm) | Returns a pseudo-random value in the range 0.0 <= x < 1.0 |
| [RECIPROCAL](reciprocal.htm) | Returns the reciprocal of the value (¹/ₓ) |
| [ROUND](round.htm) | Rounds a number to the nearest integer or to a specified number of decimal places |
| [SIGN](sign.htm) | Returns the signum function of a number |
| [SORT\_VALUES](sort_values.htm) | Returns the values sorted in numerical order |
| [SQRT](sqrt.htm) | Computes the square root of a number |
| [TRUNCATE](truncate.htm) | Returns a number truncated to an integer or to a specified number of decimal places |
