# DEGREES

Converts the specified radians to degrees.

## Syntax

```
DEGREES(value)
```

## Arguments

| Name | Type | Description | Default Value |
| --- | --- | --- | --- |
| value | numeric |  |  |

## Returns

double

---

## Examples

| value | Output |
| --- | --- |
| 0 | 0 |
| 3.14159 | 180 |
| 6.28319 | 360 |
