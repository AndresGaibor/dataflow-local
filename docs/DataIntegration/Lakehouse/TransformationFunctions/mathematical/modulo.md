# MODULO

Returns the remainder of the first number divided by the second.

## Syntax

```
MODULO(x, y)
```

## Arguments

| Name | Type | Description | Default Value |
| --- | --- | --- | --- |
| x | numeric |  |  |
| y | numeric |  |  |

## Returns

The same as the input.

---

## Examples

| x | y | Output |
| --- | --- | --- |
| 5 | 2 | 1 |
| 5.3 | 2.2 | 0.8999999999999995 |
| 5 | -2 | 1 |
