# TO\_DOUBLE

Convert any numeric value to a Double precision floating point IEEE-754 number.

## Syntax

```
TO_DOUBLE(value)
```

## Arguments

| Name | Type | Description | Default Value |
| --- | --- | --- | --- |
| value | numeric | The numeric value to convert |  |

## Returns

Returns a `double` value.

---

## Examples

| value | Output |
| --- | --- |
| 3 | 3.0 |
| 3.5 | 3.5 |
