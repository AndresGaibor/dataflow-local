# CONCAT

Concatenates the given arguments.

This function provides the same functionality as the [SQL-standard concatenation operator](string.htm) (`||`).

## Syntax

```
CONCAT(STRING1, STRING2, ..., STRINGN)
```

## Arguments

#### **`STRING`**

Type: `string`

A string to concatenate.

## Returns

Type: `string`

The concatenation of all the `STRING` arguments.
