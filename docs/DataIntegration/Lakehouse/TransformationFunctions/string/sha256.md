# SHA256

Hashes the input value using `SHA-256`.

## Syntax

```
SHA256(input)
```

## Arguments

| Name | Type | Description | Default Value |
| --- | --- | --- | --- |
| input | string |  |  |

## Returns

Returns a `string` value.

---

## Examples

| input | Output |
| --- | --- |
| "Hello SHA" | `4ea3b17f15346417f4c9b2ff94a1bfe82de99fdb0bbd30dc4dca031ab920d5e4` |
