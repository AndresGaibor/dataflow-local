# SHA3\_512

Hashes the input using `SHA3-512`.

## Syntax

```
SHA3_512(input)
```

## Arguments

| Name | Type | Description | Default Value |
| --- | --- | --- | --- |
| input | string |  |  |

## Returns

Returns a `string` value.
