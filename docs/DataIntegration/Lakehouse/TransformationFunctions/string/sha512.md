# SHA512

Hashes the input value using `SHA-512`.

## Syntax

```
SHA512(input)
```

## Arguments

| Name | Type | Description | Default Value |
| --- | --- | --- | --- |
| input | string |  |  |

## Returns

Returns a `string` value.
