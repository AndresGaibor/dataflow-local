# REVERSE

Reverses the order of the characters within the given input string.

## Syntax

```
REVERSE(STRING)
```

## Arguments

#### **`STRING`**

Type: `string`

A sequence of characters.

## Returns

Type: `string`

`STRING` with its characters in reverse order.

---

## Examples

| STRING | Output |
| --- | --- |
| string | gnirts |
| a | a |
| abc | cba |
| 123 | 321 |
