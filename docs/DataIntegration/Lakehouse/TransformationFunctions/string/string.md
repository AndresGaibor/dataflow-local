# String functions

This section describes the following string functions:

| Function | Description |
| --- | --- |
| [BASE64\_DECODE](base64_decode.htm) | Decode a base 64 string into a string |
| [BASE64\_TO\_HEX](base64_to_hex.htm) | Converts a base 64 string into a hex string |
| [BYTES\_SUBSTRING](bytes_substring.htm) | Returns a substring of the input, using the offsets in bytes of the UTF-8 encoded byte representation. Partial characters and invalid UTF-8 code points are removed from the result |
| [CONCAT](concat.htm) | Returns the concatenation of string1, string2, ..., stringN |
| [DATE](date.htm) | Casts a string to a date |
| [JOIN\_ARRAYS](join_arrays.htm) | Joins any number of arrays by index using a MessageFormat pattern |
| [LENGTH](length.htm) | Returns the length of the string |
| [LOWER](lower.htm) | Converts the string to lowercase letters |
| [LPAD](lpad.htm) | Pad the input string to the left with a given padding string up until size |
| [LTRIM](ltrim.htm) | Returns the given string without leading whitespaces |
| [MD5](md5.htm) | Hashes the input using MD5 |
| [PARSE\_DATETIME](parse_datetime.htm) | Parses a string into a timestamp with time zone using a format |
| [REPLACE](replace.htm) | Replaces all instances of search with replace in input. If the search is empty, inserts replace in front of every character and at the end of the input |
| [REVERSE](reverse.htm) | Returns a string with the characters in reverse order |
| [RPAD](rpad.htm) | Pad the input string to the right with a given padding string up until size |
| [RTRIM](rtrim.htm) | Returns the given string without trailing whitespaces |
| [SHA1](sha1.htm) | Hashes the input using SHA-1 |
| [SHA256](sha256.htm) | Hashes the input using SHA-256 |
| [SHA3\_512](sha3_512.htm) | Hashes the input using SHA3-512 |
| [SORT\_VALUES](sort_values.htm) | Returns the values sorted in dictionary order |
| [SPLIT](split.htm) | Returns the given string split by the provided delimiter. Does not remove empty entries |
| [SPLIT\_TO\_RECORD](split_to_record.htm) | Returns the given string split by the provided delimiter |
| [STRING\_FORMAT](string_format.htm) | Format any number of inputs into a string using the given format |
| [STRIP\_MARGIN](strip_margin.htm) | For each line remove the prefix of control or whitespace characters followed by the given margin char |
| [STRIP\_PREFIX](strip_prefix.htm) | Remove the given prefix string from the beginning of the string |
| [STRIP\_SUFFIX](strip_suffix.htm) | Remove the given suffix string from the end of the string |
| [STRPOS](strpos.htm) | Returns the starting position of the first instance of a given substring within a string |
| [SUBSTR](substr.htm) | Extracts a substring of a certain length starting from a specified point within the given string |
| [SUBSTRING](substring.htm) | Extracts a substring of a certain length starting from a specified point within the given string |
| [TRANSLATE](translate.htm) | Translates the given value using a given dictionary |
| [TRIM](trim.htm) | Returns the given string without leading or trailing whitespaces |
| [TRIM\_CHARS](trim_chars.htm) | Returns the given string without leading or trailing characters |
| [UPPER](upper.htm) | Converts the string to uppercase letters |
| [UUID\_GENERATOR](uuid_generator.htm) | Returns UUID |
| [XX\_HASH](xx_hash.htm) | Hashes the input using xxHash |
