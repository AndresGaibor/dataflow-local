# SHA1

Hashes the input using `SHA-1`.

## Syntax

```
SHA1(input)
```

## Arguments

| Name | Type | Description | Default Value |
| --- | --- | --- | --- |
| input | string |  |  |

## Returns

Returns a `string` value.

---

## Examples

| input | Output |
| --- | --- |
| 'hello world' | `2aae6c35c94fcfb415dbe95f408b9ce91ee846ed` |
