# Comparison functions

Comparison functions evaluate two or more values against each other according to specified criteria to determine their relative relationship or ordering.

The following functions are available in Qlik Open Lakehouse:

| Function | Description |
| --- | --- |
| [GREATEST](greatest.htm) | Returns the greatest value of the list of arguments. |
| [LEAST](least.htm) | Returns the smallest value of the provided values. |
