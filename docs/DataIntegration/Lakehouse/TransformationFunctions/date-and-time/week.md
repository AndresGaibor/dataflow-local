# WEEK

Returns the [ISO week](https://en.wikipedia.org/wiki/ISO_week_date) of the year from timestamp.

Values range from **1** to **53**.

## Syntax

```
WEEK(timestamp)
```

## Arguments

| Name | Type | Description | Default Value |
| --- | --- | --- | --- |
| timestamp | timestamp |  |  |

## Returns

bigint

---

## Examples

| timestamp | Output |
| --- | --- |
| timestamp "2018-03-10 08:55:12.456" | 10 |
