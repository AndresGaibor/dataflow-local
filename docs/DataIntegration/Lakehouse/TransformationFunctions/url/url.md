# URL functions

This section describes the following URL functions:

| Function | Description |
| --- | --- |
| [TOP\_PRIVATE\_DOMAIN](top_private_domain.htm) | Returns the top private domain from a domain name. |
| [URL\_DECODE](url_decode.htm) | Un-escapes a URL-encoded value |
| [URL\_ENCODE](url_encode.htm) | Escapes a value by encoding it so that it can be safely included in URL query parameter names and values |
| [URL\_PARSER](url_parser.htm) | Parses the URI/URL into its component parts |
