# Spatial functions

This section describes the following spatial functions:

| Function | Description |
| --- | --- |
| [ST\_DISTANCE](st_distance.htm) | Calculates the two-dimensional cartesian minimum distance between two WKT formatted geometries in the units of the inputs |
| [ST\_WGS84\_DISTANCE](st_wgs84_distance.htm) | Calculates the distance between two WKT formatted points in meters in the WGS84 projection |
| [WKT\_SPATIAL\_CONTAINS](wkt_spatial_contains.htm) | Checks if the first WKT formatted spatial object contains the second |
| [WKT\_SPATIAL\_INTERSECT](wkt_spatial_intersect.htm) | Checks if the WKT formatted spatial objects intersect |
