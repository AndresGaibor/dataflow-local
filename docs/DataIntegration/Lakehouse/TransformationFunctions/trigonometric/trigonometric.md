# Trigonometric functions

This section describes the following trigonometric functions:

| Function | Description |
| --- | --- |
| [COS](cos.htm) | Computes the cosine of an angle in radians |
| [SIN](sin.htm) | Computes the sine of an angle in radians |
| [TAN](tan.htm) | Computes the tangent of an angle in radians |
| [TANH](tanh.htm) | Computes the hyperbolic tangent of a hyperbolic angle |
