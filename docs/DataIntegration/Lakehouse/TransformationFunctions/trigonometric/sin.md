# SIN

Evaluates the sine of the given number of radians.

## Syntax

```
SIN(X)
```

## Arguments

#### **`X`**

Type: `numeric`

A numeric value representing an angle in radians.

## Returns

Type: `double`

The sine of `X`.

---

## Examples

| X | Outputs |
| --- | --- |
| 1 | 0.8414709848078965 |
| -1 | -0.8414709848078965 |
| 0 | 0 |
| 0.5 | 0.479425538604203 |
