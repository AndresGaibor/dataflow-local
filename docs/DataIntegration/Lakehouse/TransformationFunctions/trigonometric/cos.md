# COS

Evaluates the cosine of the given number of radians.

## Syntax

```
COS(X)
```

## Arguments

#### **`X`**

Type: `numeric`

A numeric value representing an angle in radians.

## Returns

Type: `double`

The cosine of `X`.

---

## Examples

| X | Output |
| --- | --- |
| 1 | 0.5403023058681398 |
| -1 | 0.5403023058681398 |
| 0 | 1 |
| 0.5 | 0.8775825618903728 |
