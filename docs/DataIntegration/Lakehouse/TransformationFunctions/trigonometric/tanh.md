# TANH

Evaluates the hyperbolic tangent of the given hyperbolic angle.

## Syntax

```
TANH(X)
```

## Arguments

#### **`X`**

Type: `numeric`

A numeric value representing the magnitude of a hyperbolic angle.

## Returns

Type: `double`

The hyperbolic tangent of `X`.

---

## Examples

| X | Output |
| --- | --- |
| 1 | 0.7615941559557649 |
| -1 | -0.7615941559557649 |
| 0 | 0 |
| 0.5 | 0.46211715726000974 |
