# TAN

Evaluates the tangent of the given number of radians.

## Syntax

```
TAN(X)
```

## Arguments

#### **`X`**

Type: `numeric`

A numeric value representing an angle in radians.

## Returns

Type: `double`

The tangent of `X`.

---

## Examples

| X | Output |
| --- | --- |
| 1 | 1.5574077246549023 |
| -1 | -1.5574077246549023 |
| 0 | 0 |
| 0.5 | 0.5463024898437905 |
