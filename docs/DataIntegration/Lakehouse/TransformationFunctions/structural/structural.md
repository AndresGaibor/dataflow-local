# Structural functions

This section describes the following structural functions:

| Function | Description |
| --- | --- |
| [FROM\_KEY\_VALUE](from_key_value.htm) | Maps a list of key values to a record with fields for each key |
| [GET\_RANGE](get_range.htm) | Returns a range of numbers between start and end (inclusive) |
| [JOIN\_ALL\_BY\_KEY](join_all_by_key.htm) | Combines multiple key-value arrays into one by the keys |
| [JSON\_PATH](json_path.htm) | Extracts data from JSON objects |
| [JSON\_TO\_RECORD](json_to_record.htm) | Extracts data from JSON objects |
| [MAP\_WITH\_INDEX](map_with_index.htm) | Outputs an index and a value field. The index contains a zero-based index, and the value contains the value in the input field |
| [QUERY\_STRING\_TO\_RECORD](query_string_to_record.htm) | Extracts data from a query string |
| [RECORD\_TO\_JSON](record_to_json.htm) | Converts the record containing the field to a JSON string |
| [SORT\_BY](sort_by.htm) | Sorts the values array by the sortKeys array |
| [TO\_ARRAY](to_array.htm) | Outputs all the values from all the inputs as an array |
| [ZIP](zip.htm) | Combines multiple arrays by index into records |
| [ZIP\_WITH\_INDEX](zip_with_index.htm) | Combines multiple arrays by index into records |
