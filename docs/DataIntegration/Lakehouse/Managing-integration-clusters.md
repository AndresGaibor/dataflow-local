# Managing network integrations and lakehouse clusters

Create, view, edit, and manage network integrations and lakehouse clusters in the Administration activity center.

## Permissions

A tenant or data administrator can create and manage network integrations and lakehouse clusters from the Administration activity center.

## [*Managing network integrations*](manage-network-integrations.htm)

View, edit, and manage existing network integrations, and create new network integrations for your Qlik Open Lakehouse projects.

## [*Managing lakehouse clusters*](manage-clusters.htm)

Monitor the clusters within your tenant to check gateway status. Stop, start, roll, and scale existing clusters, and create new clusters.
