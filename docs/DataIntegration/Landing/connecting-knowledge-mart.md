# Setting up connections for knowledge marts

With Qlik Talend Data Integration, you can connect to vector databases, LLM connections, and file storage to use a knowledge mart.

Information noteYou need a Qlik Talend Cloud Enterprise subscription.

## Requirements

- You need a Qlik Talend Cloud Enterprise subscription.
- Supported on Snowflake and Databricks platforms. Snowflake Iceberg is not supported.
- A customer managed data gateway is required.

  Databricks requires Qlik Data Gateway - Data Movement version 2024.11.95 or higher.

## *[*Connecting to vector databases*](connecting-vector-databases.htm)*

Connect to vector databases when you want to use a knowledge mart.

## [*Connecting to LLM connections*](connecting-llm-connections.htm)

Connect to Large Language Models (LLM) connections when you use a knowledge mart.

## *[*Connecting to file storage*](connecting-file-storage.htm)*

Connect to file storage when you want to use a knowledge mart.
