# Setting up connections to data sources

With Qlik Talend Data Integration, you can connect to a large number of data sources to onboard data to a cloud platform or replicate data. Data sources include SaaS applications, databases, cloud data warehouses, and SAP. You connect to a data source by creating a connection in the Qlik Talend Data Integration activity center.

Information noteThe available target update methods (CDC, full load, and others) are determined by both the data task type and the connector certification. For more information, see [*Target update methods*](../SourcesConnections/Change-processing.htm).

## [*Connecting to SaaS applications*](connecting-web-applications.htm)

Connect to a large number of SaaS applications, such as Salesforce, Workday, and Google Analytics.

## [*Connecting to databases*](connecting-data-source-dmg.htm)

Connect to databases such as MySQL, Oracle, Microsoft SQL Server, PostgreSQL, and SAP.

## [*Connecting to SAP sources*](connecting-sap-sources.htm)

Connect to SAP sources such as SAP OData, SAP Extractor, and SAP Concur.

## [*Requesting new connectors*](Connector-factory-request-form.htm)

The Connector Factory Request Program streamlines the process and time line to develop a new Qlik connector, thus enabling Qlik to rapidly respond to customer requests for access to new sources.
