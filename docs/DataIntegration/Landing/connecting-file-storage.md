# Connecting to file storage

You can connect to file storage when you create knowledge marts in Qlik Talend Data Integration. For more information, see [*Creating knowledge marts*](../KnowledgeMart/Creating-knowledge-marts.htm).

Information noteYou need a Qlik Talend Cloud Enterprise subscription.

To connect to file storage, set up Data Movement gateway. For more information, see [*Setting up Qlik Data Gateway - Data Movement for knowledge marts*](../../Gateways/gateways-for-knowledge-mart.htm).
