# Connecting to LLM connections

You can connect to Large Language Models (LLM) connections when you create knowledge marts in Qlik Talend Data Integration. For more information, see [*Creating knowledge marts*](../KnowledgeMart/Creating-knowledge-marts.htm).

Information noteYou need a Qlik Talend Cloud Enterprise subscription.

To connect to LLM connections, set up Data Movement gateway. For more information, see [*Setting up Qlik Data Gateway - Data Movement for knowledge marts*](../../Gateways/gateways-for-knowledge-mart.htm).

For more information about the configuration, see the settings in [Creating a knowledge mart](../KnowledgeMart/Creating-a-knowledge-mart.htm) and [Creating a file-based knowledge mart](../KnowledgeMart/Creating-file-based-knowledge-mart.htm).
