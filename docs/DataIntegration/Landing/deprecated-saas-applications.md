# Deprecated SaaS applications

The connectors listed in this section are deprecated, and cannot be used to create new tasks. Although deprecated, the connectors remain fully supported, and tasks which are already using these connector will continue to work as usual. For new tasks, use the enhanced corresponding connector that is referenced at the start of each deprecated connector topic.

For more information about connecting to SaaS applications, see [*Connecting to SaaS applications*](connecting-web-applications.htm).
