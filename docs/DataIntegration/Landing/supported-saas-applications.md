# Supported SaaS applications

You can land data from a large number of SaaS applications in Qlik Talend Data Integration.

For more information about connecting to SaaS applications, see [*Connecting to SaaS applications*](connecting-web-applications.htm).

Information noteSome SaaS application connectors have been deprecated and replaced with newer versions of the same connector. Deprecated connectors will continue to work with existing tasks, but cannot be used in new tasks. For more information, see [*Deprecated SaaS applications*](deprecated-saas-applications.htm).

The following applications are supported as data sources.
