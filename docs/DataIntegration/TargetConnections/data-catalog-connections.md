# Set up connections to data catalogs

The following data catalogs are supported targets in Qlik Open Lakehouse projects.

When working with Qlik Open Lakehouse, a data catalog is required to organize and manage the metadata associated with your Apache Iceberg tables. The catalog acts as the central target for your lakehouse project, storing the schemas of your tables along with references to the underlying data files. By maintaining this information, the catalog makes it possible to discover, validate, and query data across your lakehouse environment. Qlik Open Lakehouse supports integration with the following catalogs:
