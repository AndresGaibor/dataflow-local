# Supported data types

The following table shows the supported SAP ODP source data types (ABAP) and their default mapping to Qlik Talend Data Integration data types.

For information on how the data type is mapped to the target, see the topic for the target connector you are using.

Supported data types

| ABAP data type | Qlik Talend Data Integration data type |
| --- | --- |
| ACCP | DATE |
| CHAR | STRING |
| CLNT | STRING |
| CUKY | STRING |
| CURR | NUMERIC |
| DATS | DATE |
| DEC | NUMERIC |
| FLTP | REAL4 |
| INT1 | INT1 |
| INT2 | INT2 |
| INT4 | INT4 |
| INT8 | INT8 |
| LANG | STRING |
| NUMC | STRING |
| QUAN | NUMERIC |
| RAW | STRING |
| SSTR | STRING |
| STRG | CLOB |
| TIMS | TIME |
| UNIT | STRING |
| VARC | STRING |
