# Supported data types

The following table shows the supported SAP Extractor source data types and their default mapping to Qlik Talend Data Integration data types.

For information on how to view the data type that is mapped in the target, see the section for the target connector you are using.

Supported data types

| ABAP Data Type | Qlik Talend Data Integration Data Type |
| --- | --- |
| ACCP | DATE |
| CHAR | STRING |
| CLNT | STRING |
| CUKY | STRING |
| CURR | NUMERIC(15.2) |
| DATS | DATE |
| DEC | REAL8 |
| FLTP | REAL4 |
| INT1 | INT1 |
| INT2 | INT2 |
| INT4 | INT4 |
| LANG | STRING |
| NUMC | STRING |
| QUAN | REAL8 |
| RAW | BYTES |
| STRG | CLOB |
| TIMS | TIME |
| UNIT | STRING |
| VARC | STRING |
