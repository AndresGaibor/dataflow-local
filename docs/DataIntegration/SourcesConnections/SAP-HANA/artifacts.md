# Removing Data Movement gateway artifacts from the database

In order to capture changes, Data Movement gateway creates various artifacts in the SAP HANA database when the task starts. When the task completes, you can safely remove these artifacts.

For information on the Data Movement gateway artifacts, see [*Capturing data changes*](prereq_saphana.htm#Change).
