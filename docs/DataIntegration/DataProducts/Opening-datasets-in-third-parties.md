# Opening datasets in third parties

You can open a dataset in Databricks from Qlik Talend Data Integration, and quickly display and manage your source data.

Information noteYou need one of the following subscriptions:

- Qlik Talend Cloud Enterprise
- Qlik Talend Cloud Premium
- Qlik Cloud Analytics Premium
- Qlik Cloud Analytics Enterprise
- Qlik Sense Enterprise SaaS

1. Open the dataset.
2. In the right, click ![Actions icon](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more_horizontal.png) > Open in Databricks.

   ![Open in Databricks](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/dataset-open-in.png)

   Databricks opens in a new tab and you can manage the source data.
