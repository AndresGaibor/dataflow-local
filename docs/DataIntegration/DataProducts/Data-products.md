# Working with data products

A data product is an entity that allows you to gather, and package trusted datasets related to the same domain, or any grouping that makes sense for your business.

Information noteYou need one of the following subscriptions:

- Qlik Talend Cloud Enterprise
- Qlik Talend Cloud Premium
- Qlik Cloud Analytics Premium
- Qlik Cloud Analytics Enterprise
- Qlik Sense Enterprise SaaS

![Overview of a data product](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/data-product.png)

Using datasets from your Catalog, start building data products and make them available to use in Analytics applications.

Data products can include a semantic model that defines relationships, measures, and dimensions for the datasets. Semantic models enable analytics developers to consume pre-built data structures and business metrics in their applications. For more information, see [*Semantic models in data products*](semantic-models-in-data-products.htm).

Most data product actions can also be performed through the corresponding [Qlik Public API](https://qlik.dev/apis/rest/data-governance/data-products/).

In a data product, you can work in different tabs:

- Overview, where you can review datasets, metadata, and quality indicators.
- Semantic model, where you can create and manage relationships, measures, and dimensions.
- Documentation, where you can manage the Read me section and key contacts.

When datasets are grouped in a data product, you can see in the Overview tab:

- A description of the data product, which can be entered manually or generated by AI. See [*Generating an AI-based description*](Generating-AI-based-description.htm).
- The overall Qlik Trust Score™ for the data product, calculated as the average of the trust scores of all included datasets. See [*Qlik Trust Score™*](Qlik-Trust-score.htm).
- A pending changes indicator, showing the number of unpublished changes (for example, "3 changes") if the data product is activated and has been modified. Pending changes are not visible to consumers until you update the marketplace. See [*Updating the data product in the marketplace*](../Marketplace/Updating-the-marketplace.htm) to learn how to publish changes.
- A list of all datasets in the data product, showing each dataset’s trust score, freshness, and associated space. Datasets that are greyed out are not accessible to you, contact their owners for access. See [*Browsing datasets from the Catalog*](Browsing-datasets-from-catalog.htm).

  Next to each dataset, the contextual menu ![](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more_horizontal.png) lets you view the dataset schema, examine lineage and impact analysis, refresh the quality, and view the Qlik Trust Score™ history. You also have the option to create an application based on this dataset, or access Databricks lineage for Databricks datasets.

  Next to each column, the contextual menu ![](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more_horizontal.png) lets you manage columns by hiding or adding columns depending on your needs. You can use this feature to display the Qlik Trust Score™ dimensions.
- The added tags, key contacts, owner, space, and regulations associated with this data product.
- The applications and activated API endpoints that are based on this data product. See [*Consuming data products through APIs*](Consuming-data-products-through-apis.htm).
- Additional metadata, including relevant timestamps such as "last activated," "metadata modified," and "metadata created".

From a data product, you can also request access to datasets that are in spaces to which you do not have access. See [Requesting access to spaces](../DataSpaces/manage-data-space.htm#requesting-access).

## Navigating the Data products menu

Information noteYou need the permission to manage data products.

From the Data products menu, you are able to create data products, document them, and enrich them with certified datasets. You can then activate them to the data marketplace.
![Data product menu](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/data-products-menu.png)

## Navigating the data marketplace

The central place to see your active data products is the Data marketplace where you can use them as source for analytics applications.

The data marketplace let you see all the active data products in one place. You can only see the data products that are in a space to which you have access.

![View of the data marketplace](../../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/data_marketplace_menu.png)
