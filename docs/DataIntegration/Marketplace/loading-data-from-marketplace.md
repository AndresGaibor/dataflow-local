# Loading data from the data marketplace

You can load data into your application from an existing data product that you can access in the data marketplace.

You can access the data marketplace from the [*Analytics activity center*](../../QlikCloudNavigation/Analytics-activity-center.htm). This is the central place to manage data products which are entities that allow you to gather, and package trusted datasets related to the same domain, or any grouping that makes sense for your business. For more information, see [*Working with data products*](../DataProducts/Data-products.htm).

Information noteYou need one of the following subscriptions:

- Qlik Talend Cloud Enterprise
- Qlik Talend Cloud Premium
- Qlik Cloud Analytics Premium
- Qlik Cloud Analytics Enterprise
- Qlik Sense Enterprise SaaS

Prerequisite: You have access to managed spaces where data products are activated.

For more information about loading data products into applications, see [*Consuming data products in applications*](../DataProducts/consuming-data-products-apps.htm).
