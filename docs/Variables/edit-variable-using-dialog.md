# Editing a variable

You can edit [variables](#glossary-0 "Glossary term") from the variables dialog.

Do the following:

1. When editing a sheet, click ![Variables](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_variables_outline.svg) in the edit bar on the sheet to open the variables dialog.

   The variables dialog opens.
2. In the row of the variable you want to edit, click ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) and select Edit.
3. Edit the variable as desired.
4. Click Save.

## Editing script variables

If you update a script variable during a user session—that is, in the application interface, without reloading the application—the updated variable definition is temporary and unique to you. After your session expires, the variable definition returns to its original value as per the last reload. Also, if you reload the application, your changes will be undone.
