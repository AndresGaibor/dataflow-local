# Scripting to load or export data

You can choose between two script editing experiences in Qlik Cloud Analytics. In analytics applications, you use Data load editor. In scripts created in the catalog, you use the editor in Script.

Otherwise, both editors offer a similar script editing experiences. In the script editor, you add or connect to your data sources and select data to load. You can then edit your load script to transform the data. You can then run the load script to either load data into your application or to export data from your script.
