# Requesting application access

You can request access to apps that you don’t have permission to open.

When you try to open an application through a shared link without permission, and access request page appears. The space owner and members with the Can manage role receive your request and can approve or deny it. They can grant access only to the application or to the entire space, which also gives you access to other content in that space.

## Requesting access to an application

You can request access when you click a link to an application (for example, shared via email or chat), the application is in a shared or managed space, and you don’t currently have permission to open it.

Do the following:

1. Click the link to the application.
2. If you don’t have permission, the access request page opens.

   Access request page where you can enter a message and send a request.

   ![The page where you can send an access request.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_request_access_start.png "Click to view full size")
3. Enter a short message explaining why you need access.
4. Click Send request.

## What happens after you send a request

Approvers receive a notification and can approve or deny your request. Approval can be:

- Application access: You can view the application only.
- Space access: You are added to the space with specific roles, giving you access to the application and all other content in the space.

You receive a notification if your request is approved. If no action is taken, requests expire after six months. Sending a new request replaces the previous one.

For more information about access approval, see [*Approving access requests*](approving-access-requests.htm).

### Managing notifications for access requests

To change notifications for when you are invited to an application or space:

1. Go to your personal settings and select Notifications.
2. In the Spaces section, turn on or off notifications for I am invited to new content.

For more information, see [*Notifications*](../Introduction/profile-settings.htm#Notifica)
