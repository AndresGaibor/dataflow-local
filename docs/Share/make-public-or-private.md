# Granting access to sheets, sheet groups, bookmarks, and stories

In the application overview, you can make [sheets](#glossary-1 "Glossary term"), sheet groups, [bookmarks](#glossary-2 "Glossary term"), and [stories](#glossary-3 "Glossary term") public or private. You can also re-order sheets and stories.

To be able to see public sheets, sheet groups, bookmarks, and stories, you need Can view permissions in the associated shared space.
You can also view public content in individual applications that have been shared with you. To be able to make these items public or private in a shared space, you need Can edit or higher permissions in the space.

For information about required permissions for publishing and making application content private in a managed space, see [*Managing permissions in managed spaces*](../Spaces/managing-managed-spaces.htm).

New items added to the application overview are always private. Private items are only visible to you. If you make an item public, you are no longer the owner. If you make an item private, you become the owner.

You can reorder sheets and stories by dragging them.

Information noteIf you can't drag sheets to re-order them, disable Touch screen mode. Click the navigation button (![Navigation](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg)) and use the toggle for ![Touch screen mode](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_touch_outline.svg).

## Making application content public in shared spaces

To make private sheets, sheet groups, bookmarks, and stories public, you need one of the following roles in the shared space:

- Owner
- Can manage
- Can edit

In user-based subscriptions, these permissions apply only to users with a Professional user entitlement.

For more information, see [*Managing permissions in shared spaces*](../Spaces/managing-shared-spaces.htm).

The following procedure shows how to make a private sheet public. The same process is used for making private sheet groups, bookmarks, and stories public.

Do the following:

1. Open the application overview and ensure the correct tab is open (for your sheets, this is Sheets. It will be different for Bookmarks or Stories.).
2. Under My sheets, find the sheet you want to make public.
3. Right-click the sheet, and choose Make public in the drop-down.

   Make sheet public

   ![Using the dropdown to make a sheet public.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_gen_make_public_sheet_rev.png "Click to view full size")

Tip note

For apps in personal and shared spaces, you can also make sheets public by dragging them to the Public section in the application overview.

Your sheet is now public. You are no longer the owner.

## Making application content private in shared spaces

To make public sheets, bookmarks, and stories private, you need one of the following space roles in the [shared space](#glossary-4 "Glossary term"):

- Owner
- Can manage
- Can edit

The following procedure shows how to make a public sheet private. The same process is used for making public bookmarks and stories private.

Do the following:

1. Open the application overview and ensure the correct tab is open (for your sheets, this is Sheets. It will be different for Bookmarks or Stories.).
2. Under Public sheets, find the sheet you want to make private.
3. Right-click the sheet, and choose Make private in the drop-down.

Tip note

For apps in personal and shared spaces, you can also make sheets private by dragging them to the Private section in the application overview.

You are now the sheet owner.

## Adding community content in managed spaces

In an application that has already been published to a managed space, you can publish and unpublish new sheets, bookmarks, and stories to and from the Community. To perform these actions, you must have the required space role and entitlement in the space. For more information, see [*Managing permissions in managed spaces*](../Spaces/managing-managed-spaces.htm).

Content that is public in the source application when it is published becomes the base content for the application. It cannot be made private, but sheets and stories can be duplicated as private copies by users with sufficient permissions.

For more information about navigating managed spaces, see [*Using applications in managed spaces*](../Spaces/managing-apps-in-managed-spaces.htm).

### Publishing application content to Community

The following procedure shows how to publish a private sheet to the Community. The same process is used for publishing private bookmarks and stories.

Do the following:

1. Open the application overview and ensure the correct tab is open (for your sheets, this is Sheets. It will be different for Bookmarks or Stories.).
2. Under My sheets, find the sheet you want to publish to the Community.
3. Right-click the sheet, and choose Publish in the drop-down.

### Removing application content from Community

The following procedure shows how to unpublish a Community sheet and make it private. The same process is used for unpublishing Community bookmarks and stories.

Do the following:

1. Open the application overview and ensure the correct tab is open (for your sheets, this is Sheets. It will be different for Bookmarks or Stories.).
2. Under My sheets, find the sheet you want to unpublish from the Community.
3. Right-click the sheet, and choose Unpublish in the drop-down.
