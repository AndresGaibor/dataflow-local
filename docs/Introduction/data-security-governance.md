# Managing data governance and transfers

Data security and management ensure your applications and data are organized, secure, and accessible. Several tools are available in Qlik Cloud to manage data access, governance, and secure transfers.

## [*Managing spaces*](../Admin/mc-administer-spaces.htm)

Data security and governance in Qlik Cloud are managed through spaces, which organize, enable collaboration, and define access to applications and data.

## [*Data gateways*](../Gateways/setting-up-gateways.htm)

Data gateways provide secure access to data behind a firewall.

## [*Installing Qlik DataTransfer*](../QlikDataTransfer/install-Qlik-DataTransfer.htm)

Qlik DataTransfer enables seamless uploads of data from on-premises sources without requiring firewall tunneling.
