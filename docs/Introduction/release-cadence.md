# Qlik Cloud Analytics release cadence

Qlik is committed to providing the best experience for our end-users, from consumers to creators and everyone in between. We aim to do this in a variety of ways, including continuous deployment of the latest innovations, current product enhancements, bug fixes, and more.

At Qlik, we pride ourselves on multichannel communication efforts via Qlik Community, help.qlik.com, in-product messaging, the customer portal, and more. Start by exploring the product information located on [Qlik Community](https://community.qlik.com/t5/Qlik-Resources/ct-p/qlik-company).

## Qlik Cloud Analytics release types

Our Qlik Cloud Analytics platform features the following kinds of releases:

- Qlik Cloud Analytics Feature Releases
- Qlik Cloud Analytics Technical Releases
- Qlik Cloud Analytics Significant Changes

### Qlik Cloud Analytics Feature Releases

Most Qlik Cloud Analytics feature releases deploy on Tuesdays. These releases potentially introduce either new or changing behavior to the end-user. These changes will not always be universal for all end-users. Multiple factors such as user type, account type, license type all have an influence on how new features may impact you. To help our end-users with the deployment of new features, documentation updates are published to [Qlik Help](https://help.qlik.com/en-US/cloud-services/Subsystems/Hub/Content/Sense_Hub/Introduction/analyzing-data.htm) on Tuesdays to accompany these releases. Additionally, details for each feature can be found in our weekly [What’s new in Qlik Cloud](https://help.qlik.com/en-US/cloud-services/Subsystems/Hub/Content/Sense_Hub/Introduction/saas-change-log.htm).

### Qlik Cloud Analytics Technical Releases

All Qlik Cloud Analytics technical releases are deployed throughout the week and are intended to be transparent to our customers. These mostly consist of service and maintenance deployments to ensure that our platform is always at peak performance for our end-users.

### Qlik Cloud Analytics Significant Changes (Qlik Cloud Government only)

For Qlik Cloud Government customers, "significant changes" refer to updates within the Qlik Cloud Government environment that require additional review as part of FedRAMP and DISA requirements. These changes may be comprised of any Qlik Cloud Analytics release type, with varying review timelines. Significant changes will be deployed based on a defined schedule once approved.

## Client-managed releases

Client-managed releases are scheduled twice a year, the first release deploying in May and the second release deploying in November.

All download files for both initial release and patch releases can be found on [Product Downloads](https://community.qlik.com/t5/Download-Qlik-Products/tkb-p/Downloads).
