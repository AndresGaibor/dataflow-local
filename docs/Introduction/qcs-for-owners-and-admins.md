# Deploying Qlik Cloud

The Qlik Cloud infrastructure is hosted and managed by Qlik. To get started, choose the Qlik Cloud Analytics or Qlik Talend Cloud subscription that best fits your needs, register for a subscription, and follow the steps for initial setup and configuration.

## Getting started with Qlik Cloud

### [*Registering for a subscription*](qcs-register.htm)

Register for a subscription to start using Qlik Cloud Analytics, Qlik Talend Cloud, or Qlik Anonymous Access.

### [*Creating and configuring your tenant*](qcs-tenant-domain.htm)

Request your Qlik tenant domain and configure your deployment.

### [*Accessing the Administration activity center*](../Admin/management-console.htm)

Manage and configure your tenant from the Administration activity center.

### [*System requirements and supported browsers*](qcs-supported-browsers.htm)

Review the system requirements and the supported web browsers.

## Adding users and assigning tenant administrators

### [*Understanding administrator roles and responsibilities*](qlik-sense-admin-roles.htm)

Learn about the key responsibilities of different administrator roles.

### [*Adding users to Qlik Cloud*](../Admin/SaaS-invite-users-capacity-model.htm)

Invite users to your tenant via email using the default identity provider (IdP), or configure a corporate IdP for user authentication and login.

### [*Assigning security roles and custom roles*](../Admin/SaaS-roles-capacity-model.htm)

The service account owner is the default tenant administrator upon tenant creation. Assign the Tenant Admin role to users who need full access for setup and tenant management.
