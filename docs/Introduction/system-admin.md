# Configuring features and integrations

Enable and configure various functionalities to manage and optimize the platform, facilitating application generation, sharing, and subscriptions for users.

## Configuring system features

### [*Enabling cross-region inference*](../Admin/cross-region-data-processing.htm)

Opt in to temporarily process your data in other regions, enabling features such as Qlik Answers that require cross-region access.

### [*Enabling and managing data alerts*](../Admin/mc-managing-alerts.htm)

Enable or disable the alerting functionality, as well as toggle individual alerts on or off.

### [*Administering reporting and subscriptions*](../Admin/mc-administer-subscriptions.htm)

Enable or disable the reporting functionality, as well as manage users’ subscriptions to reports.

### [*Configuring announcement banners*](../Admin/configure-announcement-banner.htm)

Configure tenant-wide banners to display important messages to all users, such as system notices or scheduled maintenance alerts.

### [*Configuring session timeouts*](../Admin/configure-session-timeout.htm)

Set session inactivity timeouts and maximum session duration for your tenant.

### [*Enabling note creation*](../Admin/mc-managing-notes.htm)

Enable or disable creation and sharing of notes on a per-user basis.

### [*Setting access to the Qlik Analytics mobile app*](../Admin/mobile-set-access.htm)

Enable or disable offline functionality to allow users to download applications to mobile devices and work without internet access.

### [*Enabling on-demand data in applications*](../Admin/mc-administer-odag.htm)

Enable or disable on-demand application generation and dynamic views in the tenant.

### [*Displaying content usage metrics*](../Admin/mc-usage-metrics.htm)

Enable or disable metrics showing the number of users who have opened content.

### [*Configuring dataset preview size*](../Admin/mc-dataset-preview-size.htm)

Configure how many rows are shown when previewing datasets.

### [*Configuring Data Integration features*](../Admin/mc-manage-DI-features.htm)

Enable features in Data Integration

### [*Providing application-opening progress*](../Admin/mc-open-app-progresss.htm)

Enable real-time progress to users when they open an application.

### [*Session replay in Qlik Cloud*](session-replay.htm)

Session replay helps Qlik to better understand how customers use its products, and in turn helps to deliver improvements to these products. Turn on session reply to allow Qlik to track certain user interactions, such as where they click and encounter friction. No customer data or content is collected.

## Managing integrations

### [*Configuring email for reports and notifications*](../Admin/mc-configure-email-support.htm)

Set up an email server to enable users to generate and subscribe to reports, share charts, and receive notifications.

### [*Securing and configuring the Qlik Analytics mobile app with Microsoft Intune*](../Admin/configure-mobile-app.htm)

Set up and secure the Qlik Analytics mobile app for your organization using Microsoft Intune.

### [*Adding connections to external collaboration platforms*](../Admin/mc-collaboration-platforms.htm)

Configure external collaboration environments to connect to your Qlik Cloud tenants, allowing external interaction with your application content with conversational analytics.

### [*Managing installation manifests for Qlik add-ins for Microsoft Office*](../Admin/mc-administer-add-in.htm)

Obtain the file that you and others can use to install Qlik add-ins for Microsoft Office. These add-ins are used to build report templates in Excel, PowerPoint, and Word format.
