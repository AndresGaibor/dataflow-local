# JDBC databases

You can deliver data efficiently into Qlik Cloud from databases accessed through supported JDBC (Java Database Connectivity) drivers.

You do not need to create a DSN connection before connecting to the JDBC database.

[*Create connections and load data from JDBC databases*](JDBC-create-load.htm)

## Databases

The following databases are supported:

- Cassandra versions 3.0 to 4.1
- Couchbase versions 4.0 to 6.0
- SAP HANA
