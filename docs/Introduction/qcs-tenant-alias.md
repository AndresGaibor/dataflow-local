# Configuring a tenant alias

You can define an alias for your tenant, providing users with two options to access it. The original tenant name is automatically assigned when the service account owner (SAO) sets up the account. The alias can be configured or changed at any time to better represent your organization.

The tenant hostname remains unchanged and serves as a secure way to access your tenant and for recovery purposes. To find your tenant hostname, click your user profile icon, select About, and view the information in the dialog that appears. The hostname is listed there.

As a tenant administrator, you can:

- Update the Alias hostname and log in using the new alias.

  Information noteAfter changing the tenant alias, users will need to update their bookmarks to reflect the new alias. Be sure to communicate the updated alias to all users.
- Remove the Alias hostname.
- Update the Display name of your tenant.

Information noteTrial subscriptions of Qlik Sense Business or Qlik Cloud Analytics Standard allow updating the Display name but not setting an Alias hostname.

For a visual demo about how to configure a tenant alias, see [Configuring a tenant alias](https://share.vidyard.com/watch/8Bh6Q8Dt5qyJcCmhqAqR9i)

To configure or change your tenant alias, do the following:

1. Log in using the original hostname.
2. In the Administration activity center, go to the Settings page, then select the Tenant tab.
3. In the General section, enter or change the value for Alias hostname.
4. Optionally, update the Display name.
5. Navigate to hostname alias and log in to verify that the tenant works with the alias.
