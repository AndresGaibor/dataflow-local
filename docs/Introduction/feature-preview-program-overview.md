# Feature preview

Feature preview gives you early access to upcoming features before they become generally available. With feature preview, you can explore new capabilities, provide feedback, and help shape the future of Qlik Cloud.

## What are preview features

Preview features are new features that we make available before general availability. These features are production-ready but may change based on customer feedback and real-world usage. Preview features let you:

- Test new functionality in your environment
- Provide feedback that influences product direction
- Prepare for upcoming changes before general availability
- Ensure a smooth transition when features become generally available

## How preview features differ from generally available features

Preview features differ from generally available features in the following ways:

- Opt-in model: You must explicitly activate preview features. They are not activated by default.
- Subject to change: Functionality, behavior, and user interface elements may be modified based on feedback.
- Permission-based access: Permissions determine whether you can view and activate preview features.
- Limited documentation: Documentation for preview features may be less comprehensive than for generally available features.

Tenant-level controls and permissions are managed by tenant administrators. For more information, see [*Managing feature preview for your tenant*](../Admin/mc-manage-preview-features.htm).

Warning notePreview features are activated by default in [Talend Studio](https://help.qlik.com/talend/en-US/studio-user-guide/8.0/what-is-talend-studio) and do not depend on permissions. You cannot deactivate preview features.

## Activating and deactivating preview features

Information note

To activate preview features, your tenant administrator must enable feature preview for the tenant and grant you the required permissions.

You can activate or deactivate preview features from your user profile.

Do the following:

1. Click your user profile in Qlik Cloud and select ![Feature preview](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_feature_preview_outline.svg) Feature preview.
2. Read the description for each preview feature to understand what it does.
3. Turn the Activate toggle on or off for a preview feature.
4. Click Refresh now to apply the changes.

Available preview features and activations controls

![Preview dialog with available features and Activate controls](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_public_preview_dialog.png "Click to view full size")

You can deactivate a preview feature at any time. Your data and configurations related to the preview feature are preserved, and you can activate the feature again later.

## Providing feedback

Your feedback helps us improve preview features. To provide useful feedback:

- Be specific: Describe what you were trying to accomplish, what happened, and what you expected.
- Include context: Mention your use case, environment, and any relevant details about your workflow.
- Report issues early: Share issues while the details are fresh.
- Suggest improvements: Share ideas about how the feature could better meet your needs.

You can provide feedback in the following ways:

- In the Activate preview features dialog, click Give feedback.
- Use the [Qlik Community Public Previews](https://community.qlik.com/t5/Public-Previews/bd-p/qlik-publicpreviews) page.
- Use the [Ideation portal](https://community.qlik.com/t5/Ideation/idb-p/qlik-ideas).
- Contact your Qlik account team.
