# Planning your Qlik Cloud deployment

To successfully plan your Qlik Cloud deployment, consider key factors such as your company's geographical distribution, current deployments, security requirements, capacity needs, and strategies for managing your subscription and environment.

## Choosing a subscription

### [*Qlik Cloud Analytics subscription options*](../Admin/subscription-options-analytics.htm)

Qlik Cloud Analytics delivers advanced analytics and insights.

### [*Qlik Talend Cloud subscription options*](../Admin/subscription-options-QTC.htm)

Qlik Talend Cloud provides the ability to create data pipelines to perform a variety of data integration tasks.

### [*Qlik Anonymous Access subscriptions*](../Admin/subscription-options-anonymous.htm)

Qlik Anonymous Access subscriptions are designed for providing anonymous access to Qlik Cloud analytics.

## Understanding specifications, requirements, and value meters

### [*Qlik Cloud Analytics capacity limits*](qcs-specs-capacity.htm)

Specifications and capacity vary based on your subscription tier. With large application support, you can work with larger applications.

### [*Qlik Anonymous Access specifications and capacity limits*](qcs-specs-capacity-anonymous-access.htm)

Qlik Anonymous Access specifications have different specifications than capacity-based subscriptions. In this topic, learn about the differences.

### [*System requirements and supported browsers*](qcs-supported-browsers.htm)

Qlik Cloud is designed to work with the platform and web browser combinations listed in this section, using default browser settings.

### [*Understanding the subscription value meters*](../Admin/subscription-value-meters.htm)

Learn the details of the subscription value meters.
