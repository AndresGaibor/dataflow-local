# Help for developers

Use Qlik Cloud APIs and tools to build, extend and deploy custom data-driven applications. You can also build mashups, create applications and visualizations on the fly, or embed rich and engaging analytics into your applications.

To learn how to start using Qlik Cloud APIs or to consult API reference documentation, visit [Qlik Developer](https://qlik.dev/).

Subscribe to the [Qlik Developer video playlist](https://www.youtube.com/playlist?list=PLW1uf5CQ_gSqH8fmAkLI5ZZWrR8imz3-o) to quickly understand the possibilities available to extend and customize Qlik Cloud.
