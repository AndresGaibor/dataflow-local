# Tutorials

Whether you are just beginning your Qlik journey or you are looking to enhance your skills to help implement your data analytics strategy, Qlik has the step-by-step tutorials you need.

## Introduction to Qlik Cloud Analytics

### [Beginning with the basics](../Tutorials/introduction-beginning-with-basics.htm)

This tutorial introduces you to Qlik Cloud Analytics. After completing the tutorial, you will understand the basics and experience how every chart, table, and object is interactive and instantly updates to the current context with each action.

### [Monitoring data with alerts](../Tutorials/alerting-example.htm)

This tutorial shows you how to create alerts. You will modify an application, create alerts, and manage alert lifecycles.

## Loading and preparing data

### [Scripting for beginners](../Tutorials/introduction-getting-started-scripting.htm)

This tutorial introduces loading and manipulating data in Qlik Cloud Analytics using scripting in the data load editor.

### [Next steps in scripting](../Tutorials/introduction-next-steps.htm)

This tutorial introduces advanced scripting concepts. This includes transforming data using cross-tables, cleaning data, and creating and loading data from Qlik data files (QVD).

### [Combining tables using forced concatenation](../LoadData/step-by-step-concatenate-tables.htm)

This tutorial shows how to use forced concatenation in Qlik Cloud Analytics to combine two or more similar data tables for analysis. You will learn how to prepare, load, map, and merge tables using the Data Manager.

### [Table recipe for beginners](../TableRecipe/table-recipe-tutorial.htm)

This tutorial introduces the process of preparing and cleaning sales data using Table recipe. It covers steps such as importing data, cleaning and transforming columns, applying filters, and exporting the results to be used in analytics applications.

### [Data flow for beginners](../DataFlow/data-flow-tutorial.htm)

This tutorial introduces the process of preparing and transforming sales data using Data flow. It covers steps such as importing data, filtering records, joining datasets, renaming and organizing fields, and exporting the results to be used in analytics applications.

### [Using the OpenAI analytics connector in Qlik Cloud](../LoadData/ac-openai-tutorial.htm)

This tutorial shows how to set up and use the OpenAI connector in Qlik to enhance your analytics by integrating AI-powered features. This guide covers account setup, connection creation, and configuration.

## Creating analytics applications and visualizing data

### [Building an analytics application](../Tutorials/introduction-building-an-app.htm)

This tutorial shows you how to build a Qlik analytics application. You will add data, create charts, and build a storytelling presentation.

### [Designing sheets for PowerPoint reports](../Tutorials/designing-and-creating-PowerPoint-reports.htm)

This tutorial shows you how to design a Qlik analytics application that will be used in generated PowerPoint reports. You will upload applications, change layouts, and add background images.

### [Chart expressions](../Tutorials/introduction-chart-expressions.htm)

This tutorial introduces chart expressions. Expressions are a combination of functions, fields, and mathematical operators used to process data, creating dynamic and powerful visualizations.

### [Creating a set expression](../ChartFunctions/SetAnalysis/set-analysis-tutorial.htm)

This tutorial introduces set expressions to support data analysis. This includes creating set expressions using set modifiers, identifiers and operators.

### [Dynamic views](../DynamicViews/dynamic-views-tutorial.htm)

This video tutorial introduces dynamic views in Qlik Cloud Analytics. It demonstrates how to use them for associative analysis on large data sources by embedding charts on demand.

### [Customizing how Insight Advisor interprets data](../BusinessLogic/Tutorial/tutorial-customizing-insight-advisor.htm)

This tutorial introduces how you can use business logic to customize how Insight Advisor interprets your data in search-based analytics.

### [Creating calendar periods using a custom calendar](../BusinessLogic/Example/step-by-step-custom-calendar.htm)

In this tutorial, you will learn how to create custom calendar periods in Qlik Cloud Analytics by using specific date fields and flags for comparative analysis..

### [Time series decomposition in Qlik Sense](../ChartFunctions/RelationalFunctions/tutorial-time-series-decomposition.htm)

This tutorial teaches you how to decompose time series data into trend, seasonal, and residual components and perform analysis on them.

## Creating predictive analytics

### [Generating and visualizing prediction data](../AutoML/tutorial-machine-learning.htm)

This tutorial introduces ML experiments, ML deployments, and predictions. You will start by creating and configuring an Qlik Predict experiment, training machine learning models, and reviewing model metrics. Finally, you will deploy a model, use it to create predictions, and build a Qlik Sense application to visualize those predictions.

### [Predicting sales with multivariate time series forecasting](../AutoML/time-series-tutorial-intro.htm)

This tutorial shows you how to train and deploy a multivariate time series model using historical data to predict and visualize daily sales by store and product family.

## Working with business glossaries

### [Creating a business glossary](../Catalog/BusinessGlossary/Tutorial/tutorial-business-glossary.htm)

In this tutorial, you will learn how to create a business glossary in Qlik Cloud, including how to add terms and categories, set up stewardship roles, and link glossary terms to master items.
