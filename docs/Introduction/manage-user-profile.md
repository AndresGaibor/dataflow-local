# Editing your user profile

You can update your profile information from the Account page.

Do the following:

1. Click your user profile icon.
2. Select Manage account.
3. In the Profile section, click Edit profile.

   Account profile page.

   ![Overview of the account settings page.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_account_profile_page.png "Click to view full size")
4. Update the following information as needed:

   - First name
   - Last name
   - Middle name (optional)
   - Job title (optional)
   - Company
   - Phone number (optional)
   - Country
   - Region (appears for applicable countries)

   Edit profile dialog.

   ![Dialog showing fields for updating user profile information.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_account_profile_edit.png "Click to view full size")
5. Click Save. Your changes take effect the next time you log in.

## More account settings

From the Account page, you can also manage your security settings. For more information, see:

- [*Resetting your password*](qcs-reset-password.htm)
- [*Configuring multi-factor authentication (MFA)*](qcs-MFA.htm)

You can manage other preferences, such as language, time zone, and notifications, in your personal settings. See [*Managing your personal settings*](profile-settings.htm).

Information note

The Account page follows your browser language. If your browser language isn’t supported, the page will display in English.
