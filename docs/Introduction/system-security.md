# Securing the system

Ensure the safety of your environment by protecting against unauthorized access and securing your data and resources.

## [*Configuring multi-factor authentication (MFA)*](qcs-MFA.htm)

Add an additional layer of security for accessing Qlik Cloud.

## [*Managing Content Security Policy (CSP)*](../Admin/mc-administer-content-security-policy.htm)

Detect and mitigate attacks such as cross-site scripting (XSS) and data injection.

## [*Managing API keys*](../Admin/mc-generate-api-keys.htm)

Authenticate users, developers, or programs to APIs, allowing controlled access and usage tracking.

## [*Creating and managing OAuth clients*](../Admin/mc-create-oauth-client.htm)

Enable secure third-party application access to Qlik Cloud resources without sharing end-user credentials.

## [*Managing IP allowlists*](../Admin/manage-ip-allowlists.htm)

Control which IP addresses can access your Qlik Cloud tenant to enhance network security.

### [*Securing and configuring the Qlik Analytics mobile app with Microsoft Intune*](../Admin/configure-mobile-app.htm)

Protect analytics data on mobile devices by enforcing security policies with Microsoft Intune.
