# Getting started

## Opening Qlik Cloud

You access Qlik Cloud by entering a web address in your browser, such as https://<server name>/. The exact address and credentials that you enter depend on how your organization has deployed Qlik Cloud.

Qlik Cloud is separated into activity centers. In the Analytics activity center, you can add your application.

Tip noteFor an overview of navigating Qlik Cloud, see [*Qlik Cloud interface overview*](../QlikCloudNavigation/Qlik-Cloud-Interface-Overview.htm)

## Uploading the tutorial application in Qlik Cloud

You need to upload the Beginner’s tutorial application in the Analytics [activity center](#glossary-0 "Glossary term").

Do the following:

1. Log in to Qlik Cloud.
2. Click ![Navigation menu](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_grid_menu.svg) > Analytics > Create.
3. Click Upload.
4. Do one of the following:

   - Drop the Beginner's tutorial.qvf file in the designated area in the upload dialog.
   - Click Browse and browse to the location of the Beginner's tutorial.qvf, select the application, and click Open.
5. Under Space, select Personal.
6. Select Navigate to space.
7. Click Upload.

The upload starts, and a progress bar is displayed. When the application is uploaded, Qlik Cloud navigates to the catalog and shows the application in your Personal space.
