# System requirements and supported browsers

Qlik Cloud is designed to work on the web browsers described in this section, using default browser settings.

Each Qlik Cloud release is tested for compatibility with the latest publicly available browser versions. Due to the frequency of browser version updates, Qlik does not include specific browser version numbers in the system requirements.

Each Qlik Cloud release is compatible with and supported on the latest iOS versions that are publicly available at the time of the Qlik Cloud release. Due to the frequency of iOS version updates, Qlik does not include specific iOS version numbers in the system requirements.

Information noteQlik Cloud Analytics supports a mobile version, Qlik Analytics. For system requirements for the Qlik Analytics mobile app, see [*Setting up the Qlik Analytics mobile app*](../Mobile/qsmsaas-setup.htm).

Information noteQlik Cloud Analytics supports a Windows application, Qlik Sense Desktop, that allows you to develop applications for local and offline usage. For system requirements for Qlik Sense Desktop, see [*Setting up Qlik Sense Desktop*](../Desktop/qsd-setup.htm).

## Supported Microsoft Windows browsers

The following browsers can be used on supported Microsoft Windows and Microsoft Windows Server machines to access the Administration activity center and the other Qlik Cloud [activity centers](#glossary-0 "Glossary term"):

- Microsoft Edge
- Google Chrome
- Mozilla Firefox (requires hardware acceleration, not supported in virtual environments)

CefSharp embedded browser v55 or later (CefSharp allows you to embed the Chromium open source browser inside .Net applications)

## Supported Apple macOS browsers

The following browsers can be used on supported Apple macOS machines to access the Administration activity center and the other Qlik Cloud activity centers:

- Apple Safari (the last 3 major versions)
- Google Chrome
- Mozilla Firefox (requires hardware acceleration, not supported in virtual environments)
- Microsoft Edge

## iOS/iPadOS

The following browsers can be used on supported devices (script editing is not supported on tablet devices):

- Apple Safari (the last 3 major versions)
- Microsoft Edge

## Android

The following browsers can be used on supported devices (script editing is not supported on tablet devices):

- Google Chrome
- Microsoft Edge
