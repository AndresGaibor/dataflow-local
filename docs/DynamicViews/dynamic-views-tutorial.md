# Tutorial - Dynamic views

This video shows you how to get started working with [dynamic views](#glossary-0 "Glossary term") and [charts](#glossary-1 "Glossary term").

Dynamic views allow you to conduct associative analysis on larger data sources by embedding charts on demand from slices of data without loading full tables into memory. This give you the choice of handling large data sources before the data comes into the application or handling it in-application after loading it.

This video provides an introduction to building a dynamic view solution with the built-in navigation options.
