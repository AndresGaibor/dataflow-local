# Editing model details

Each model that you train within an experiment has a name and description. You can edit these details to help you more easily identify models. You can edit model details in the Training data, Models, or Analyze tabs within an experiment.

## From the Training data or Analyze tabs

Do the following:

1. In the toolbar, use the drop down menu to select a model.
2. Click ![Three-dot menu](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) .
3. Click Edit model details.
4. Edit the Name and Description of the model as needed.
5. Click Save.

## From the Models tab

Do the following:

1. In the Model metrics table, click ![Three-dot menu](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) next to a model.
2. Click Edit model details.
3. Edit the Name and Description of the model as needed.
4. Click Save.
