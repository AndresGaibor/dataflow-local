# Machine learning with Qlik Predict

Automated machine learning finds patterns in your data and uses them to make predictions on future data. Machine learning experiments in Qlik Cloud Analytics let you collaborate with other users and integrate your predictive analytics in Qlik Sense applications. In addition to making predictions, you can do an in-depth analysis of the key features that influence the predicted outcome.

Load historical data from the catalog, start the automated machine learning process, and then choose the best-fitting machine learning model for your use case. Deploy the models to make predictions on the outcome of business problems. Explore the variables that impact the predicted outcome, and gain a thorough understanding of your data.

You can access Qlik Predict in the following ways:

- Through the Qlik Cloud user interface. Create experiments and deployments using workflows shown throughout the Qlik Predict help documentation.
- Using Qlik Answers, you can build end-to-end machine workflows using natural language.

  [*Working with machine learning in Qlik Answers*](../QlikAnswers/predict-agent.htm)
- Use the Qlik MCP server to access Qlik Predict from compatible LLM clients.

  [*Qlik MCP server*](../QlikMCP/Qlik-MCP-server.htm)
- Developers can integrate Qlik Predict capabilities into their own workflows using the [Machine Learning API](https://qlik.dev/apis/rest/ml/). For a tutorial to help you get started, see [Automated machine learning tutorial](https://qlik.dev/embed/machine-learning/tutorial/tutorial-overview/).

Qlik Cloud Government note

Qlik Cloud Government does not support Qlik Predict.
