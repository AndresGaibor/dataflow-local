# Navigating Insight Advisor

Click [Insight Advisor](#glossary-0 "Glossary term") in a open [sheet](#glossary-1 "Glossary term") to open [Insight Advisor Search](#glossary-2 "Glossary term") and [Insight Advisor Analysis Types](#glossary-3 "Glossary term").

Insight Advisor is available from the sheet view of an application. Click the ![Insight Advisor](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_cognitive.svg) button to open Insight Advisor.

Information note

Insight Advisor is not available when a sheet is in edit mode.

Information note

Insight Advisor is not available when a tenant is using the Qlik Answers agentic experience. Use Qlik Answers instead to explore your application's data and create sheets and charts. For more information, see [*Qlik Answers*](../QlikAnswers/Qlik-Answers.htm).

![The Insight Advisor button for opening Insight Advisor.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_insight-advisor-button-qcs.png "Click to view full size")

From Insight Advisor, you can start generating analyses with Insight Advisor Search or Insight Advisor Analysis Types.

Insight Advisor

![The Insight Advisor button for opening Insight Advisor.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_insight-advisor-qcs-rev.png "Click to view full size")

Enter a question or select fields from the assets panel to start creating analyses with Insight Advisor Search. Click Create an analysis to start building analyses with Insight Advisor Analysis Types. You can also select from the common analysis types to start with Insight Advisor Analysis.

## Insight Advisor assets panel

In Insight Advisor Search, you can create queries by selecting fields and master items. In Insight Advisor Analysis Types, you can select fields and master items to use in your analysis.

Insight Advisor assets panel

![Insight Advisor assets panel.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_insight-advisor-assets-panel-rev.png "Click to view full size")

## Insight Advisor search box

You can also access Insight Advisor Search by entering a natural language question in the search box.

Search box

![The search box in an app. ](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_insight-advisor-search-box_qcs-rev.png "Click to view full size")

Search box (expanded)

![The search box expanded with text, showing all search options including the microphone button for asking queries verbally.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_insight-advisor-search-expanded_qcs.png "Click to view full size")

You can enter your search here, either by entering asset names or using natural language. If you used a natural language question, you can click ![Info](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_info.svg) to view the filters generated from your question. You can change the language used in Insight Advisor by selecting a language from the dropdown.

## Insight Advisor analyses

These are the [charts](#glossary-5 "Glossary term") created by Insight Advisor. Insight Advisor Analysis Types shows the primary chart for your analysis type, with alternative chart types for your analysis beneath. Insight Advisor Search indicates the number of results and breaks them down as follows:

- How many results are found.
- How many charts already exist in your [sheets](#glossary-6 "Glossary term").
- How many charts are newly generated by Insight Advisor.

Analyses generated by Insight Advisor

![Analyses in Insight Advisor.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_gen_insights_matching_result.png "Click to view full size")

Insight Advisor charts can be added to existing or new sheets in your application.
You can also monitor charts in [activity centers](#glossary-7 "Glossary term").
A chart can be downloaded as an image or PDF.

## Properties panel

The properties panel contains options for editing analysis and changing the precedents you have set in Insight Advisor.

Properties panel in Insight Advisor

![Properties panel in Insight Advisor.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_insight-advisor-properties-panel.png "Click to view full size")

In General properties, you can view and edit your charts and the precedents you have set for generating analysis. For more information, see [*Managing general properties*](insight-advisor-create-visualizations.htm#Managing).

In Analysis properties, you can edit an analysis and view details. You can see the Analysis type used to create the chart. Click ![Help](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_help.svg) to learn more about the analysis type used. For more information, see [*Editing Insight Advisor analysis properties*](insight-advisor-create-visualizations.htm#Editing).

## Insight Advisor Analysis Types parameters

When using Insight Advisor Analysis Types, you select the parameters for your analysis. You can select from the assets panel or from the recommendations for each parameter type.
