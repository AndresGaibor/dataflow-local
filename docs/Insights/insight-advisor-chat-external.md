# Accessing Insight Advisor Chat through external collaboration platforms

Interact with Qlik Sense applications in external collaboration platforms, such as Microsoft Teams, using conversational analytics.

Use group and team-based chats to communicate with applications in a Qlik Cloud tenant through Insight Advisor Chat. By integrating data exploration directly into your team's core communication tools, your team can accelerate and enhance data analysis.

Add external collaboration environments as collaboration channels. These channels can access applications in the Qlik Cloud tenant and allow users to engage with application data using conversational analytics and natural language.

You can connect to Insight Advisor Chat from Microsoft Teams.

## Requirements

Before you can use an external collaboration platform to interact with your Qlik Sense applications, consider the following requirements, which must be completed by you or your Qlik Cloud tenant administrator:

- Add the external tenant as a collaboration channel in the Administration activity center.
  For more information, see [*Adding connections to external collaboration platforms*](../Admin/mc-collaboration-platforms.htm).
- Required permissions for accessing Insight Advisor Chat via Microsoft Teams. You need one of the following:

  - The Collaboration Platform User built-in security role. See:

    - [*Assigning security roles and custom roles*](../Admin/SaaS-roles-capacity-model.htm) (capacity-based subscriptions)
    - [*Assigning security roles and custom roles*](../Admin/SaaS-roles.htm) (user-based subscriptions)
    - [*Assigning security roles and custom roles*](../Admin/SaaS-roles-anonymous.htm) (Qlik Anonymous Access subscriptions)
  - The Insight Advisor in Microsoft Teams permission set to Allowed through the default permissions or a custom security role. See:

    - [*Default permissions and custom roles*](../Admin/permissions-scopes-capacity-model.htm) (capacity-based subscriptions)
    - [*Default permissions and custom roles*](../Admin/permissions-scopes.htm) (user-based subscriptions)
    - [*Default permissions and custom roles*](../Admin/permissions-scopes-anonymous.htm) (Qlik Anonymous Access subscriptions)

Information noteDepending on the collaboration platform, additional actions are also required. See the page specific to your collaboration platform for full details. Available collaboration platforms are noted in the following sections on this page.
