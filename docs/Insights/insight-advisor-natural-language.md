# Using natural language with Insight Advisor

[Insight Advisor](#glossary-0 "Glossary term") supports natural language questions, such as Show me Product Inventory for Japan under 2500.

Natural language questions support three kinds of filters:

- Time: A unit of time or date. For example, Show me 2019 Sales.
- Category: A value from one of the [dimensions](#glossary-1 "Glossary term"). For example, Show me Sales by Product for Sweden.
- Measure: A value or values from a [measure](#glossary-2 "Glossary term"). For example, Show me Sales for Sweden by Product under 1K.

You can search for facts, comparisons, and rankings. Facts are statements such as What are my sales, or Show expenses over time for 2019. You can ask for a comparison by adding vs or compare to your question. For example, Compare sales to expenses over time. You can ask for rankings by adding top  to your question. For example, Show me top 10 product by sales for 2020.

Information note

Qlik Cloud supports several languages in Insight Advisor Search. For more information on supported languages in Insight Advisor Search, see [Supported languages](/en-US/cloud-services/Subsystems/Hub/Content/Sense_Hub/Insights/insight-advisor-create-visualizations.htm#anchor-8).

If your browser is not set to a supported language, English is used. You can change the language used by Insight Advisor by selecting a language from the Language button.

Natural language searches need to reference field names and values in your data model. Synonyms for fields and values can be added using business logic vocabulary. For more information, see [*Creating vocabularies for Insight Advisor*](../BusinessLogic/business-logic-vocabulary.htm). You can also tag master items with synonyms using tags on your master items. Use the format alt:<term> in synonym tags. If you wanted to use cities as a synonym, you would tag the master item alt:cities. For more information, see [*Tagging master items*](../Assets/tag-master-items.htm).

Click ![Rate](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_rate.svg) on a [chart](#glossary-3 "Glossary term") generated by Insight Advisor to provide feedback on the [visualization](#glossary-4 "Glossary term"). You can indicate a positive or negative response, and write a comment.

Information noteWhen searching [field](#glossary-5 "Glossary term") values, natural language queries only search the first 100,000 values per [field](#glossary-6 "Glossary term") in the question.

For more information about natural language questions, see [Qlik Sense Natural Language Query features](https://community.qlik.com/t5/Support-Knowledge-Base/Qlik-Sense-Natural-Language-Query-features/ta-p/1711977).
