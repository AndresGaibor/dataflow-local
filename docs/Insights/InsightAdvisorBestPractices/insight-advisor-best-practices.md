# Insight Advisor best practices

Learn how to use Insight Advisor to design your applications to achieve user-specific goals, improve the quality of application structure and data, and get stronger results when asking Insight Advisor questions.

## Best practices for improving performance of applications

As an application developer, learn methods for making applications more responsive and how you can improve the quality of analysis that users get out of your applications.

[*Best practices for improving performance of applications*](best-practice-improve-app-performance.htm)

## Best practices for creating logical models

As an application developer, learn methods for creating your business logic vocabulary and logical model. Building a strong logical model and vocabulary provides value to your users and make it easier for them to create visualizations.

[*Best practices for using business logic*](best-practice-create-business-logic.htm)

## Best practices for asking questions in Insight Advisor

As an application user, learn tips for asking questions in Insight Advisor and Insight Advisor Chat. Learn how to use filters and other key terms when asking questions.
