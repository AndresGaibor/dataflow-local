# Turning off Insight Advisor

By default, [Insight Advisor Search](#glossary-0 "Glossary term") and [Insight Advisor Analysis Types](#glossary-1 "Glossary term") are enabled in applications. You can turn off Insight Advisor to prevent users from accessing these features.

Information note

Insight Advisor is not available when a tenant is using the Qlik Answers agentic experience. Use Qlik Answers instead to explore your application's data and create sheets and charts. For more information, see [*Qlik Answers*](../QlikAnswers/Qlik-Answers.htm).

Do the following:

1. In the application navigation bar, click ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) > Settings.
2. In the menu, switch to the Capabilities tab.
3. Turn off Insight Advisor in this application.
