# Exploring analyses with Insight Advisor

Explore application data through search-based analytics and building analyses from selected analysis types. You can use Insight Advisor to explore both [visualizations](#glossary-1 "Glossary term") within an application as well as create new visualizations analyses based on what you are searching for.

As you explore and analyze data in application visualizations, you may not be able to find what you are looking for. You may know the question you want answered or the analysis you want to see, but not how to get it.

[Insight Advisor](#glossary-2 "Glossary term") helps by creating visualizations for you. You can build analyses in Insight Advisor, picking the analysis type you want to see and the fields you want used in the analysis. Insight Advisor then builds [charts](#glossary-3 "Glossary term") based on your selections. Insight Advisor also provides a search-based interface for querying application data to return visualizations based on your question.

Insight Advisor is available from the [sheet](#glossary-4 "Glossary term") view of an application by clicking Insight Advisor.

Information note

Insight Advisor is not available when a tenant is using the Qlik Answers agentic experience. Use Qlik Answers instead to explore your application's data and create sheets and charts. For more information, see [*Qlik Answers*](../QlikAnswers/Qlik-Answers.htm).

## Analyzing applications with Insight Advisor

How and where you can use Insight Advisor in an application depends on the type of space the application is in and your [permissions](#glossary-5 "Glossary term") in that space.

For user-based subscriptions, how you can use Insight Advisor also depends on your user entitlement:

- Analyzer entitlement: You can use Insight Advisor but cannot add generated charts to sheets. You can still monitor charts you created in Insight Advisor from activity centers.
- Professional entitlement: Depending on your space permissions, you can add charts you create to sheets in the application. You can also monitor your Insight Advisor charts from activity centers.

The data assets available in Insight Advisor depend on whether the application uses [business logic](#glossary-6 "Glossary term") to define its [logical model](#glossary-7 "Glossary term") and on your space permission. Users with Can view permission can only see master items, unless the application uses business logic to define its logical model.

For more information about using Insight Advisor, see [*Creating visualizations with Insight Advisor*](insight-advisor-create-visualizations.htm).
