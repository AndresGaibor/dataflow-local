# PostgreSQL

Connections to a PostgreSQL database are made by selecting PostgreSQL from the list of drivers in the list of connectors in the Qlik Sense Add data or Data load editor dialogs.

Information noteIndustry-accepted best practices must be followed when using or allowing access through the ODBC Connector. Administrators must follow The Principle of Least Privilege when setting up source database privileges and permissions.

## Supported PostgreSQL versions

The following PostgreSQL versions are supported:

- 12, 13, 14, 15, 16, 17, 18

QlikView supports PostgreSQL versions 12, 13, 14, 15, 16, and 17.
