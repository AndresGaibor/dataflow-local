# Turning on chart level scripting

By default, [chart](#glossary-0 "Glossary term") level scripting is disabled in applications. You can turn it on in application settings.

Do the following:

1. In the application navigation bar, click ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) > Settings.
2. In the menu, switch to the Capabilities tab.
3. Turn on Allow chart scripts.
