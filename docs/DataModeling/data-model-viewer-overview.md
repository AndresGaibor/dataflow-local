# Data model viewer

View the data structure of the data that you have added to your application in the data model viewer, and view metadata about the tables and fields.

Click Data model viewer in the application navigation menu to open the data model viewer.

Data model viewer

![Data model viewer.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_gen_data_model_viewer_sense.png "Click to view full size")

See:

- [*Viewing and transforming the data model*](view-data-model.htm)
- [*Best practices for data modeling*](best-practices-data-modeling.htm)

## Previewing data and viewing metadata

Click a table or a [field](#glossary-1 "Glossary term") in the table, and then click Preview to open the Preview panel.

See: [*Previewing tables and fields in the data model viewer*](preview-tables-fields-data-model-viewer.htm)

## Creating dimensions and measures from fields

Click Preview to open the Preview panel, select a field, and then click Add as dimension or Add as measure.

See:

- [*Creating a master dimension from the data model viewer*](../Dimensions/create-master-dimension-from-data-model-viewer.htm)
- [*Creating a master measure from the data model viewer*](../Measures/create-master-measure-data-model-viewer.htm)

Data model viewer tools

| UI item | Description |
| --- | --- |
| Collapse | Collapse all tables to show the table name only. |
| Reduce | Reduce the size of all tables to show the table name and all fields with associations to other tables. |
| Expand | Expand all tables to show all fields. |
| Scatter chart | Internal table view - the Qlik Sense data model including synthetic fields. |
| Data model | Source table view - the data model of the source data tables. |
| Grid View | Layout menu with the options Grid layout, Auto layout and Restore layout. |
