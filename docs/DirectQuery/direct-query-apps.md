# Direct Query applications

Direct Query lets you directly communicate with underlying data sources without having to import the data.

Qlik Cloud Government noteQlik Cloud Government users cannot use Direct Query.

Direct Query provides an easy way to intelligently manage compute costs and user experience across databases and applications without moving the data from the underlying data sources.
This capability is primarily meant to support specific analytical needs, as well as to introduce new users how to leverage Qlik analytic capabilities over customer data stored in databases. Direct Query also makes it easy to transition from a Direct Query application state to an in-memory data extract.

For more information about Direct Query, see [*Accessing cloud databases directly with Direct Query*](direct-access-with-direct-query.htm).
