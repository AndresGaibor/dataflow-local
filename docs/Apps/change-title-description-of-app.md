# Changing the title and description of an application

You can change the title and description of your applications. When creating a new application the name of the application is used as its title.

## Changing the title and description in an activity center

Do the following:

1. Click ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) on the application you want to edit and select Manage > Edit details.
2. Change the title and description and click Save.

## Changing the title and description within the application

Do the following:

1. Click the application name to open the application details area.
2. Click ![More actions](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) > Edit details.
3. Edit Title and Description.
4. Click Done.
5. Click ![Checkmark](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_tick.svg) to stop editing.

The changes you made are saved.

Alternatively, you can change the title and description from the application settings. Click ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) in the application navigation bar, and select ![Settings](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_cogwheel_outline.svg) Settings. Edit the title and description in the menu.
