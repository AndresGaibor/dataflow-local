# Converting applications to scripts

You can convert applications into scripts.

Converting duplicates the application and then converts it into a script. Scripts only contain the load script in Data load editor and do not include sheets, stories, data models and master items.

Do the following:

1. Click ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) on the application you want to export and select Manage > Duplicate as script.
2. Click Confirm.
