# Duplicating applications

You can duplicate any application to which you have access. The duplicate can be modified: you can add different data or edit sheets.

Information noteTo duplicate an application that uses section access, you must be assigned at least one of the following permissions for shared spaces:

- Can edit
- Can manage

Duplicating applications has several uses. For example, you can copy an application to use it as a template. You can also duplicate applications as a form of version control, and store older ones a space created for archival purposes.

Duplicated applications keep the original data sources and data. If you did not create the original data sources used in the application, you will have to recreate data sources in the application.

Information note

If you duplicate an application published to Qlik Cloud Analytics from Qlik Sense Enterprise, the data sources in the application may not be supported for applications in Qlik Cloud.
You will not be able to reload data. You can change the data sources in a duplicated application, however.

## Duplicating applications from your activity center

Do the following:

- In your activity center, click ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) on the application and select Manage > Duplicate.

## Duplicating applications from an application

Do the following:

1. In your application, click the application name to open the application details area.
2. In the application details area, click ![More actions](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) > Duplicate.
