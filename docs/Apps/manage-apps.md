# Managing applications

Once you have created and built an application with the [sheets](#glossary-1 "Glossary term") and visualizations you want it to have, you may want to fine-tune it to make it easy and efficient to use, not only for yourself but also for other people.

What you can do with an application depends on the type of space the application is in. In your personal space, you can manage your own applications. In a shared space, depending on your permissions in that space, you can manage both your own applications and the applications of other users. In managed spaces, there are fewer options for managing applications as access is more governed. For more information about spaces, see [*Working in spaces*](../Spaces/Spaces.htm).

The following options are available for managing applications:

- Edit and manage details and styling of an application.
  - [*Changing the title and description of an application*](change-title-description-of-app.htm)
  - [*Changing the thumbnail of an application*](change-thumbnail-app.htm)
  - [*Editing application details*](edit-app-cloud-hub.htm)
- Manually reload or schedule reloads for data in an application.

  - [*Reloading application data*](reloading-apps-cloud-hub.htm)
- Manage if Insight Advisor is available in your application and if the application is available in Insight Advisor Chat.

  - [*Turning off Insight Advisor*](../Insights/insight-advisor-off.htm)
  - [*Making applications available in Insight Advisor Chat*](../Insights/insight-advisor-available-chat.htm)
- Manage if key driver analysis is available in your application.

  - [*Turning off key driver analysis*](../KeyDrivers/key-drivers-off.htm)
- Make an application available elsewhere by moving it or publishing it to a managed space.

  - [*Moving applications*](move-apps-cloud-hub.htm)
  - [*Publishing applications*](publish-app-cloud-hub.htm)
- Duplicate, export, or upload additional applications.

  - [*Duplicating applications*](duplicating-app-cloud-hub.htm)
  - [*Converting applications to scripts*](convert-app-to-script.htm)
  - [*Downloading applications*](export-apps-cloud-hub.htm)
  - [*Uploading applications*](uploading-apps.htm)
- View what data sources your application uses and what data your application outputs for other applications.

  - [*Analyzing lineage in Analytics*](../Catalog/lineage.htm)
  - [*Analyzing impact analysis in Analytics*](../Catalog/impact-analysis2.htm)
- Delete an application that is no longer required.
  - [*Deleting applications*](delete-app-cloud-hub.htm)

Information noteTenant and analytics administrators can also manage applications. For example, they can change application ownership and an application's space. For more information, see [Managing applications for tenant and analytics administrators](/en-US/cloud-services/Subsystems/Hub/Content/Sense_Hub/Admin/mc-administer-apps.htm).
