# Application overview

Manage sheets, [bookmarks](#glossary-0 "Glossary term") and stories from the application overview.

Click an application to open the application overview.

Application overview

![App overview.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_gen_app_overview-saas-rev2.png "Click to view full size")

You can view additional information about your application from the application details area. The application details area displays the application name, space, and data load information. It also shows when you last opened the application, how many people have viewed the application in the last month, when the application was created, and when the application was last updated. Additional application actions are available in the application details area by clicking ![More actions](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) and selecting the action. You can open the application details area from the application navigation bar by clicking the application name or by clicking ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) > Details.

Application details area

![The app details area.](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/ui_app-details-rev.png "Click to view full size")

Public content is shown under Public. Private content is displayed under My own. For applications in managed spaces, content added by other users after the application was published is displayed under Community.

You can do the following:

- Click ![Sheets](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_sheet2.svg) Sheets, ![Bookmark](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_bookmark.svg) Bookmarks, or ![Story Mode](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_slideshow_outline.svg) Stories to display those elements in the application overview.

  - Click a [sheet](#glossary-2 "Glossary term"), story, or bookmark to open it.
  - Create new sheets or stories, and view bookmarks. You have to create bookmarks in sheet view.
  - Click the title of a sheet or a story to display details.
  - Duplicate or reorder sheets.
  - Make sheets or stories public or private.
- Click ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) > Details to change application details and manage the application. In the application details area, you can:
  - Change the thumbnail, name, description, and tags of the application.
  - Move the application to a new space.
  - Duplicate the application.
  - Reload the application.
  - Create tasks to schedule reloads.
  - Evaluate application performance.
- Click ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) > ![Settings](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_cogwheel_outline.svg) Settings to change the settings for an application. You can, for example, turn on or turn off Insight Advisor Search and Insight Advisor Analysis Types, change the appearance of the application, and change the styling of the sheet. You can hide the toolbar and header on sheets.

Tip noteYou can open or close the application details area by clicking the application name in the navigation bar.
