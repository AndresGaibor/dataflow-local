# Editing application details

After creating an application, you can edit the application details.
You can add new information to the application or move the application to a different space.

You can change the titles and descriptions of your applications. Tags are used to group applications with related content. When adding new tags to an application, users can view all tags that exist in the tenant.

## Editing application details in an activity center

Do the following:

1. In your activity center, click ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) on the application you want to edit and select Manage > Edit details,
2. Edit the title, description, or tags.
3. Click Done.

## Editing application details in an application

Do the following:

1. In your application, click the application name to open the application details area.
2. In the application details area, click ![More actions](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) > Edit details.
3. Edit the thumbnail, title, description, or tags.
4. Click Done.

Alternatively, you can change the application details from application settings. Click ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) in the application navigation bar, and select ![Settings](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_cogwheel_outline.svg) Settings. In the menu, change the thumbnail, title, description, or tags.
