# Changing the thumbnail of an application

You can replace the default thumbnail of an application with another thumbnail, to make it easier to distinguish between applications in your [activity centers](#glossary-1 "Glossary term"). You can use one of the default images, or an image of your own.

Do the following:

1. Click the application name to open the application details area.
2. Click ![More actions](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) > Edit details.
3. Click ![Image](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_image_outline.svg) on the default thumbnail.

   The Media library opens.
4. Select the image you want to use as a thumbnail for the application and click Close.

The image you selected is now used as a thumbnail for the application.

Alternatively, you can change the thumbnail from the application settings. Click ![More](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_more.svg) in the application navigation bar, and select ![Settings](../_images/en-US/cloud-services/Subsystems/Hub/Content/Resources/Images/Icons/ic_cogwheel_outline.svg) Settings. Change the thumbnail in the menu.

Tip noteThe optimal aspect ratio of a thumbnail is 8:5 (width:height).

The following formats are supported: .png, .jpg, .jpeg, and .gif.When using Qlik Sense in Qlik Cloud, you upload images to the In app folder in the media library.

Tip noteYou can open or close the application details area by clicking the application name in the navigation bar.
