# Embedded analytics

Whether you're aiming to enhance user experiences, leverage data-driven
decision-making, add interactive analytics to your customer portals, or
add AI and NL insights to your product or service, you can leverage Qlik Cloud
to enhance your web apps, or bring complete customization to your end
user experiences.

If you're new to the topic, consider learning more about the [value of embedded analytics](https://www.qlik.com/us/products/qlik-embedded-analytics),
or dive into [examples and benefits of embedding analytics](https://www.qlik.com/us/data-analytics/embedded-analytics).

## Get started with qlik-embed

Qlik-embed is Qlik's primary embedding framework, simplifying embedding of
Qlik technologies, while also increasing the potential breadth and depth of
your integrations for both Qlik Cloud and Qlik Sense Enterprise client-managed.

- [Understand why qlik-embed](https://qlik.dev/embed/qlik-embed/why-qlik-embed) - Learn why you should use qlik-embed for your embedded project
- [Learn how to authenticate for qlik-embed](https://qlik.dev/embed/qlik-embed/authenticate/connect-qlik-embed) - Discover the good practice for authenticating web apps using qlik-embed
- [Embed with qlik-embed web components](https://qlik.dev/embed/qlik-embed/quickstart/qlik-embed-webcomponent-quickstart) - Jump into creating an embedded web app using qlik-embed web components
