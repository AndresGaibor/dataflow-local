# Talend Management Console

Track Capacity-Based Pricing (CBP) metrics for task executions in Talend Management Console.

## Table of Contents

### system-events.talend-management-console

- [com.qlik.talend-management-console.cbp-execution-metrics.aggregated](#comqliktalend-management-consolecbp-execution-metricsaggregated)

## Events published on the `system-events.talend-management-console` channel

### com.qlik.talend-management-console.cbp-execution-metrics.aggregated

**Title:** Talend Management Console cbp metrics aggregated

**Action:** `send`

**Visibility:** `public`

**Stability:** `stable`

Talend Management Console Capacity-Based Pricing (CBP) metrics have been aggregated

**Payload**

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `string` | Yes | Unique identifier for the event. |
| `time` | `string` | No | Timestamp of when the event happened. Metadata: format = "date-time". |
| `type` | `string` | Yes | The type of the event. Metadata: default = "com.qlik.talend-management-console.cbp-execution-metrics.aggregated". |
| `source` | `string` | Yes | The source of the event. Metadata: default = "com.qlik/tmc-metrics-collector-job". |
| `specversion` | `string` | Yes | The event is compatible with the CloudEvents specification v1.0.2. Allowed values: 1.0. |
| `datacontenttype` | `string` | No | Content type of the data value. Must adhere to RFC 2046 format. Metadata: minLength = 1, default = "application/json". |
| `tenantid` | `string` | Yes | Unique identifier for the tenant related to the event. |
| `data` | `object` | No | The CBP execution metrics details that were aggregated. |
