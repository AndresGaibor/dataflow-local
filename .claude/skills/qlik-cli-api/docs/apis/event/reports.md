## Events published on the `system-events.report` channel

### com.qlik.v1.report.collected

**Title:** Report processing data collected

**Action:** `send`

**Visibility:** `public`

**Stability:** `stable`

Emitted when the processing of a report has completed, whether it succeeded or failed. It carries the report data and the outcome, and it is immediately followed by the report finished event, unless the latter is suppressed by configuration. It is not emitted for the parent request of a cycle-based request, but it is emitted for each report generated by the cycle.

**Payload**

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `string` | Yes | Identifies the event. Metadata: minLength = 1. |
| `time` | `string` | No | Timestamp of when the occurrence happened. Must adhere to RFC 3339. Metadata: minLength = 1, format = "date-time". |
| `type` | `string` | Yes | Unique identifier for the event type. Allowed values: com.qlik.v1.report.collected. Metadata: default = "com.qlik.v1.report.collected". |
| `source` | `string` | Yes | Identifies the context in which an event happened. Metadata: minLength = 1, format = "uri-reference". |
| `specversion` | `string` | Yes | The version of the CloudEvents specification which the event uses. Metadata: minLength = 1. |
| `datacontenttype` | `string` | No | Content type of the data value. Must adhere to RFC 2046 format. Metadata: minLength = 1, default = "application/json". |
| `userid` | `string` | No | Unique identifier for the user triggering the event. |
| `authtype` | `string` | No | Representing the type of principal that triggered the occurrence. |
| `tenantid` | `string` | Yes | Unique identifier for the tenant related to the event. |
| `authclaims` | `string` | No | A JSON string representing claims of the principal that triggered the event. |
| `data` | `dataPayload` | Yes | The data payload for a report processing event. |

### com.qlik.v1.report.triggered

**Title:** Cycle-based report generation triggered

**Action:** `send`

**Visibility:** `public`

**Stability:** `stable`

Event emitted when a cycle-based request has generated its individual report requests. A cycle-based request uses template cycle fields to produce multiple reports. Each generated report emits its own report collected and report finished events, while no report finished event is emitted for the parent request.
