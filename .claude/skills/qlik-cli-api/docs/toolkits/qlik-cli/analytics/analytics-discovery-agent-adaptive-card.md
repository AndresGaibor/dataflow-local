# analytics discovery-agent adaptive-card

## qlik analytics discovery-agent adaptive-card

Generate adaptive cards for metrics

### Synopsis

Adaptive cards present discovery agent insights as ready-to-use cards that summarize metrics across your apps, with support for filtering by app, measure, dimension, and analysis type.

```
qlik analytics discovery-agent adaptive-card [flags]
```
