# Visualizations

> **Note:** Where possible, use [qlik-embed](https://qlik.dev/embed/qlik-embed/) and [qlik/api](https://qlik.dev/toolkits/qlik-api) rather than this framework.

Visualizations are used to present the data that is loaded into the app. The
selections you make in the app are reflected in all associated visualizations.

If you're new to Qlik visualizations, review
the [visualization intro](https://qlik.dev/embed/foundational-knowledge/visualizations).
