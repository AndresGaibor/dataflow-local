# New visualization - Tab container

The new Tab container chart object offers improved styling settings for labels, tabs, and icons compared to the
deprecated Container object.

While existing Container objects still work, you can no longer create new ones. The Tab container is now the go-to
replacement.

For more information, refer to [Foundational knowledge](https://qlik.dev/embed/foundational-knowledge/visualizations/).
