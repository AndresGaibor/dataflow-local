# OAuth Client ID Metadata Documents (CIMD) now supported

Tenant administrators can now configure a Model Context Protocol (MCP) connection between their AI platforms and
Qlik Cloud tenants using OAuth Client ID Metadata Documents (CIMD).
CIMD reduces the manual steps required to configure OAuth clients and eliminates the need to manually manage client
secrets.

For setup and management instructions, see the [CIMD documentation](https://qlik.dev/authenticate/oauth/oauth-client-id-metadata-documents/).
