# OAuth Dynamic Client Registration (DCR) is now available

Tenant administrators can now enable OAuth Dynamic Client Registration (DCR), allowing compatible applications
(including AI and MCP clients) to register OAuth clients dynamically in Qlik Cloud.
Each dynamically registered client must be approved by a tenant administrator before it can be used.

For more information, see [OAuth dynamic client registration](https://qlik.dev/authenticate/oauth/oauth-dynamic-client-registration/).
