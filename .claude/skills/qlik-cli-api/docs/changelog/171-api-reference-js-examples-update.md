# JavaScript examples in the REST API reference documentation now use qlik-api

The [`qlik-api`](https://qlik.dev/toolkits/qlik-api/) JavaScript library is now the recommended approach for integrating with
Qlik Cloud REST APIs and the Qlik Analytics Engine (QIX) in JavaScript solutions.

To simplify adoption and reduce complexity, all JavaScript examples in the [REST API reference documentation](https://qlik.dev/apis/rest/#api-reference-documentation)
now use `qlik-api` instead of native Node.js code.

![Updated JavaScript example using qlik-api in REST API reference documentation](https://qlik.dev/_astro/qlik-api-js-example-screenshot.Bt9YyJOF.png)

This update makes it easier for developers to:

- Get started with Qlik Cloud API integrations in JavaScript
- Follow best practices for authentication and API usage
- Maintain and extend their solutions using a supported library
