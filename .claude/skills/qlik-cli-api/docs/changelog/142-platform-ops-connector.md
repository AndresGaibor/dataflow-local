# Block updates - Qlik Platform Operations & Qlik Cloud Services connectors

The [Qlik Platform Operations](https://qlik.dev/manage/platform-operations/no-code/overview)
and Qlik Cloud Services connectors for [Qlik Automate](https://qlik.dev/toolkits/no-code/)
enable the deployment and management of Qlik Cloud tenants without any code.

New blocks in the **Qlik Platform Operations** connector:

- `Get Role`: Retrieves the definition for a specific role.
- `Create Custom Role`: Creates a new custom role.
- `Update Custom Role`: Updates an existing custom role by its ID.
- `Update Custom Role By Name`: Updates an existing custom role by it's name.
- `Delete Custom Role`: Deletes a specific custom role by its ID.
- `Create Folder`: Creates a new folder in the user's personal DataFiles connection.
- `Create Folder In Space`: Creates a new folder in the specified space's DataFiles
  connection.

Updated blocks in the **Qlik Platform Operations** connector:

- `List Data Files`: Added folder support.
- `List Data Files From Space`: Added folder support.
- `Get Data File`: Added folder support.
- `Create Data File`: Added folder support.
- `Create Data File In Space`: Added folder support.
- `Copy Data File`: Added folder support.
- `Copy Data File In Space`: Added folder support.
- `Delete Data File`: Added folder support.

New blocks in the **Qlik Cloud Services** connector:

- `Get Role`: Retrieves the definition for a specific role.
- `Create Custom Role`: Creates a new custom role.
- `Update Custom Role`: Updates an existing custom role by its ID.
- `Update Custom Role By Name`: Updates an existing custom role by its name.
- `Delete Custom Role`: Deletes a specific custom role by its ID.
- `Create Folder`: Creates a new folder in the user's personal DataFiles connection.

Updated blocks in the **Qlik Cloud Services** connector:

- `Import Datafile From Temporary Contents`: Added folder support.
- `List Data Files`: Added folder support.
