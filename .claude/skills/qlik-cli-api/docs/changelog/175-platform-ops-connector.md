# Block updates - Qlik Platform Operations & Qlik Cloud Services connectors

The [Qlik Platform Operations](https://qlik.dev/manage/platform-operations/no-code/overview)
and Qlik Cloud Services connectors for [Qlik Automate](https://qlik.dev/toolkits/no-code/)
enable the deployment and management of Qlik Cloud tenants without writing any code.

### Qlik Platform Operations connector \{#175-qlik-platform-ops-connector}

**New block**:

- `Create Automation Connection`: Creates a new automation connection, which can then be referenced from an automation.
- `Update Automation Connection`: Updates an existing automation connection.

**Updated block**:

- No blocks were updated in this release.

### Qlik Cloud Services connector \{#175-qlik-cloud-services-connector}

**New block**:

- `Create Automation Connection`: Creates a new automation connection, which can then be referenced from an automation.
- `Update Automation Connection`: Updates an existing automation connection.

**Updated block**:

- `Raw API Request`: Added `report-templates`, `data-sources`, `automation-connectors`, and `automation-connections`
  APIs to the list of supported APIs.
- `Raw API List Request`: Added `report-templates`, `data-sources`, `automation-connectors`, and
  `automation-connections` APIs to the list of supported APIs.
