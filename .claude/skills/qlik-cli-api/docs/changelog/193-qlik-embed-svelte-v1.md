# @qlik/embed-svelte version 1.0.0 released

Version 1.0.0 of the `@qlik/embed-svelte` [library](https://www.npmjs.com/package/@qlik/embed-svelte) is now available.

The `@qlik/embed-svelte` library is now production-ready.
You can confidently use it to embed Qlik insights in your Svelte and SvelteKit applications.

The public API contracts remain unchanged from v0.x. No code changes needed when upgrading to v1.0.0,
which is the stable, supported version of the library.

Check the tutorials to learn how to use `@qlik/embed-svelte` with [Svelte](https://qlik.dev/embed/qlik-embed/quickstart/qlik-embed-svelte-quickstart/) or [SvelteKit](https://qlik.dev/embed/qlik-embed/quickstart/qlik-embed-sveltekit-quickstart/).
