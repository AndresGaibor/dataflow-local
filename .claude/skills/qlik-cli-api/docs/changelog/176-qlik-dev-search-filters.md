# Filtered search on qlik.dev

You can now filter site search results on qlik.dev to find docs, tutorials, and API reference faster.

After you submit a search, the **Filter results** panel on the results page lets you narrow results.

The **Filter results** panel groups options into three categories:

- Content type: choose the kind of content you want (for example, API reference, article, or changelog).
- API type: limit results to a specific API technology (for example, REST, JSON-RPC, JavaScript, events).
- Area: focus on a site area or topic (for example, Embed, Extend, Manage, Toolkits).

![Search results page with Filters panel showing API reference, Articles, and Changelog options](https://qlik.dev/_astro/search-filters-qlik-dev.Ct43kzQF.png)

Try it from the navigation bar search box.
