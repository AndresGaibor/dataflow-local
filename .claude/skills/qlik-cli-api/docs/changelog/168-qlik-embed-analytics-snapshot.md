# New analytics/snapshot UI for qlik-embed

You can now embed Qlik analytics snapshots offline using the `analytics/snapshot` UI in qlik-embed.

This new UI uses a JSON payload, generated by [sharing tasks](https://qlik.dev/apis/rest/sharing-tasks/) or exported from a live object,
to render the chart without a Qlik Sense engine session or authentication. All resources load from the Qlik CDN.

For more information, refer to:

- [UIs and parameters](https://qlik.dev/embed/qlik-embed/parameters/#analyticssnapshot)
- [Quick start: Embed offline snapshots](https://qlik.dev/embed/qlik-embed/quickstart/qlik-embed-offline-snapshots)
- [Tutorial: Embed analytics snapshots offline with qlik-embed and OAuth M2M](https://qlik.dev/embed/qlik-embed/quickstart/qlik-embed-offline-snapshots-m2m-tutorial)
