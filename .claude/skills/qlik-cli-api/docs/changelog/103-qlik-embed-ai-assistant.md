# qlik-embed adds Qlik Answers support with ai/assistant

The AI assistant component brings you the [Qlik Answers](https://qlik.com/answers)
experience in embedded format, with the following tag:

```html
<qlik-embed
  ui="ai/assistant"
  assistant-id="<assistant-id>"
></qlik-embed>
```

Review the [ai/assistant parameters](https://qlik.dev/embed/qlik-embed/parameters/#aiassistant),
or learn more about the other [UIs and params in qlik-embed](https://qlik.dev/embed/qlik-embed/parameters/).
