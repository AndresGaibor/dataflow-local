# Block updates - Qlik Platform Operations & Qlik Cloud Services connectors

The [Qlik Platform Operations](https://qlik.dev/manage/platform-operations/no-code/overview)
and Qlik Cloud Services connectors for [Qlik Automate](https://qlik.dev/toolkits/no-code/)
enable the deployment and management of Qlik Cloud tenants without any code.

No blocks were updated or added to the **Qlik Platform Operations** connector this release.

New blocks in the **Qlik Cloud Services** connector:

- `Create Space Share`: Supports creation of shares for individual resources in a space.
- `List Space Shares`: Lists individual resource shares in a space.
- `Get Space Share`: Retrieves a specific resource share configuration.
- `Update Space Share`: Updates a specific resource share.
- `Delete Space Share`: Deletes a specific resource share.

Updated blocks in the **Qlik Cloud Services** connector:

- `List Reloads`: Added filter filter input to support filtering on reload status, etc.
- `Raw API Request`: Added support for `tasks` API.
- `Raw API List Request`: Added support for `tasks` API.
