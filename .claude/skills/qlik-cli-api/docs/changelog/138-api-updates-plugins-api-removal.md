# API updates - Removal of plugins API for visualizations

Qlik will be removing the experimental Plugins API from the following nebula visualizations to
support ongoing visualization improvement work:

- Scatter plot
- Bar chart
- Line chart
- Combo chart
- Grid chart
- Pie chart
- Bullet chart
- Sankey chart
- Funnel chart

This API is experimental and as such this notice is provided as a courtesy to users.

> **Breaking change:** This removal will take effect on or after June 06, 2025.
