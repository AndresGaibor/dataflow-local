# Download all REST API specs in one ZIP

You can now download every REST OpenAPI spec as a single ZIP archive instead of
downloading each spec individually.

Qlik regenerates the archive with each qlik.dev release from the published REST API specs.

- For tenant-level REST APIs, go to [REST APIs](https://qlik.dev/apis/rest/) and select **Download the REST
  specs (ZIP)**.
- For organization-level REST APIs, go to [Organization REST APIs](https://qlik.dev/apis/org-rest/) and select
  **Download the organization REST specs (ZIP)**.
