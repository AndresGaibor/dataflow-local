# Deprecation notice - enableAnalyticCreation field in the Tenants API

> **Deprecation notice:** The `enableAnalyticCreation` field in the [Tenants API](https://qlik.dev/apis/rest/tenants/)
> is deprecated and will be removed on or after March 2027.

The `enableAnalyticCreation` boolean field was used for an early feature preview
and is no longer in use. If you are currently using this field, remove these
references before March 2027.
