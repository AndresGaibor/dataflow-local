# Deprecation notice - duration sort option in the Automations API

> **Deprecation notice:** The `duration` option for the `sort` query parameter in `GET /automations` is deprecated and will be removed on or
> after October 21, 2025.

Use other available sort options such as `lastRunAt` or `lastRunStatus`.

For more information, see the [Automations API reference](https://qlik.dev/apis/rest/automations/).
