# qlik-embed adds support for Anonymous Access

Support for the anonymous OAuth type has been added to qlik-embed, which allows
you to leverage the Anonymous Access capability for embedding Qlik Sense components
with qlik-embed.

Review the [Anonymous Access with qlik-embed tutorial](https://qlik.dev/embed/qlik-embed/quickstart/qlik-embed-anonymous-tutorial/)
to learn more.
