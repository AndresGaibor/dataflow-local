# Removal of usage restrictions for Brands API

The Brands API, initially launched for use by Qlik OEM customers, is now
available to all Qlik customers. You can find the original release in
[this changelog](https://qlik.dev/changelog/39-api-updates-brands/). This API helps
improve alignment with your corporate branding and reduces friction
for your end users as they switch between experiences.

For more information, review the [Brands API reference](https://qlik.dev/apis/rest/brands/), or take a look at
the [Apply branding to a tenant tutorial](https://qlik.dev/manage/platform-operations/brand-a-tenant) to learn how
to call the API using code.

For no-code developers, native blocks are available in the [Qlik Platform Operations](https://qlik.dev/toolkits/no-code/)
connector in Qlik Automate.
