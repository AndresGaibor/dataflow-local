# TypeScript Platform SDK end of life and end of support

Following the [deprecation notice](https://qlik.dev/changelog/88-typescript-platform-sdk-deprecation/) of March 26, 2024, the
TypeScript Platform SDK will reach end-of-life and end-of-support on **March 27, 2025**.

Starting from March 27, 2025, this SDK will no longer receive updates or releases,
and may be removed at any time.
Please use [qlik-api](https://qlik.dev/toolkits/qlik-api/) instead.
