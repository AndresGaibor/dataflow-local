# Deprecation notice - AutoML dataset predictions and real-time predictions APIs

The following legacy APIs are deprecated and will be removed on or after February 3, 2026:

- [AutoML dataset predictions API](https://qlik.dev/apis/rest/automl-predictions/)
- [AutoML real-time predictions API](https://qlik.dev/apis/rest/automl-deployments/)

For new development, use the [Machine Learning API](https://qlik.dev/apis/rest/ml/) instead.
